## Q-04-02-UG-01
- id: Q-04-02-UG-01
- entry_id: 04-02-UG / subtheme_id: 04-02 / difficulty: 1 / fact_type: fact
- 問題文: USDA FAS『Coffee: World Markets and Trade』2025年12月版の2025/26年産予測（60kg袋）で、ウガンダの生産量6.875百万袋のうち約85%を占める種はどれか。
- 選択肢:
  1. アラビカ
  2. ロブスタ ★
  3. リベリカ
  4. エクセルサ
- 解説（要点）: 内訳はロブスタ5.815百万袋／アラビカ1.06百万袋で、ロブスタが約85%を占める。ウガンダはアフリカ有数のロブスタ生産国である。
- 詳細解説: USDA は2025年6月版でウガンダを「世界第4位のロブスタ生産国」（ベトナム、ブラジル、インドネシアに次ぐ規模）と位置づけた。ロブスタはビクトリア湖周辺を含む中部・西部・東部の低〜中標高地が中心で、アラビカは東部エルゴン山周辺（ブギシュ／シピ呼称地域）などで生産される。ロブスタはウガンダを含むビクトリア湖周辺が原産域の一つとされ、在来系統が自生してきた土地で商業生産が拡大した点が、移植先で広がった他国と異なる位置づけである（02-02）。数値は予測であり版によって改訂されるため、引用時は版と年度の明記が前提になる。
- 出典: USDA FAS "Coffee: World Markets and Trade" December 2025（https://apps.fas.usda.gov/psdonline/circulars/coffee.pdf ）／ USDA GAIN "Coffee Annual" UG2025-0001（2025年5月公表）

## Q-04-03-SIDAMO-02

- 選択肢:
  1. 2020年に南部諸民族州から分離して新設された地域州で、州都はハワッサである ★
  2. 2020年にオロミア州へ編入された地域で、州都を持たない

## Q-09-04-01
- id: Q-09-04-01
- entry_id: 09-04 / subtheme_id: 09-04 / difficulty: 2 / fact_type: fact
- 問題文: SCA の記述的評価（SCA Standard 103-2024）における酸質（Acidity）の記録方法として正しいのはどれか。
- 選択肢:
  1. CATA リストから当てはまる項目を最大2つ選ぶ
  2. 9点スケールで好ましさを記録する
  3. CATA リストはなく、総強度を記録し、質は自由記述で書く ★
  4. フレーバーホイールの外側の語を必ず1つ選ぶ
- 解説（要点）: Acidity はセクションの一つだが CATA リストはなく、強度（セクションごとの総強度、15点スケール）と自由記述による質の表現で記録する。「酸が強い」と「レモンのような酸」は別の情報であり、強度と質を分けて言うのが語彙運用の原則である。
- 詳細解説: CATA リストから最大2つ選ぶ運用があるのは質感（Mouthfeel）等のセクションであり、酸質（Acidity）には CATA リスト自体がない点が混同しやすい。また、9点スケールで好ましさを記録するのは情緒的評価（SCA-104）の方式であり、記述的評価（SCA-103）の記録方法とは別である。酸質の表現は、強さの軸（穏やか〜際立つ）と質の軸（柑橘系、果実系、発酵系等の系統）で整理すると伝えやすい。なお「明るい（bright）」は酸質の好ましい質を指す慣用表現で、強度そのものとは別概念である。また、欠点としての「酸っぱさ（sour、発酵由来の酢酸様）」は 09-05 の欠点側で扱い、区別する。
- 出典: SCA Standard 103-2024「Coffee Value Assessment: Descriptive Assessment」（https://sca.coffee/value-assessment ）／ World Coffee Research "Sensory Lexicon" 2.0（2017、C09-02）

## Q-09-05-01
- id: Q-09-05-01
- entry_id: 09-05 / subtheme_id: 09-05 / difficulty: 1 / fact_type: fact
- 問題文: 現行の情緒的評価（SCA Standard 104-2024）で、フォーム上の官能的欠点として減点対象になるのはどれか。
- 選択肢:
  1. ポテト（potato）／カビ（moldy）／フェノール（phenolic）の3種 ★
  2. ポテト／未熟豆／虫害豆の3種
  3. カビ／過発酵／スティンカーの3種

- 解説（要点）: 制度上の官能的欠点はポテト、カビ、フェノールの3種に限られ、欠点カップ1つにつき −4点と定められている。未熟豆や虫害豆は外観で判別できる物理的欠点で、選別・格付け側（03-07 等）の担当である。
- 詳細解説: 減点の運用として、欠点として記録するには該当カップの番号と欠点の種類の両方を記録し、欠点カップは原則として均一でないカップとしても数える。実務で遭遇する欠点は他にもあるが（過発酵による酸、スティンカー、パストクロップ／バッギー等）、フォーム上の減点対象として制度化されているのはこの3種である点が、制度と実務を分けて理解する要点になる。

- 選択肢:
  1. ロット全体に均一に広がり、すべてのカップに同じ強さで出る
  2. 生のジャガイモの皮のような匂いで、特定のカップだけに強く出ることが多く、豆1粒単位で生じる ★
  3. 浅煎りの豆にだけ出る、焙煎由来の欠点である
  4. 麻袋のような匂いが移るもので、長期保管が原因である
- 解説（要点）: ポテトは東アフリカ（ルワンダ、ブルンジ等）の一部ロットで知られる欠点で、豆に付着する細菌の関与が報告されている。豆1粒単位で生じるため、ロット全体を捨てる問題ではなく、該当カップの特定が対処になる。
- 詳細解説: 欠点には、ロット全体に広がるもの（乾燥不足によるカビ臭、保管不良による劣化臭＝パストクロップ／バッギー系）と、特定のカップ・特定の豆だけに出るもの（ポテト、フェノール様、スティンカー等）がある。複数カップを並べるカッピング（09-01）で「1カップだけ違う」ことが分かるのは、この区別のためである。判別では、まず抽出条件を標準に戻して豆以外の要因を除外し、全カップ共通か特定カップだけかを分けるのが手順になる。
