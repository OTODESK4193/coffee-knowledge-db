## Q-05-09-01
- id: Q-05-09-01
- entry_id: 05-09 / subtheme_id: 05-09 / difficulty: 1 / fact_type: fact
- 問題文: 「レギュラーコーヒー及びインスタントコーヒーの表示に関する公正競争規約」では、産地・品種・銘柄等を冠した「○○ブレンド」と表示できる条件として、正しいのはどれか。
- 選択肢:
  1. 当該コーヒー生豆を30%以上使用している場合に限る ★
  2. 当該コーヒー生豆を50%を超えて使用している場合に限る
  3. 当該コーヒー生豆を少しでも使用していれば、割合にかかわらず表示できる
  4. 当該コーヒー生豆の生産国名が原材料表示の先頭にあれば、使用割合にかかわらず表示できる
- 解説（要点）: 規約で「○○ブレンド」と表示できるのは、当該コーヒー生豆を30%以上使用している場合に限られる。あわせて、レギュラーコーヒーの原材料は100%コーヒー豆に限られ、香料等を使ったものは「レギュラーコーヒー」と表示できないことが定められている。なお、生産国名の表示は別の定めであり、「○○ブレンド」の可否を決める条件ではない。
- 詳細解説: 生豆生産国名の表示にも規約の定めがあり、ブレンドの場合は主要な生産国を原則として重量の多い順に表示し、3か国以上使う場合は重量割合の高いものから2か国以上を表示して残りを「その他／他」とすることができる。これらは、消費者が配合の実態を誤認しないようにするための表示ルールである。なお、この公正競争規約は景品表示法第36条に基づき認定された業界ルールで、全日本コーヒー公正取引協議会が運用している。
- 出典: 「レギュラーコーヒー及びインスタントコーヒーの表示に関する公正競争規約」および施行規則（05-D13）／ エントリー 05-09

## Q-05-09-02
- id: Q-05-09-02
- entry_id: 05-09 / subtheme_id: 05-09 / difficulty: 2 / fact_type: fact
- 問題文: 「食品期限表示の設定のためのガイドライン」（厚生労働省・農林水産省）における賞味期限設定の基本的な考え方として、正しいのはどれか。
- 選択肢:
  1. 理化学試験・微生物試験・官能検査等の客観的な指標に基づいて期限の目安を得て、食品の特性に応じて1未満の安全係数を掛けて、それより短い期間を設定する ★
  2. 業界で慣行となっている標準的な月数を、そのまま自社製品の賞味期限として採用する
  3. 保存試験等で得られた期限の目安に、1を超える安全係数を掛けて、長めの期間を設定する
  4. 賞味期限は安全性だけで決まるため、官能検査（味・香り）の結果は設定の指標に含めない
- 解説（要点）: ガイドラインの基本は「客観的な指標で期限の目安を得る→1未満の安全係数を掛けて短い期間を設定する」という2段階である。安全係数は1未満であり、掛けると期間は短くなる（1を超える係数を掛けて期間を延ばすのは向きが逆である）。他社・業界の慣行値の流用は、この考え方に反する。なお、変動が少ないと考えられる食品では安全係数0.8以上を目安とすることが望ましいとされ、設定根拠の資料は事業者が整備・保管し、求めがあれば情報提供することとされている。
- 詳細解説: コーヒーの賞味期限は、安全性よりも品質（酸化による風味劣化、07-04）が制限要因になるのが通常であり、指標には官能評価と酸化関連の理化学指標が使われる。豆のままか粉か、包装形態（窒素置換の有無）で劣化速度が変わるため、期限は製品形態ごとに設定される。「業界標準の月数」のような一律の慣行値は根拠にならず、期限は製品ごとの保存試験と安全係数で決まる。
- 出典: 「食品期限表示の設定のためのガイドライン」（厚生労働省・農林水産省、05-D14）／ エントリー 05-09
- 関連: Q-07-04-01, Q-03-08-01
- メディア: M-05-09-1
