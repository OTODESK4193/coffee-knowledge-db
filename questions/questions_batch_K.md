## Q-09-01-06
- id: Q-09-01-06
- entry_id: 09-01 / subtheme_id: 09-01 / difficulty: 2 / fact_type: fact
- 問題文: SCA Standard 102-2024 に基づくカッピングで、ある容器に縁（rim）まで常温の水を入れて量ると 220 g であった。この容器で情緒的評価の試料を調製する場合、1カップあたりのコーヒーの投量として正しいのはどれか。
- 選択肢:
  1. 12.1 g ★
  2. 8.25 g
  3. 5.6 g
  4. 11.0 g
- 解説（要点）: 投量は「容器の縁までの容量150 mLあたり8.25 g」と定められており、容量は縁まで入れた水の重さ（g）を密度1 g/mLとして測る。したがって 8.25 × 220 ÷ 150 = 12.1 g となる。投量は容器容量に比例して変わるものであり、容量によらず固定したり、150 mLと実測容量を取り違えて逆算したりすると、この値にはならない。
- 詳細解説: 規格では、カップごとに豆を別々に量り、秤の精度は0.1 g以上、豆1粒の重さに由来する±0.2 gの許容差が認められる。容器は容量200〜350 mL・上部直径75〜90 mmの範囲で、使用する全カップで容量・寸法・材質を同一にすることが求められる。「150 mLあたり8.25 g」という規定は固定の投量ではなく、実測した容器容量に比例させる比率の規定として読む必要がある。
- 出典: SCA Standard 102-2024 §5.2（C07-01）／ エントリー 09-01
- 関連: Q-09-01-01, Q-09-01-05
- メディア: M-09-01-2

## Q-09-02-04
- id: Q-09-02-04
- entry_id: 09-02 / subtheme_id: 09-02 / difficulty: 2 / fact_type: fact
- 問題文: あるロットの取引資料に「カッピングスコア 85点」とだけ記されていた。CVA への移行を踏まえた実務上の解釈として、正しいのはどれか。
- 選択肢:
  1. その85点が CVA の情緒的スコアなのか、旧100点フォームのスコアなのかを確認しなければ意味が定まらない。両者は物差しが異なり（CVA は全セクション中立で79.00点が基準、旧制度では80点がスペシャルティの目安とされた）、同じ85点でも意味が同じとは限らない ★
  2. 85点であれば、新旧どちらの制度のスコアでも同じ意味であり、スペシャルティと断定できる
  3. CVA の情緒的評価では85点というスコアは付けられないため、この資料の数値は誤記である
  4. 旧フォームの85点は、決められた換算で自動的に CVA の85点に読み替えられる
- 解説（要点）: スコアの数値は、どの制度の物差しで付けられたかが分からなければ解釈できない。CVA の情緒的評価は「全て中立＝79.00点」を基準点とする設計で、旧フォームは「80点以上＝スペシャルティ」が目安とされた別制度である。なお、CVA の換算範囲は合計8（全て1）→58.00から合計72（全て9）→100.00までであり、85点という数値自体は CVA でも付けられうる。数値が存在することと、その意味が旧フォームと同じであることは、別の話である。
- 詳細解説: 旧2004年プロトコルとフォームは、現行規格（102／103／104-2024）で置き換え（supersede）の対象と明記されているが、旧フォームによるスコアは現在も市場で流通しうる。そのため資料を読む側は、数値の大きさではなく制度の帰属を先に確認する。なお CVA でも Physical Assessment は2004年の生豆格付け制度に基づいており、置き換えられたのはカッピングのプロトコルとフォームである点も、混同を避けるうえで重要である。なお、旧フォームの「80点以上＝スペシャルティ」という定義文そのものは、2004年プロトコル原文での照合が未了のため、本DBでは旧制度の目安として扱っている。
- 出典: SCA Standard 103-2024／104-2024 および SCA 公式 CVA ページ（C07-02、C07-03）／ エントリー 09-02
- 関連: Q-09-02-01, Q-09-02-02, Q-09-02-03

## Q-07-05-04
- id: Q-07-05-04
- entry_id: 07-05 / subtheme_id: 07-05 / difficulty: 2 / fact_type: fact
- 問題文: 粉 20 g を使い、抽出液 300 g を得る抽出で、抽出率を 20% にしたい。必要な TDS はおよそどれか。
- 選択肢:
  1. 1.33% ★
  2. 2.00%
  3. 1.25%
  4. 0.75%
- 解説（要点）: 抽出率（%）＝ TDS（%）× 抽出液の質量 ÷ 粉の質量、という関係式を TDS について解く。TDS ＝ 20 × 20 ÷ 300 ≒ 1.33%。値を覚える問題ではなく、式を組み替えて必要な濃度を導く問題である。分母に粉と液の総質量（320 g）を使うと別の値になってしまうため、分母は抽出液の質量（300 g）であることを確認する。
- 詳細解説: TDS（濃度）と抽出率は独立に動く2つの量であり、ブリュー比率が固定されれば両者はおおよそ比例する。この逆算は、レシピ設計で「目標の抽出率に対して、どの程度の濃度が出ていればよいか」を見積もる際の基本操作になる。なお、この式は液の一部が粉に保持される方式（浸漬式等）では保持分の扱いで前提が変わる点に注意する。
- 出典: 抽出率の関係式（Guinard et al. 2023、C07-09）／ エントリー 07-05
- 関連: Q-07-05-02, Q-07-05-03
- メディア: M-07-05-1

## Q-07-05-05
- id: Q-07-05-05
- entry_id: 07-05 / subtheme_id: 07-05 / difficulty: 3 / fact_type: fact
- 問題文: 同じ豆・同じ器具で抽出したところ、抽出の進み具合（抽出率）は今のままでよいが、味が薄い（TDS が低い）と感じた。抽出率を大きく変えずに濃さだけを上げるための調整として、考え方に合うのはどれか。
- 選択肢:
  1. ブリュー比率を変える（湯に対する粉の割合を増やす） ★
  2. 粉を細かく挽く
  3. 湯温を上げる
  4. 攪拌・乱流を増やす
- 解説（要点）: ブリューイング・コントロールチャートの考え方では、濃さの問題と抽出具合の問題を分けて直す。粉を細かくする・湯温を上げる・攪拌を増やすはいずれも抽出率を上げる方向の変数であり、「抽出率はそのままに濃さだけ上げる」という要求には合わない。粉の割合を増やす（ブリュー比率の変更）は、抽出を進める側の変数ではなく、濃度を上げる側の調整であるため、濃さの問題を比率の側で直す調整になる。チャート上では、点は元の比率の直線から別の比率の直線へ移る。
- 詳細解説: チャート上では、比率を変えずに抽出の進み具合だけを変えると点は比率の直線に沿って移動し、比率を変えると別の直線へ移る。診断の出発点は「薄い／濃い」と「未抽出／過抽出」を混同しないことであり、失敗診断への応用は 07-07 で扱う。なお古典チャートの「理想域」の数値域は、本DBでは公式原文の直接確認が済むまで出題・表示の対象にしていない。
- 出典: ブリューイング・コントロールチャートの考え方（Lockhart の古典的枠組み、C07-09）／ エントリー 07-05
- 関連: Q-07-05-01, Q-07-05-02
- メディア: M-07-05-2

## Q-02-03-04
- id: Q-02-03-04
- entry_id: 02-03 / subtheme_id: 02-03 / difficulty: 2 / fact_type: fact
- 問題文: 品種系統図におけるゲイシャ（Geisha / Gesha）の位置づけとして、正しいのはどれか。
- 選択肢:
  1. ティピカ系統とブルボン系統のどちらからも派生していない。エチオピアの在来系統であり、20世紀に研究機関の生殖質コレクションを経由してエチオピアから直接中米へ渡った ★
  2. ティピカ系統から派生した品種である
  3. ブルボン系統から派生した品種である
  4. ティピカとブルボンの交配によって近代育種で作出された品種である
- 解説（要点）: WCR 品種カタログはゲイシャの遺伝的説明を「Ethiopian landrace（エチオピア在来系統）」とし、育種者は「なし」とする。イエメンを経由して世界に広がったティピカ／ブルボンの2つの遺伝的基盤には属さず、Lyamungu 研究所や CATIE といった研究機関の生殖質（種子資源）コレクションを経由する「もう一つの伝播経路」で中米へ渡った点が、系統図に載せる学習上の意味である。
- 詳細解説: 経路の骨格は、1930年代にエチオピアのコーヒー林で採集 → タンザニアの Lyamungu 研究所 → 1953年に CATIE へ導入（番号 T2722）→ 1960年代にパナマへ配布、である（Q-02-03-01）。系統の位置づけと来歴の経路は別の知識であり、経路を覚えていても「どの系統に属するか」を取り違えることはある。なお「ゲイシャ」と表示されたロットがパナマ系（T2722 の子孫）と同一の遺伝的系統であることは、表示だけでは保証されない（Q-02-03-03）。
- 出典: WCR 品種カタログ「Geisha (Panama)」（A-01）／ エントリー 02-03
- 関連: Q-02-03-01, Q-02-03-03
- メディア: M-02-03-1

## Q-02-03-05
- id: Q-02-03-05
- entry_id: 02-03 / subtheme_id: 02-03 / difficulty: 3 / fact_type: fact
- 問題文: ゲイシャは1960年代のパナマへの配布時にはさび病への耐性が注目されたが、現行の WCR 品種カタログではさび病への抵抗性は「中程度（Intermediate）」と評価されている。この抵抗性評価の読み方として、正しいのはどれか。
- 選択肢:
  1. 抵抗性の表示は地域条件付きで読む必要がある。病原菌のレース（race）構成によって、現地での振る舞いは変わりうる ★
  2. かつて持っていた耐性が完全に失われたことを意味する
  3. 「中程度」であれば、どの生産地でも同じ程度の抵抗性を示すことが保証される
  4. さび病には一切かからない品種であることを意味する
- 解説（要点）: 導入当時に評価された「耐性」という表現と、現行カタログの「中程度の抵抗性」という評価は食い違って見えるが、WCR は病原菌のレース構成によって現地での振る舞いが変わりうる旨を注記している。つまり抵抗性の表示は、品種に固定された絶対的な性質ではなく、植える地域の病原菌の構成とセットで読む条件付きの評価である。「かつて持っていた耐性が完全に失われた」と断定する根拠はカタログにはなく、評価の変化をそのようには読まない。
- 詳細解説: WCR カタログの栽培特性では、ゲイシャは品質ポテンシャルが高標高で「Exceptional（例外的に高い）」とされる一方、収量ポテンシャルは低く、線虫とコーヒーベリー病には感受性と評価される。品種カタログの各評価は「どの条件のもとでの評価か」を伴って読むものであり、単独の形容詞だけを切り取って品種の性質として固定しないことが、系統・品種情報の読み方の基本になる。
- 出典: WCR 品種カタログ「Geisha (Panama)」（A-01）／ エントリー 02-03
- 関連: Q-02-03-01, Q-02-03-02
- メディア: M-02-03-1

  3. ハニーはチェリーの形のまま乾燥させる点だけが異なる
  4. 違いは乾燥方法（天日か機械か）だけであり、果肉除去後の工程は同じである
- 解説（要点）: 方式の違いの本質は「どの層を・どの順序で・どの水分状態で取り除くか」である。両方式とも果肉除去（パルピング）までは同じで、分岐点はその後にミューシレージを落とすかどうか、に移る。「チェリーのまま乾燥させる」方式はナチュラル（乾式）であり、果肉を除去する両方式とは出発点から異なる。なお、残すミューシレージの量による色名の細分（ホワイト／イエロー／レッド／ブラック等）は生産者・地域依存の呼称で、公的規格ではないため本問の判定には使っていない。
- 詳細解説: 工程順に並べると、ウォッシュドは「果肉除去 → 発酵 → 水洗 → 乾燥」、ハニーは「果肉除去 →（ミューシレージを残したまま）乾燥」となる。ブラジルのパルプドナチュラルと中米のハニーは近縁の方式として扱われることが多いが、呼称の使い分けに厳密な国際定義はない。味の傾向としては、ハニーはウォッシュドとナチュラルの中間的で甘さが強調されやすいと語られるが、これは傾向表現であり、方式から味を断定はしない。
- 出典: FAO 加工資料（03-S12）ほか ／ エントリー 03-05

## Q-03-05-04
- id: Q-03-05-04
- entry_id: 03-05 / subtheme_id: 03-05 / difficulty: 2 / fact_type: fact
- 問題文: ある生産者は、収穫したチェリーをそのまま天日で乾燥させる方式を採っている。この方式では、発酵や水洗による後段の修正が効かない。そのため品質管理上、特に重要になることの組み合わせとして正しいのはどれか。
- 選択肢:
  1. 収穫時点での成熟選別と、乾燥中の管理（攪拌、雨対策、カビ防止） ★
  2. 発酵タンクの水の管理と、発酵時間の調整
  3. 高い含水率のうちにパーチメントを剥くタイミングの調整
  4. 水洗の回数と、洗浄水の入れ替え頻度

- 詳細解説: FAO 資料はナチュラルを「最も古く、最も単純で、機械をほとんど必要としない」方式とし、天候により最大4週間ほどで最適水分約11%に到達するとする。乾燥期間が長い分、その間の天候と管理の影響を直接受ける。方式選択は気候・水資源・設備・労働力・狙う市場で決まるものであり、「どの工程に品質管理の重点が移るか」は方式の構造から導ける。

## Q-07-01-03
- id: Q-07-01-03
- entry_id: 07-01 / subtheme_id: 07-01 / difficulty: 3 / fact_type: fact
- 問題文: サンプル焙煎で、到達した色はカッピング用焙煎の規格範囲（粉の明度 L* 26〜29）に入っていたにもかかわらず、評価では「baked（香りの伸びない状態）」とされた。この食い違いの説明として、焙煎の科学と規格の前提に合うのはどれか。
- 選択肢:
  1. 到達色が同じでも、焙煎の時間配分によって欠陥になることがある。焙煎が遅すぎる場合は baked と呼ばれ、色（粉の明度）は到達点の明るさを示す測定値で、そこに至る時間配分までは示さない ★
  2. 規格は到達色だけで合否を決めるため、baked という評価自体が誤りである
  3. 原因はデガス不足であり、焙煎後の休息を延ばせば必ず解消する
  4. 1ハゼの音が聞こえなかったことが、baked の定義上の条件である
- 解説（要点）: SCA Standard 102-2024 はサンプル焙煎について、速すぎる焙煎（未発達・焦げ）と遅すぎる焙煎（baked）を「焙煎の問題」として避けるよう定めており、到達色が規格内でも時間配分が不適切なら欠陥になることが規格の前提になっている。また、本問の色は粉の明度として測られる到達点の値であり、そこに至る時間配分の良し悪しは、この値だけでは判断できない。試料の休息（8〜24時間）はデガスと風味の安定を待つための規定であり、baked の解消策として定められたものではない。休息を延ばしても、焙煎の時間配分の問題そのものは解消しない。
- 詳細解説: 焙煎の記録・評価では、色（測定値）に加えて、乾燥 → メイラード反応の本格化 → カラメル化 → 1ハゼ → 発展、という進行の時間配分が対象になる。サンプル焙煎で「発展」区間を含む全体の時間配分が記録の対象になるのはこのためである（07-03 のプロファイル）。色を測定量として扱うことと、色だけで焙煎の良し悪しが決まらないことは、矛盾しない。
- 出典: SCA Standard 102-2024 のサンプル焙煎規定（C07-01）／ 学術書 Illy & Viani 編（C07-11）／ エントリー 07-01、09-01

## Q-07-01-04
- id: Q-07-01-04
- entry_id: 07-01 / subtheme_id: 07-01 / difficulty: 2 / fact_type: fact
- 問題文: 焙煎したての豆は、そのままでは抽出が安定しにくい。デガス（二酸化炭素の放出）との関係で、この現象と実務上の扱いの説明として正しいのはどれか。
- 選択肢:
  1. 焙煎中に生成された二酸化炭素は豆の内部に蓄えられ、焙煎後も放出が続く。ガスが多い焙煎直後は安定した抽出が難しく、ドリップの「蒸らし」でガスを抜く工程や、カッピング規格が定める試料の休息（8〜24時間）には、この放出を待つ意味がある ★
  2. 二酸化炭素は焙煎が終わった時点で全て放出されるため、焙煎直後の不安定さとは無関係である
  3. 焙煎直後の豆は水分が多すぎるため湯が浸透せず、乾燥が進むまで待つ必要がある
  4. 焙煎直後はカフェインが最も多く、それが抽出を妨げるため、時間が経ってカフェインが減るのを待つ
- 解説（要点）: デガスは焙煎で生成した二酸化炭素が豆内に蓄積し、焙煎後も放出が続く現象であり、粉にすると表面積が増えて放出は速まる。焙煎直後の不安定さはこのガスに由来する部分が大きく、蒸らしと休息時間はその対策として位置づけられる。カッピング規格（SCA-102-2024）が試料の休息を8〜24時間と定めるのも、この放出と風味の安定を待つためである。豆の水分は焙煎の乾燥段階で抜けていくものであり、焙煎直後の不安定さの主因ではない。また、時間の経過でカフェインが減って抽出が安定するという仕組みは、本エントリーの根拠にはない。
- 詳細解説: デガスは保存設計ともつながる。放出されるガスを前提に、包装には一方向バルブ（ガスは逃がし空気は入れない仕組み）が使われ、ガスと酸化・香りの揮散の関係は SCA の『The Coffee Freshness Handbook』（2018）が実測研究に基づいて扱う（詳細は 07-04）。「焙煎直後が最も香るから最良」とも「置けば置くほど良い」とも単純化できず、放出と酸化の両方を見る必要がある。
- 出典: 学術書 Illy & Viani 編（C07-11）、SCA『The Coffee Freshness Handbook』（C07-07）、SCA Standard 102-2024（C07-01）／ エントリー 07-01、09-01

## Q-07-02-03

- entry_id: 07-02 / subtheme_id: 07-02 / difficulty: 2 / fact_type: fact
- 問題文: 異なる2つのロースターが、どちらも「シティロースト」と表示した豆を販売している。購入者が両者を焙煎度で正確に比較しようとする場合の考え方として、正しいのはどれか。
- 選択肢:
  1. 段階名の区切りは国・団体・事業者で統一されておらず、同名でも実物の色が異なりうるため、呼称だけで比較せず、Agtron や CIELAB の明度 L* といった色の測定値を共通の物差しにする必要がある ★
  2. 「シティ」は日本の8段階でも英語圏の呼称でも指す色の範囲が完全に一致するため、呼称のまま比較できる
  3. 日本の8段階の呼称は公的規格として一元的に定められているため、表示が同じなら焙煎度も同じである
  4. 焙煎日が近ければ、呼称が同じ豆同士は焙煎度も同じとみなせる
- 解説（要点）: 日本で使われる8段階の呼称（ライト、シナモン、ミディアム、ハイ、シティ、フルシティ、フレンチ、イタリアン等）は業界の慣用であり、公的規格として一元的に定められたものではない。英語圏の同名呼称とも指す範囲がずれる場合があり、ロースター独自の段階名も多い。したがって比較の物差しは呼称ではなく色の測定値であり、規格文書自身もカッピング用焙煎を粉の L* 26〜29、およそ Agtron タイル #65 と測定値で定義している。

## Q-07-02-04
- id: Q-07-02-04
- entry_id: 07-02 / subtheme_id: 07-02 / difficulty: 2 / fact_type: fact
- 問題文: Agtron スケールで測った焙煎度の数値を、別のロットの測定結果と比較するときの注意点として、正しいのはどれか。
- 選択肢:
  1. 豆のままの測定と粉の測定では値が異なるため、どちらで測ったかを併記しなければ比較できない ★
  2. 豆のまま測っても粉で測っても値は同じなので、測り方を記録する必要はない
  3. Agtron は豆のままでは測定できず、必ず粉にしなければならない
  4. Agtron の値と CIELAB の L* は対応づけができないため、併記しても意味がない
- 解説（要点）: Agtron スケールは数値が大きいほど浅く（明るく）、小さいほど深い（暗い）という読み方自体は共通だが、測定対象が豆のままか粉かで値が変わる。そのため数値の比較には測定条件の記録が前提になる。Agtron の値と CIELAB の L* には対応づけが存在する。SCA-102-2024 自身がカッピング用焙煎レベルを粉の L* 26〜29 と定義し、Agtron／SCA タイル #65 への対応を併記していることが、その根拠である。
- 詳細解説: 測定値で管理する現在の方法では、「値」と「測定条件」はセットである。"Gourmet" スケールのような区分の違いも含め、どのスケール・どの状態（whole bean / ground）で測ったかが記録されていなければ、異なる出所の数値を並べても焙煎度の比較にはならない。これは水の基準で「どの体系の数値か」を併記するのと同じ、測定値一般の読み方の原則である。

## Q-07-08-02
- id: Q-07-08-02
- entry_id: 07-08 / subtheme_id: 07-08 / difficulty: 2 / fact_type: fact
- 問題文: コーヒー用の水質を測る滴定キットのうち、「KH」と表示されたキットが実際に測っているものの説明として、正しいのはどれか。
- 選択肢:
  1. 一般にアルカリ度（水が酸を中和できる容量）を測るもの。実体はほぼ炭酸水素イオン（HCO3−）であり、一定量の酸を加えて pH が規定の終点まで下がるのに要する酸の量として測る ★
  2. 総硬度（Ca2+ と Mg2+ の合計量）
  3. 水の TDS（溶けている全物質の総量）
  4. その瞬間の水の pH
- 解説（要点）: 「KH」キットの実体はアルカリ度の測定である場合が多い。アルカリ度は緩衝能（酸を中和できる容量）の指標であり、値の瞬間的な酸性・アルカリ性を示す pH とは別の量である。総硬度は Ca2+ と Mg2+ の合計を測るもので、アルカリ度とは対象が異なる。炭酸塩硬度という概念は「総硬度とアルカリ度のうち小さい方」を指し、多くの水道水では両者が近接するために KH と混同されやすいが、軟水化した水などでは一致しない。
- 詳細解説: 指標を取り違えると基準の読み違いに直結する。たとえば2009年 SCAA 基準が使うのはカルシウム硬度であり、総硬度と取り違えると基準を読み誤る。また水の TDS メーターは電気伝導度からの推定値でしかなく、「何が溶けているか」は分からないため、組成の判定には使えない。したがって水の TDS の値だけから、硬度やアルカリ度を読み取ることはできない。ミネラルウォーターのラベル値と基準を比べる際も、各イオンを CaCO3 換算に直してから比較する必要がある。
- 出典: SCA『The Water Quality Handbook』（2018、C07-06）ほか ／ エントリー 07-08
- 関連: Q-07-08-01, Q-07-08-03
- メディア: M-07-08-2

## Q-07-08-03
- id: Q-07-08-03
- entry_id: 07-08 / subtheme_id: 07-08 / difficulty: 2 / fact_type: fact
- 問題文: 店舗の水をイオン交換式の軟水器に通したところ、硬度は下がった。しかしこの水が、そのままコーヒーの抽出用として最適とは限らない。その理由として正しいのはどれか。
- 選択肢:
  1. 軟水器は Ca2+／Mg2+ を Na+（または K+）と交換して硬度だけを下げる仕組みで、アルカリ度は変わらず、Na+ が増えるため ★
  2. 軟水器を通すとアルカリ度も同時にゼロになるため
  3. 軟水器は硬度を下げるのではなく上げる装置であるため
  4. 軟水器は塩素と硬度を完全に除去し、水を純水にするため
- 解説（要点）: 各処理は、水を「総硬度 × アルカリ度」の平面上で決まった方向にだけ動かす。軟水器（イオン交換）の動きは「総硬度は下がる、アルカリ度は変わらない、Na+ は増える」であり、万能の処理ではない。アルカリ度が高すぎる水は抽出液の酸を中和して味を平たくするため、硬度だけを下げても酸の知覚の問題は残りうる。旧試験では、イオン交換で軟水化した水（Na+ とアルカリ度が残る水）が粉層の流れを遅くしたため抽出用には勧められないとされた報告もある。
- 詳細解説: 処理の組み立ては、まず水道事業体の公表値や滴定キットで現在の総硬度とアルカリ度を把握し、目標との差分から処理を選ぶのが順序である。硬度とアルカリ度の両方を下げたい場合は脱炭酸（弱酸性陽イオン交換）や逆浸透（RO）＋再ミネラル化が候補になり、塩素除去だけなら活性炭で足りる（活性炭は硬度もアルカリ度も変えない）。「軟水＝コーヒーに向く水」という短絡を避けることが、水の実務の出発点になる。
- 出典: SCA『The Water Quality Handbook』（2018、C07-06）の処理整理 ／ エントリー 07-08
- 関連: Q-07-08-01, Q-07-08-02
- メディア: M-07-08-1

## Q-04-01-05
- id: Q-04-01-05
- entry_id: 04-01 / subtheme_id: 04-01 / difficulty: 2 / fact_type: fact
- 問題文: 生産国マスター表の見出しにある「2025/26年産」という表記について、正しい理解はどれか。
- 選択肢:
  1. 各国のマーケティングイヤーの開始月は国により異なるため、「2025/26」は全世界で同一の暦期間を意味しない ★
  2. 全世界の生産国で10月開始に統一されているため、同一の暦期間を意味する

  4. 北半球の暦年（2025年1月〜2026年12月）と正確に対応している

## Q-05-02-03
- id: Q-05-02-03
- entry_id: 05-02 / subtheme_id: 05-02 / difficulty: 2 / fact_type: fact
- 問題文: ICO の複合指標価格 I-CIP の位置づけとして、正しいのはどれか。
- 選択肢:
  1. 現物市場の相場から算出される「市場の物差し」であり、個別ロットの取引価格そのものではない。個別の輸出価格は、原則として先物価格 ± ディファレンシャルで決まる ★
  2. 全ての生産国・全てのロットに強制される取引価格である
  3. ニューヨークの先物価格そのものを別名で呼んだものである
  4. 生産者の生産コストを積み上げて算出される価格である
- 解説（要点）: コーヒーの国際価格は層になって決まる。取引所の先物価格が価格発見の土台となり、ICO の指標価格（4グループとその加重平均である I-CIP）は現物相場から算出される物差しとして公表され、個別取引の価格は先物価格に品質・産地・需給で決まるディファレンシャルを上乗せ・差し引いて決まる。I-CIP の重み自体を問う既存問題（Q-05-02-02）とは角度が異なり、本問は価格の層構造の中での位置づけを問う。国際価格は個々の農家の生産コストを積み上げて決まるものではなく、生産コストは国際価格に直接は反映されない。
- 詳細解説: World Bank Pink Sheet のアラビカ／ロブスタ価格系列の正体は、ICO 指標のうち Other Milds と Robustas であり、指標価格が統計・報道で「世界価格」のように扱われる背景になっている。ただし指標はあくまで集計された相場の物差しであり、スペシャルティ領域ではカップ品質に基づく大きなプレミアムが先物と切り離されて交渉される場合もある。その場合、先物は価格の本体ではなく「参照」にとどまる。

## Q-05-02-04
- id: Q-05-02-04
- entry_id: 05-02 / subtheme_id: 05-02 / difficulty: 3 / fact_type: fact
- 問題文: ある生産国で、国際価格（ドル建て）が前年と変わらなかったにもかかわらず、農家の現地通貨建ての受け取りが増えた。価格の伝達の仕組みから導ける説明として、正しいのはどれか。
- 選択肢:
  1. 輸出価格はドル建てで決まり、輸送・精製・輸出経費等を差し引いた残りが現地通貨に換算されて農家価格になるため、現地通貨が安くなれば現地通貨建ての受け取りは押し上げられる（ただし輸入資材費も上がる） ★
  2. ICO 指標価格のグループ重みが見直されたためである
  3. 先物契約の契約単位が変更されたためである
  4. ディファレンシャルは国際価格が不変なら自動的に拡大する決まりのためである
- 解説（要点）: 農家価格は国際価格の写しではなく、「ドル建ての輸出価格 → 経費の差し引き → 現地通貨への換算」という伝達の末端にある。したがって農家の受け取りは、国際価格が同じでも為替レートで大きく変わる。ディファレンシャルはロットごとの交渉で決まるものであり、国際価格が不変なら自動的に拡大するといった決まりはない。ICO 指標のグループ重みの見直しは指標の算出方法の話であり、個別の農家価格を直接動かす仕組みでもない。
- 詳細解説: この「国際価格と農家の受け取りのずれ」は、生産者の所得問題（05-04）の出発点でもある。国際価格は需給と金融市場の見通しで決まり、生産コストから積み上げて決まる価格ではない。さらに国によっては協同組合や公的機関が国内基準価格を公表する（例: コロンビア FNC の国内基準価格）など、伝達の途中には制度的なフィルターも入る。価格ニュースを読むときは「どの層の、どの通貨建ての価格か」を確認するのが読み方の基本である。
- 出典: エントリー 05-02（価格の層構造、ICO 規則 ICC-105-17、ICE 契約仕様はカタログ02で確認）／ エントリー 05-02

## Q-03-11-02
- id: Q-03-11-02
- entry_id: 03-11 / subtheme_id: 03-11 / difficulty: 2 / fact_type: fact
- 問題文: 欠点豆の判定項目のひとつ「クエーカー」について、正しいのはどれか。
- 選択肢:
  1. 焙煎しても色づかない未熟豆のことであり、生豆サンプルの欠点数えでは判定せず、焙煎した豆の側で確認する別工程の判定である ★
  2. 生豆の緑色が濃いものを数える、生豆段階の欠点である
  3. 生豆を水に浮かせ、浮いたものを数える判定である
  4. 生豆を割って断面の詰まり具合で判定する、生豆段階の欠点である
- 解説（要点）: クエーカーは「焙煎後に初めて姿を現す」欠点であり、生豆の外観による分類（03-11 の本体）とは工程が異なる。水に浮く軽い豆を数えるのはフローターの判定であり、断面の詰まり具合を見るのは未熟豆そのものの同定ポイントである。どちらも生豆段階の判定で、クエーカーの判定とは工程が異なる。未熟豆が生豆段階で数える欠点であるのに対し、その一部は焙煎後にクエーカーとして改めて問題になる、という二段構えで理解する。
- 詳細解説: 物理的欠点の判定は「どの段階の、どの対象を見るか」で整理できる。未熟豆は生豆の外観（緑がかった銀色で薄く、表面にしわ）で同定される Category 2 の欠点だが、クエーカーの判定対象は焙煎豆である。また水分・サイズ・色も Physical Assessment の記録項目であり、欠点数だけでロットの評価が完結するわけではない。なお、本問は判定の工程の区別を問うもので、相当欠点数の換算率やグレード条件の数値は、原典照合が済むまで本シリーズでは出題しない。

## Q-09-09-02
- id: Q-09-09-02
- entry_id: 09-09 / subtheme_id: 09-09 / difficulty: 2 / fact_type: fact
- 問題文: トライアングルテスト（3点試験法）を、知覚できる差が全くない2製品で行い、評価者30人が全員当てずっぽうで「異なる1点」を選んだとする。このとき正答者数の期待値として正しいのはどれか。
- 選択肢:
  1. 約10人 ★
  2. 約15人
  3. 約5人
  4. 約20人
- 解説（要点）: トライアングルテストの当てずっぽうの正答率は1/3であり、独立した判断が n 件あれば正答数は二項分布 B(n, 1/3) に従う。期待値は 30 × 1/3 = 10人。正答率を1/2（デュオ・トリオや2点試験法の偶然確率）と取り違えると15人という値になるが、トライアングルテストの偶然確率は1/3である。判定では、この期待値ちょうどではなく、観測した正答数以上の正答が偶然に得られる確率（上側確率）が有意水準以下になるかどうかで「偶然だけでは説明しにくい偏り」を判断する。
- 詳細解説: 期待値の計算は出発点にすぎず、実際に必要な評価者数は、検出したい最小の差（真に識別できる人の割合 pd）と検出力から事前に決める。単純な推測補正モデルでは期待正答率は pc = 1/3 + (2/3)pd と表せ、pd が小さいほど期待正答率は1/3に近づき、必要な独立判断数は大きくなる。「人数に万能の値は置かない」のが方法論の原則であり、途中で結果を見て人数を足す運用は誤判定の確率を変えてしまうため行わない。

## Q-09-09-03
- id: Q-09-09-03
- entry_id: 09-09 / subtheme_id: 09-09 / difficulty: 2 / fact_type: fact
- 問題文: ある官能試験では、最初に基準試料 R を提示し、続いてコード化した2点を提示して、R と同じものを選ばせた。この方法の名称と、当てずっぽうの正答率の組み合わせとして正しいのはどれか。
- 選択肢:
  1. デュオ・トリオ法（1対2点試験法）／ 1/2 ★
  2. トライアングルテスト（3点試験法）／ 1/3
  3. トライアングルテスト（3点試験法）／ 1/2
  4. 2点試験法 ／ 1/3
- 解説（要点）: 基準試料を先に提示する形式はデュオ・トリオ法であり、選択は2つの候補から行うため偶然の正答率は1/2になる。トライアングルテストは基準を置かず、2種類の製品から「2点＋1点」を提示して異なる1点を選ばせる方法で、正答率は1/3である。方法の名称と偶然確率の組み合わせを一体で覚える必要がある。方法の名前に「3点」とあっても、提示される試料の数と選択肢の数は別であり、偶然確率は「いくつから選ぶか」で決まる。
- 詳細解説: デュオ・トリオには、一方の製品を基準に固定する constant-reference 方式（通常生産品を基準に工程変更品を比べる品質管理など）と、基準にする製品と提示順を均衡させる balanced-reference 方式がある（ISO 10399:2026）。トライアングルテストより統計的には効率が劣るが、評価者にとって実施しやすく、基準の記憶に依存する点が特徴である。方法の選択は正答率の見かけではなく、問い・基準品の安定性・評価者の負担・必要な統計効率で決める。
