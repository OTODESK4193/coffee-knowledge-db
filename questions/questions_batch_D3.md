## Q-10-01-01
- id: Q-10-01-01
- entry_id: 10-01 / subtheme_id: 10-01 / difficulty: 1 / fact_type: fact
- 問題文: コーヒーの脂質に含まれるジテルペン（カフェストール等）について、抽出方法によるカップへの移行の説明として正しいのはどれか。
- 選択肢:
  1. ペーパーフィルターで抽出すると大部分が紙に留まり、カップへの移行は少ない ★
  2. ペーパーフィルターで抽出すると、脂質成分はすべてカップに移行する
  3. フレンチプレスでは、ジテルペンは金属フィルターにすべて留まる
  4. 抽出方法によって移行量は変わらない
- 解説（要点）: ジテルペンは水に溶けにくく、ペーパーフィルターで抽出すると大部分が紙に留まる。金属フィルターやフレンチプレス、煮出し式ではカップに移行しやすい。「豆に含まれる量」と「実際に摂取する量」は抽出方法で変わる、というのが成分の議論の前提である。
- 詳細解説: この区別は健康研究（10-03）を読む際の前提にもなる。同じ豆でも、抽出方法が違えば摂取する成分の量は変わるため、「コーヒーを飲む」という曝露の定義自体が研究ごとに異なりうる。具体的な移行量の数値は査読論文の原典確認が未了のため、本DBでは方向性のみを扱う。
- 出典: Illy, Andrea & Viani, Rinantonio（編）『Espresso Coffee: The Science of Quality』第2版、Academic Press, 2005（ISBN: 9780123703712）系の学術書の整理（エントリー 10-01 の出典 C07-11）

## Q-10-01-02
- id: Q-10-01-02
- entry_id: 10-01 / subtheme_id: 10-01 / difficulty: 2 / fact_type: fact
- 問題文: クロロゲン酸類（カフェ酸とキナ酸のエステルで、ポリフェノールの一群）について、焙煎による変化として正しいのはどれか。
- 選択肢:
  1. 焙煎で分解が進み、深煎りほど減る。一部はラクトン等に変わり苦味に関与する ★
  2. 焙煎ではほとんど変化せず、深煎りでも生豆と同じ量が残る
  3. 焙煎によって新たに生成され、深煎りほど増える
  4. 焙煎の初期にすべて分解し、焙煎豆には一切残らない
- 解説（要点）: クロロゲン酸類は熱に安定なカフェインとは対照的に、焙煎で分解が進む成分である。生豆ではアラビカよりカネフォーラに多いことも知られている。なお「抗酸化成分が含まれる」ことと健康効果は別の話であり、効果の評価は 10-03 のエビデンス整理に従う。
- 詳細解説: 焙煎による成分変化の方向は成分ごとに異なる。カフェインは熱に比較的安定で大きくは減らず、ショ糖やアミノ酸はほぼ分解して香りと色の生成（メイラード反応等）に使われ、トリゴネリンは分解して香気成分やニコチン酸（ビタミンB3の一形態）関連物質を生じる。成分レンジの数値自体は出典付きの範囲で 02-05／10-01 の表で管理し、単一の代表値には固定しない。
- 出典: Farah, Adriana「Coffee Constituents」2012（学術書章。02-05 と同一原典、エントリー 10-01 の出典）
- 関連: Q-10-01-01, Q-10-02-01

## Q-10-02-01
- id: Q-10-02-01
- entry_id: 10-02 / subtheme_id: 10-02 / difficulty: 1 / fact_type: fact
- 問題文: カフェインが眠気を抑える主作用の仕組みとして正しいのはどれか。
- 選択肢:
  1. 脳のアデノシン受容体（A1 および A2A）を遮断し、眠気の信号を感じにくくする ★
  2. アデノシンが体内で生成されること自体を止める
  3. 脳内で覚醒をもたらす物質を新たに合成する
  4. 血糖値を上げることで覚醒を促す
- 解説（要点）: アデノシンは覚醒が長く続くと蓄積して眠気を促す物質で、カフェインはその受け手（受容体）を塞ぐ。つまりカフェイン自体が覚醒を生み出すのではなく、眠気の信号を遮る、という理解が正確である（Fredholm ら 1999 の総説）。
- 詳細解説: 通常の飲用量で到達する血中濃度では、この受容体遮断が作用の中心であり、それ以外の作用機序（ホスホジエステラーゼ阻害等）ははるかに高い濃度でないと表れないと整理されている。効き方（不安を感じやすい等）の個人差には、アデノシン A2A 受容体の遺伝子（ADORA2A）の多型が関与するとされ、「代謝の速さ」と「感受性」は別の軸である。
- 出典: Fredholm, B. B. et al. のアデノシン受容体拮抗に関する総説, 1999（エントリー 10-02 の出典）／ EFSA カフェインの安全性評価, 2015
- 関連: Q-10-02-02, Q-10-04-01
- メディア: M-10-02-2

## Q-10-02-02
- id: Q-10-02-02
- entry_id: 10-02 / subtheme_id: 10-02 / difficulty: 2 / fact_type: fact
- 問題文: カフェインの体内での代謝について正しいのはどれか。
- 選択肢:
  1. 肝臓の酵素 CYP1A2 が、摂取したカフェインの約95%の代謝を担う ★
  2. カフェインは代謝されず、そのままの形で尿中に排泄される
  3. 代謝は主に腎臓で行われ、酵素は関与しない
  4. CYP1A2 が担うのは全体の1割程度にすぎない
- 解説（要点）: カフェインの代謝の主役は肝臓のシトクロム P450 の一種 CYP1A2 で、主な代謝物はパラキサンチンである（Nehlig 2018）。代謝の速さには大きな個人差があり、喫煙は CYP1A2 を誘導して代謝を速め、妊娠・経口避妊薬の使用・肝疾患等は代謝を遅くする要因として整理されている。
- 詳細解説: CYP1A2 を阻害する薬（例: フルボキサミン）はカフェインの体内滞留を大きく延ばしうる。服薬中の人の判断は一般論で済ませず医療者に委ねるのが原則であり、摂取量の目安は 10-04 で扱う。なお本DBでは、半減期の細部は EFSA 原文の直接照合が済むまで出題対象にしない。
- 出典: Nehlig, A.「Interindividual Differences in Caffeine Metabolism and Factors Driving Caffeine Consumption」Pharmacological Reviews 70(2): 384–411, 2018（DOI: 10.1124/pr.117.014407）
- 関連: Q-10-02-01, Q-10-04-02

## Q-10-03-01
- id: Q-10-03-01
- entry_id: 10-03 / subtheme_id: 10-03 / difficulty: 2 / fact_type: interpretation
- 問題文: Poole らによる BMJ の umbrella review（2017）が、コーヒー摂取は多くのアウトカムで「害より利益と関連する結果が多い」と総括する一方で、「例外」として有害方向の関連を明記したアウトカムの組み合わせはどれか。
- 選択肢:
  1. 妊娠に関連するアウトカム（低出生体重・早産・妊娠喪失）と、女性における骨折リスク ★

  4. 心血管疾患と総死亡

## Q-10-03-02
- id: Q-10-03-02
- entry_id: 10-03 / subtheme_id: 10-03 / difficulty: 2 / fact_type: interpretation
- 問題文: コーヒーと健康の大規模な観察研究を読む際の注意として正しいのはどれか。
- 選択肢:
  1. 観察研究が示すのは「関連」であり、喫煙などの生活習慣（交絡）の影響を受けるため、そのまま因果関係（コーヒーが病気を防ぐ）とは言えない ★
  2. 大規模な観察研究であれば、因果関係が証明されたことになる
  3. メタ解析で多くの研究を束ねれば、交絡の影響は自動的に消える
  4. 関連が報告されれば、効果の担い手である成分を特定できる
- 解説（要点）: コーヒーをよく飲む集団としばしば結びつく生活習慣（喫煙、飲酒、食事、運動、所得等）は結果を歪める。特に喫煙の影響は大きく、調整が不十分な研究では本来ない関連が現れることが知られている。本DBの表現は「〜と関連が報告されている」までに留め、「予防する」「効く」とは書かない。
- 詳細解説: 肺がんについては、喫煙の調整が不十分な研究で高リスクの関連が出ることが知られ、調整の有無で結論が動く代表例である。また、カフェインレスでも似た関連が見られる領域があることは、効果の担い手がカフェインだけではない可能性を示唆するが、特定成分への帰属は証明されていない。
- 出典: Poole, R. et al., BMJ, 2017（umbrella review）／ エントリー 10-03 の「エビデンスの読み方（本DBの統一ルール）」

## Q-10-04-01
- id: Q-10-04-01
- entry_id: 10-04 / subtheme_id: 10-04 / difficulty: 1 / fact_type: fact
- 問題文: EFSA（欧州食品安全機関）の2015年の評価で、健康な成人（妊娠していない人）について「安全性の懸念なし」とされた習慣的なカフェイン摂取量はどれか。
- 選択肢:
  1. 1日400 mgまで ★
  2. 1日100 mgまで
  3. 1日800 mgまで
  4. 1日200 mgまで
- 解説（要点）: EFSA 2015 の整理では、健康な成人の習慣的摂取は1日400 mgまでが「安全性の懸念なし」とされる。EFSA の数値は対象と場面で分かれており、単回摂取では200 mgまで、妊婦・授乳中では習慣的摂取1日200 mgまでが、それぞれ「安全性の懸念なし」の目安とされる。成人の習慣的摂取の400 mgと取り違えないことが要点である。
- 詳細解説: これらの数値は「この量まで飲むべき」という推奨量ではなく、「この量まででは安全性の懸念が認められなかった」という評価の境界である。また本DBでは、カフェイン含有量が浸出条件で大きく変わるため（10-01）、mg を「1日○杯まで」と単純換算することはしない。
- 出典: EFSA（欧州食品安全機関）カフェインの安全性に関する科学的意見書, 2015（エントリー 10-04 の出典 C10-01）

## Q-10-05-01
- id: Q-10-05-01
- entry_id: 10-05 / subtheme_id: 10-05 / difficulty: 2 / fact_type: fact
- 問題文: 米国 FDA の規則（21 CFR 173.255）で、生豆からカフェインを抽出する溶媒としてジクロロメタン（塩化メチレン）を用いた場合に定められた残留上限はどれか。
- 選択肢:
  1. デカフェ焙煎豆およびデカフェ可溶性コーヒー抽出物（インスタント）で 10 ppm（0.001%）以下 ★
  2. デカフェ焙煎豆で 2 mg/kg 以下
  3. 残留は一切認められず、0 ppm でなければならない
  4. 残留の上限は定められていない
- 解説（要点）: EU の指令（2009/32/EC）ではデカフェ焙煎豆の上限が 2 mg/kg とされ、米国の値とは規制体系が異なる。米国の上限は、デカフェ焙煎豆とデカフェ可溶性コーヒー抽出物のいずれも 10 ppm 以下である。これらの上限値は「法的な天井」であり、個々の製品の実測値ではない点に注意する。
- 詳細解説: 溶媒法では、処理後の豆は蒸気処理や乾燥を経て、さらに焙煎の熱が加わる。ジクロロメタンは揮発性が高く、工程と焙煎を通じて大部分は除去される設計であり、規制の上限はこの最終製品段階での残留に対するものである。実際のばく露は、製品ごとの実測残留量と飲用量で決まる。
- 出典: 米国 FDA 規則 21 CFR §173.255「Methylene chloride」（エントリー 10-05 の出典 NEW-FDA-173.255、eCFR 条文で確認）
- 関連: Q-10-05-02, Q-11-01-02
- メディア: M-10-05-1

## Q-10-05-02
- id: Q-10-05-02
- entry_id: 10-05 / subtheme_id: 10-05 / difficulty: 2 / fact_type: fact
- 問題文: EU の抽出溶媒指令（2009/32/EC）で、ジクロロメタンをコーヒーの脱カフェインに使う場合の残留上限（焙煎コーヒー）はどれか。
- 選択肢:
  1. 2 mg/kg 以下 ★
  2. 10 ppm 以下
  3. 20 mg/kg 以下
  4. 5 mg/kg 以下
- 解説（要点）: 同じ指令の中でも値は対象ごとに分かれており、茶では 5 mg/kg、酢酸メチルを脱カフェインに使う場合は 20 mg/kg（コーヒーまたは茶）と定められる。また米国の規制値（10 ppm）は別の体系の値である。数値の違いは規制体系の違いであり、そのまま「どちらが何倍安全か」という比較にはならない。
- 詳細解説: 水法や超臨界CO2法は有機溶媒を使わない（または食品として扱われる CO2 を使う）ため、残留溶媒という論点自体が生じない。本DBでは「デカフェは危険／完全に安全」という二分法は採らず、「方式によって論点が異なり、溶媒法については残留上限が法的に定められ、その範囲で流通している」という枠組みで整理する。
- 出典: EU 指令 2009/32/EC（抽出溶媒）Annex I Part II（エントリー 10-05 の出典 NEW-EU-2009-32、EUR-Lex で確認）

## Q-11-01-01
- id: Q-11-01-01
- entry_id: 11-01 / subtheme_id: 11-01 / difficulty: 1 / fact_type: fact
- 問題文: デカフェの水法（Swiss Water Process）の仕組みとして正しいのはどれか。
- 選択肢:
  1. カフェインを除いたコーヒー成分で飽和した水（GCE）に豆を浸し、濃度勾配によってカフェインだけが豆から水へ拡散するようにする ★
  2. 有機溶媒を豆に直接接触させてカフェインを溶かし出す
  3. 超臨界状態の二酸化炭素を循環させてカフェインを溶かし出す
  4. 豆を焙煎した後に水で洗い、カフェインを洗い落とす
- 解説（要点）: 脱カフェインの方式は豆の扱い方で分かれる。有機溶媒を豆に直接接触させるのは溶媒法（直接法）、超臨界状態の二酸化炭素を循環させるのは超臨界CO2法であり、いずれも水と GCE を使う水法とは仕組みが異なる。水法では、生豆を熱水に浸して得た水を活性炭フィルターに通し、カフェインだけを吸着除去したものが GCE（Green Coffee Extract）になる。本処理の豆を GCE に浸すと、他の成分は既に飽和しているため出ていきにくく、カフェインだけが拡散する。なお脱カフェインは全方式とも焙煎前の生豆に対して行う。
- 詳細解説: 商標権者の公式説明では「99.9%カフェインフリー」が同社の基準による主張として示される。本DBではこれを一般的なデカフェの定義値として流用せず、同社基準の数値として明記して扱う。残留溶媒の規制など安全性の論点は 10-05 で扱う。

- 問題文: デカフェの溶媒法のうち「間接法」の説明として正しいのはどれか。
- 選択肢:
  1. 生豆を熱水に浸してカフェインを含む成分を水に移し、その水を豆から離れた場所で溶媒と接触させてカフェインだけを除き、成分を含んだ水を豆に戻して再吸収させる ★

  3. 水と活性炭フィルターだけでカフェインを除く
  4. 溶媒に浸した豆を、溶媒が残ったまま焙煎する

- 選択肢:
  1. 濃縮液を凍結させ、真空下で氷を昇華（液体を経ずに蒸発）させて乾燥させる。低温で乾燥するため香りの保持に有利とされ、角のある顆粒状の製品になる ★

  3. 抽出液を遠心分離して固形分だけを取り出す

- 詳細解説: 需要動向調査は、量ではなく飲む人の行動（杯数・飲用率）を測る調査であり、生豆ベースの量を測る需給表（13-01）とは別物である。量の側でも、国内消費量（生豆換算）は2018年470,212 t から2024年400,218 t へ緩やかに減っており（AJCA 需給表）、「量の成熟」が日本市場の特性とされる。

## Q-13-04-02
- id: Q-13-04-02
- entry_id: 13-04 / subtheme_id: 13-04 / difficulty: 3 / fact_type: fact
- 問題文: AJCA「コーヒー需要動向調査」の結果の読み方について正しいのはどれか。
- 選択肢:
  1. 2022年から調査方法が WEB 調査に変更されたため、それ以前の結果と単純に時系列比較はできないと調査側が注記している ★
  2. 調査方法は開始以来まったく変わっていないため、全年次の値を単純に比較できる
  3. 需要動向調査と需給表は、同じ対象を測る同じ調査である
  4. 需要動向調査は、輸入量と在庫を測る調査である
- 解説（要点）: 需要動向調査は飲む人の行動（杯数・飲用率）を測る調査で、輸入・在庫・消費の「量」を生豆ベースで追う需給表とは測る対象が異なる。調査方法の変更をまたぐ比較は、変化が実態なのか方法の影響なのかを切り分けられないため、調査側の注記に従って単純比較を避ける。
- 詳細解説: 統計の読み方の注意は国際比較でも同じで、ICO の集計（コーヒー年度・60 kg袋）と AJCA 需給表（暦年・トン・生豆ベース）のような基準の違う系列は、換算しても直接はつなげない。本DBでは、数値には必ず「どの調査の・いつの・どの基準の値か」を併記する。
- 出典: 全日本コーヒー協会（AJCA）「コーヒー需要動向調査」（C13-02）／ AJCA「日本のコーヒー需給表」（C13-01）

## Q-00-02-01

- 問題文: ICO／USDA 等の統計・取引で使う標準単位「60 kg袋」は、ポンド（lb）に換算するとおよそいくらか。
- 選択肢:
  1. 132.277 lb ★
  2. 100 lb
  3. 60 lb
  4. 220.462 lb
- 解説（要点）: 1 lb = 453.59237 g（定義値）から計算でき、60 kg = 132.277 lb になる（100万袋 = 60,000 t）。検算として、100 kg を同じ方法で換算すると 220.462 lb になり、換算する質量を取り違えるとこの値に行き着く。なお統計の「袋」は実物の袋の詰め量ではなく、60 kg 換算の単位として使われる点に注意する（実物の輸出袋の重量は産地・年代で異なる）。
- 詳細解説: 統計の建て付けは機関で異なり、AJCA 需給表や FAOSTAT はトン建て、ICO／USDA は袋建てで公表する。比較の際は換算したうえで、集計基準（暦年／コーヒー年度）の違いも併記する。
- 出典: エントリー 00-02（換算表 M-00-02-1。1 lb = 453.59237 g の定義値から計算で検証可能）

## Q-00-03-02
- id: Q-00-03-02
- entry_id: 00-03 / subtheme_id: 00-03 / difficulty: 2 / fact_type: fact
- 問題文: 本DBでコーヒー価格の時系列の正本として使う「Pink Sheet（Commodity Price Data）」を公表している機関はどれか。
- 選択肢:
  1. 世界銀行（World Bank） ★
  2. 国際コーヒー機関（ICO）
  3. 米国農務省海外農業局（USDA FAS）
  4. 国連食糧農業機関（FAO）
- 解説（要点）: Pink Sheet は世界銀行が月刊で公表する商品価格データである。コーヒーについては、アラビカは ICO の "Other Milds" 指標、ロブスタは ICO Robustas 指標が USD/kg 建てで収録される。機関ごとに本DBでの役割は異なり、USDA FAS は生産統計（Coffee: World Markets and Trade 等）、FAO は FAOSTAT の生産統計が主な役割である。
