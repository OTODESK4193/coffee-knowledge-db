## Q-01-03-03
- id: Q-01-03-03
- entry_id: 01-03 / subtheme_id: 01-03 / difficulty: 3 / fact_type: fact
- 問題文: エチオピアとイエメンにおけるコーヒー利用の「古さ」の根拠について、正しい整理はどれか。
- 選択肢:
  1. エチオピアの伝統的利用（ブンナ・カラー、葉の浸出、殻の煎じ液）は民族誌に記録されるが開始年代を文書で確定できず、飲料としての確かな記録は15世紀半ばのイエメン（スーフィーによる利用）に現れる ★
  2. エチオピアの伝統的利用は年代記の文書で9世紀まで遡れるため、イエメンの記録より古いことが文書で確定している
  3. イエメンでの飲用も伝承の域を出ず、文書で確認できるのは16世紀のオスマン帝国以降である
  4. モカはイエメンの主産地であり、栽培地としての記録が飲用の記録より古い
- 解説（要点）: エチオピア側は「伝統的利用があったこと自体は民族誌的に確かだが、年代は未確定」が本DBの扱いであり、エチオピアでの利用年代が文書史料で確定しているという理解は、民族誌の記録と年代を確定できる文書史料の混同である。飲用化の確定記録は Hattox の分析に基づく15世紀半ばのイエメンである。なお、モカは積出港であり、栽培は内陸の高原地帯で行われた（モカ自体ではコーヒーは育たない）。
- 詳細解説: 『Coffee Atlas of Ethiopia』（Kew、2018）は、果肉側の利用が種子を焙煎して飲む利用に先行した可能性を示唆するが、確証はないとする立場である。2024年のゲノム研究も「栽培は15〜16世紀のイエメンで始まった」と整理しており、歴史学側の結論と大筋で整合する。「原産地で古くから使われていた」ことと「飲料になった場所と時期が文書で確定できること」は、別の問いである。
- 出典: Hattox, R.S.『Coffee and Coffeehouses』1985（A-03）／ Davis, A.P. et al.『Coffee Atlas of Ethiopia』Royal Botanic Gardens, Kew, 2018 ／ エントリー 01-03

## Q-01-04-03
- id: Q-01-04-03
- entry_id: 01-04 / subtheme_id: 01-04 / difficulty: 3 / fact_type: fact
- 問題文: 17〜18世紀の栽培伝播の経路と、現在の栽培アラビカの遺伝的系統の対応として正しいのはどれか。
- 選択肢:
  1. ジャワで成功した栽培（1699年に持ち込まれた苗が起源）に由来するのがティピカ系統であり、モカからブルボン島へ直接導入された系統（1715〜1717年）がブルボンの起源である。分子マーカー研究も、栽培アラビカの遺伝的基盤をこの2系統に整理している ★
  2. ジャワ経由の系統がブルボンの起源であり、ブルボン島への直接導入がティピカの起源である
  3. ティピカとブルボンは、どちらもマルティニークを経由して生まれた系統である
  4. ゲイシャはティピカ系統から派生した品種である
- 解説（要点）: ジャワの系統はアムステルダム、パリの王立植物園を経てマルティニークへも広がったが、マルティニークはティピカ系統の拡散先の一つであって、両系統の発祥地ではない。2系統の由来を取り違えないことが要点である。なお、ゲイシャはティピカ／ブルボンのどちらからも派生していないエチオピアの在来系統である（02-03）。
- 詳細解説: 伝播の第2段階は「イエメンの独占」の崩壊である。オランダは1658年にセイロンで栽培を試み、1696年のジャワへの最初の苗は失われたが、1699年に持ち込まれた苗が成功してオランダ領東インドのコーヒーの祖先となり、後のティピカ系統の幹となった。他方、フランス東インド会社は1715〜1717年にモカから直接ブルボン島（現レユニオン）へ導入し、こちらがブルボン系統の起源となった。文書記録による2つの導入経路と、遺伝学が示す2つの基盤が対応する点が、この時代の伝播史の骨格である。
- 出典: Ukers, W.H.『All About Coffee』（A-08）／ 分子マーカー研究（S-16）／ エントリー 01-04、02-03

## Q-02-01-03
- id: Q-02-01-03
- entry_id: 02-01 / subtheme_id: 02-01 / difficulty: 3 / fact_type: fact
- 問題文: 資料Aは「コーヒー属（Coffea）は103種」、資料Bは「124種」と記している。この食い違いの説明として正しいのはどれか。
- 選択肢:
  1. 2006年の総括（Davis et al.）が103種を整理した後、2011年に近縁の旧 Psilanthus 属が Coffea に統合されて124種体制になったためであり、種数は「いつの時点の、どの分類によるか」に依存する ★
  2. 103種のうち21種が絶滅したため、数え直した結果として増えた
  3. 124種という数には、栽培品種（カルティバー）の数が含まれている
  4. どちらか一方が単なる誤りであり、現在の受認種数は130種ちょうどに確定している
- 解説（要点）: 種数の違いは誤記ではなく分類体系の改訂による。旧 Psilanthus 属の約20種が花の形態と分子系統の証拠に基づいて Coffea に移された。なお、Kew の Plants of the World Online（POWO）の受認種数は新種記載と再編で変動を続けており、本DBでは「130種超」と幅を持たせ、固定値として表示しない。
- 詳細解説: 2019年の Kew による絶滅リスク評価は、その時点の124種を対象に、少なくとも60%が絶滅危惧に該当するとした。つまり「124種」は2011年の統合後の体制であり、「103種」はそれ以前の総括の数である。コーヒーに限らず分類の数値は時点表示なしに引用すると食い違いに見える。本DBで種数を引用する際は、必ず時点と分類の出所を添える。
- 出典: Davis, A.P. et al.（2006年の注釈付き総括、S-10）／ 2011年の Psilanthus 統合（Davis et al. の分類研究）／ Kew の絶滅リスク評価（S-11）／ エントリー 02-01
- 関連: Q-02-01-01, Q-02-02-01

## Q-02-03-03
- id: Q-02-03-03
- entry_id: 02-03 / subtheme_id: 02-03 / difficulty: 3 / fact_type: fact
- 問題文: 「ゲイシャ」と表示されたロットについて、WCR（World Coffee Research）品種カタログの整理に照らして言えることはどれか。
- 選択肢:
  1. 表示だけでは、パナマ系ゲイシャ（CATIE に導入番号 T2722 として登録された系統の子孫）と同一の遺伝的系統であることは保証されない。遺伝的に異なる複数の植物タイプが「ゲイシャ」と呼ばれており、パナマ系については区別可能で均一な系統であることが遺伝解析で確認されている ★
  2. 「ゲイシャ」と表示されたものはすべて T2722 の子孫であり、遺伝的に均一である
  3. ゲイシャはティピカ系統の選抜品種なので、「ティピカ」と表示を替えても遺伝的な意味は同じである
  4. Gesha と綴るものは正統な系統ではなく、正しい系統は Geisha と綴るものだけである
- 解説（要点）: Gesha／Geisha の綴りの違いは、エチオピアの言語から英語への確立した音写方法がないために生じた併用であり、系統の真贋を分けるものではない。生殖質の記録に最初に登録されたのが Geisha で、採集地の地名表記に由来するのが Gesha である。なお、ゲイシャはティピカ／ブルボン系統に属さないエチオピア在来系統であり、ティピカの選抜品種とする理解は系統の誤りである。
- 詳細解説: WCR は、ゲイシャをめぐる混乱、すなわち遺伝的に異なる複数のタイプが同じ名で呼ばれ、その多くがエチオピアという地理的起源を共有するにとどまることを明記している。対して T2722 の子孫であるパナマ系ゲイシャは、遺伝的多様性解析で区別可能かつ均一と確認された。これが、オークションや流通の現場で「ゲイシャ」という表示だけでは系統の真正性が問題になる理由である。なお、脚光を浴びた Best of Panama の転機の年には資料間で異説（2004年／2005年）があり、本問では扱っていない。
- 出典: World Coffee Research「Coffee Varieties Catalog」Geisha (Panama) の項（https://varieties.worldcoffeeresearch.org/ ）／ エントリー 02-03

## Q-03-07-03
- id: Q-03-07-03
- entry_id: 03-07 / subtheme_id: 03-07 / difficulty: 3 / fact_type: fact
- 問題文: 輸入担当者が3ロットの書類を見て、「品質の序列は Excelso（コロンビア）＞ AB（ケニア）＞ G2（エチオピア）の順だ」と結論づけた。この読みの問題点として正しいのはどれか。
- 選択肢:
  1. 3つの等級は測っている属性そのものが異なる。コロンビアとケニアの等級は豆の大きさ（スクリーン）の区分であり、エチオピアの G 区分は欠点数による区分であるため、等級名だけから国境を越えた品質の序列は作れない ★
  2. 問題はない。いずれも各国で上から2番目の等級なので、同列の品質とみなせる
  3. エチオピアの G2 は欠点数の区分なので、大きさの区分である他の2つとは逆に、「2」が最も良い等級であることを示す
  4. AB は AA より小さい等級なので、カップ品質も AA より必ず劣る
- 解説（要点）: 等級付け（グレーディング）の基準軸は国ごとに異なり、コロンビアは大きさ、エチオピアは欠点数、ブラジルは欠点とカップ品質の併用、ケニアは大きさ、中米は標高、というように物差しそのものが違う。ケニアの AA／AB は大きさの表示であり、カップ品質はオークション等で別途評価される。見かけの「2番目同士」をそろえても、各国の物差しが違う以上、序列にはならない。
- 詳細解説: 同じ名前でも意味が違う例として、エチオピアの G1 とインドネシアの Grade 1 は同じ物差しではないことが挙げられる。等級を表示・比較する際は、必ず「どの国の・何の基準か」を併記する必要がある。なお、各等級の具体的な数値（スクリーン値や欠点数の上限）は、各国の公式基準文書での原典確認を前提とするため、本問では数値そのものは扱っていない。
- 出典: 輸入業者等のグレード解説資料（本DB情報源カタログ 03-S18）／ FAO ケニア収穫後処理資料（03-S14）／ エントリー 03-07

## Q-03-09-03
- id: Q-03-09-03
- entry_id: 03-09 / subtheme_id: 03-09 / difficulty: 3 / fact_type: fact
- 問題文: 販売業者が「コーファーメンテーション（共発酵）は科学的に実証された技術で、どんなロットでも香りの複雑さを高める」と宣伝している。査読研究の記録に照らした評価として正しいのはどれか。
- 選択肢:
  1. 効果は条件依存である。酵母と乳酸菌の共接種では、完熟果で代謝物生成と香りの複雑さが増したが未熟果では効果が限定的であり、果物添加の研究も単一の小規模な研究が中心であるため、「どんなロットでも」という一般化は研究の記録からは支持されない ★
  2. 宣伝の通りであり、複数の査読研究が、原料の状態を問わず一貫した香りの向上を示している
  3. 査読研究では共発酵やスターター接種の効果は一切確認されていないので、宣伝は全くの虚偽である
  4. 効果が実証されているのは、焙煎後の豆に香料を添加するフレーバードコーヒーについての研究である
- 解説（要点）: 「成分や官能評価が変化すること」と「どんなロットでも必ず良くなること」は別の主張である。スターター接種で有機酸・揮発性成分と官能評価が変化することは複数の査読研究で報告されており、「効果は一切確認されていない」とする見方は言い過ぎである。一方で、効果の出方は菌株・接種方法・原料の状態に依存する。なお、共発酵は発酵段階の操作であり、焙煎後の添加とは工程段階が異なる。
- 詳細解説: 根拠となる研究の性格を押さえることが要点である。共接種の研究（Fermentation、2019）では、同じ処理でも完熟果と未熟果で結果が分かれた。リンゴのピューレと酵母を加えた混合発酵の研究（2025）は、雲南産コーヒーを対象とした単一研究であり、一般化には追加研究が必要とエントリーでも留保されている。また「コーファーメンテーション」の規格定義自体が SCA・ICO の公開資料では確認できておらず、同じ名称でも添加物・工程は生産者ごとに異なる。したがって、宣伝文句の検証では「どの原料で、どの条件で、何が変化したか」まで遡る必要がある。
- 出典: Bressani, A.P. et al., LWT, 2018（DOI: 10.1016/j.lwt.2018.02.029）／ Fermentation 5(3): 67, 2019（DOI: 10.3390/fermentation5030067）／ He et al., 2025（リンゴと酵母の混合発酵）／ エントリー 03-09
- 関連: Q-03-09-01, Q-03-09-02
- メディア: M-03-09-2

## Q-03-11-01
- id: Q-03-11-01
- entry_id: 03-11 / subtheme_id: 03-11 / difficulty: 3 / fact_type: fact
- 問題文: コーヒーの「欠点」をめぐる2つの枠組みの関係について、正しいのはどれか。
- 選択肢:
  1. 生豆の欠点分類（03-11）は豆の外観を見て判定する物理的欠点であり、カッピングの官能的欠点（ポテト／カビ／フェノール、09-05）は抽出液の中で知覚されるものとして判定する。同じ「カビ」でも、豆の表面に見えるカビ損傷と、液体から感じるカビ臭とでは判定する対象が異なる。また、クエーカー（焙煎しても色づかない未熟豆）は生豆ではなく焙煎豆で判定する ★
  2. 物理的欠点と官能的欠点は同じ欠点の別名であり、生豆で数えた欠点の数から、そのロットのカップに出る欠点がそのまま予測できる
  3. クエーカーは、生豆の段階で色づきの悪い豆として判定する
  4. 官能的欠点は生豆の外観から判定するものであり、カッピングによる確認は不要である
- 解説（要点）: 2つの枠組みは関連するが、判定対象が「豆」か「液体」かが違う。生豆側の同定は、国際取引で参照される SCA の生豆欠点分類（2004年体系）の語彙に基づく外観の分類であり、官能的欠点は SCA-104-2024 が扱うカップ内の知覚である。なお、クエーカーは焙煎後に初めて分かるもので、生豆段階で判定できるものではない。
- 詳細解説: この区別は実務の役割分担にも対応する。生豆鑑定（J.C.Q.A. 鑑定士の生豆鑑定、SCA CSP Green Coffee、Evolved Q の Physical Assessment 等）は外観による分類と同定を要求し、カッピングは抽出液の知覚を扱う。なお、SCA 欠点分類の換算率（何粒で相当欠点1とするか）や旧来のスペシャルティグレードの条件といった数値は、SCA 原典（欠点ハンドブック）での照合が未了のため、本問では数値を扱わず枠組みの区別のみを問うている。
- 出典: エントリー 03-11、09-05 ／ SCA Standard 104-2024（官能的欠点の範囲）
- 関連: Q-09-05-01, Q-03-07-02

## Q-04-01-03
- id: Q-04-01-03
- entry_id: 04-01 / subtheme_id: 04-01 / difficulty: 3 / fact_type: fact
- 問題文: ある資料は「コロンビアの2025/26年産の生産量は12.5百万袋」、別の資料は「13.8百万袋」と記している。どちらも USDA FAS『Coffee: World Markets and Trade』を出典としている。この食い違いの説明として正しいのはどれか。
- 選択肢:
  1. 同じ年産についての予測でも、USDA は年2回改訂するため版が異なる（6月版と12月版）。予測値を引用するときは版の併記が必須であり、どちらかが誤記という話ではない ★
  2. 12.5百万袋はアラビカのみの値で、13.8百万袋はロブスタを含む合計である
  3. 13.8百万袋は60kg袋ではない別の単位で数えた値である
  4. 12.5百万袋はコロンビアの輸出量であり、13.8百万袋は生産量である

## Q-05-10-01
- id: Q-05-10-01
- entry_id: 05-10 / subtheme_id: 05-10 / difficulty: 3 / fact_type: fact
- 問題文: CIF 条件で買い付けた生豆が海上輸送中に損傷した。買い手が「運賃も保険料も売り手が支払ったのだから、損傷のリスクも仕向港に着くまで売り手が負うはずだ」と主張した。この理解の問題点はどれか。
- 選択肢:
  1. CIF で売り手が負担するのは運賃と保険料という「費用」であり、貨物の「リスク（危険負担）」は FOB・CFR と同じく、船積港で本船に積み込んだ時点で買い手に移転している。費用の分担点とリスクの分担点がずれるのが CFR／CIF の特徴である ★
  2. 問題はない。CIF ではリスクも仕向港に到着するまで売り手が負う
  3. CIF では保険を売り手が付けるため、損傷があっても買い手は保険による補償を受けられない
  4. リスクは仕向港で荷降ろしが完了した時点で買い手に移転する
- 解説（要点）: インコタームズでは、FOB／CFR／CIF のいずれでも引き渡しとリスク移転は船積港の本船積み込み時点である。CFR と CIF の違いは、仕向港までの運賃を売り手が負担するか（CFR・CIF とも負担）、さらに保険料まで売り手が負担するか（CIF）という費用側の話である。CIF の保険は買い手の貨物を対象に売り手が手配するものであり、買い手が補償を受けられないという理解は誤りである。
- 詳細解説: この「費用とリスクの分担点のずれ」は、価格比較の実務にも直結する。運賃・保険料を含む CIF 価格と、含まない FOB 価格はそのまま比較できないため、価格を比べるときは条件をそろえる必要がある（Fairtrade の最低価格が FOB 建てである等、統計・認証価格の条件表示も同じ考え方である）。なお、コンテナ貨物では港のコンテナヤードで引き渡されることが多く、海上専用条件の代わりに全輸送形態対応の FCA 等が使われる場合がある点も、エントリーの注意点である。

## Q-07-05-03
- id: Q-07-05-03
- entry_id: 07-05 / subtheme_id: 07-05 / difficulty: 3 / fact_type: fact
- 問題文: 粉 20 g で抽出し、抽出液 300 g が得られ、屈折計から求めた TDS は 1.40% だった。この抽出の抽出率（extraction yield）はどれか。
- 選択肢:
  1. 21.0% ★
  2. 1.40%
  3. 15.0%
  4. 9.3%
- 解説（要点）: 抽出率 ＝ TDS（%）× 抽出液の質量（g）÷ 粉の質量（g）＝ 1.40 × 300 ÷ 20 ＝ 21.0%。よくある誤りは、濃度（TDS）の1.40%をそのまま抽出率と答えること、粉量と液量を取り違えること、抽出比率と混同することである。なお、抽出液 ÷ 粉 ＝ 300 ÷ 20 ＝ 15 は抽出比率（15:1）を表す数であり、比率は百分率（%）ではないので、15.0%という値は成り立たない。
- 詳細解説: TDS（濃度）と抽出率は独立に動く別の量であり、粉を多く使えば濃くても抽出率は低くなりうる。この2軸の分離がブリューイング・コントロールチャートの土台で、「濃さの問題は比率で、抽出具合の問題は粒度・時間・湯温・攪拌で直す」という診断の分け方につながる。なお、求めた抽出率が「良い範囲」かどうかは古典チャートの理想域の話であり、その数値は公式原文の直接確認が済むまで本DBでは断定していないため、本問では値の読み方だけを問うている。

## Q-07-08-01
- id: Q-07-08-01
- entry_id: 07-08 / subtheme_id: 07-08 / difficulty: 3 / fact_type: fact
- 問題文: 「マグネシウムを多く含む水ほど抽出が進み、美味しくなる」という主張について、研究の到達点に照らした評価として正しいのはどれか。
- 選択肢:
  1. 根拠とされる Hendon et al.（2014）は計算化学（密度汎関数理論）によるモデル研究であり、抽出実験でも官能試験でもない。しかも Mg2+ は、好ましくないとされる酸（キナ酸・クロロゲン酸）への結合も強いという両面性が論文自身に記されている。その後の実験研究でも、飲料水として通常の濃度範囲で抽出率や酸の量が大きく変わるという証拠は弱く、実証の中心は風味バランスや酸の知覚への影響にある ★
  2. Hendon et al.（2014）は大規模な官能試験によって Mg2+ の優位を実証した
  3. 実験研究により、硬度が高いほど抽出率が比例して上がることが確認されている
  4. 水のミネラルは風味に一切影響しないことが実験で確認されている
- 解説（要点）: Hendon et al. の結果は「結合エネルギーは Mg2+ が最も大きく、Ca2+ が次ぎ、Na+ は水と同程度」という計算上の整理であり、「Mg2+ の多い水が美味しい」という結論ではない。「硬度が高いほど抽出率が比例して上がる」という理解は、ZHAW グループの試験で硬度イオンによる抽出率の変化が屈折計では検証できなかったことと矛盾する。逆に「ミネラルは一切影響しない」というのも言い過ぎで、同試験では風味バランスと香りへの明確な影響は検出されている。
- 詳細解説: Bratthäll, Figueira & Nording（2024、査読論文）は、MgCl2／CaCl2 を抽出前・抽出後に添加して有機酸を測定し、通常の濃度範囲では酸の量の変動は限定的で、10倍濃度で初めて明確な差が出たこと、抽出前添加と抽出後添加で酸量がほぼ同じだったことから、知覚される風味の違いは「抽出そのもの」より「抽出後の液中での相互作用」で生じている可能性があると結論した。つまり現在の到達点は、「水のミネラルが抽出率として測れる量を大きく動かす証拠は弱く、知覚への影響の方が実証の中心」というものである。「硬度が高いほど抽出が進む」と断定して書かないのが本DBの方針である。
- 出典: Hendon, C.H. et al., 2014（陽イオンと抽出に関する計算化学研究）／ Bratthäll, Figueira & Nording, Heliyon 10(5): e26625, 2024 ／ エントリー 07-08
- 関連: Q-07-05-01, Q-09-01-01
- メディア: M-07-08-1

## Q-07-09-01

- 問題文: 焙煎所におけるジアセチル等の α-ジケトン類への職業曝露について、米 NIOSH の施設調査と英国 HSE の知見の整理として正しいのはどれか。

  3. ジアセチルは人工香料を添加した場合にのみ発生し、通常の焙煎では生成しない
  4. これらの曝露基準は食品中の含有量についての基準であり、飲む人の安全を直接示すものである

## Q-09-01-05
- id: Q-09-01-05
- entry_id: 09-01 / subtheme_id: 09-01 / difficulty: 3 / fact_type: fact
- 問題文: SCA Standard 102-2024 に基づく試料調製について、評価の種類との対応として正しいのはどれか。
- 選択肢:
  1. 情緒的評価（Affective）では均一性を見るため1試料につき5カップを試飲し、各カップは容器の縁まで150 mLあたり 8.25 g で調製する。記述的評価（Descriptive）ではバッチブリューによる代替が認められ、その場合のブリュー比率は水1 Lあたりコーヒー55〜60 g である ★
  2. 情緒的評価はバッチブリュー（水1 Lあたり55〜60 g）で行い、記述的評価は必ず5カップのカッピングで行う
  3. 記述的評価でバッチブリューを使う場合も、投量は「150 mLあたり 8.25 g」をそのまま使う
  4. カップ数はどちらの評価でも1試料につき3カップに統一されている
- 解説（要点）: 8.25 g／150 mL はカッピング（浸漬式のカップ調製）の条件、55〜60 g／L は記述的評価でバッチブリューを用いる場合の条件であり、体系が異なる数値を取り替えることはできない。カップ数も、情緒的評価では5カップが必須であるのに対し、記述的評価でカッピング法を使う場合は3〜5カップと幅があり、どちらも同じカップ数に統一されているわけではない。
- 詳細解説: カッピングが均一性（uniformity）を評価できる手法として位置づけられるため、情緒的評価ではカッピングが必須とされ、複数カップのばらつき自体が評価対象になる（均一でないカップは情緒的評価の減点対象にもなる）。一方の記述的評価は属性の記録が目的であり、フィルター抽出またはフレンチプレスによるバッチブリューが認められる。湯温 93 ± 3℃、挽き目（US 20メッシュ通過 70〜75%）等の調製条件は規格本文で直接確認した値である。

## Q-09-02-03
- id: Q-09-02-03
- entry_id: 09-02 / subtheme_id: 09-02 / difficulty: 3 / fact_type: fact
- 問題文: CVA（Coffee Value Assessment）への移行で「何が変わり、何が残ったか」の整理として正しいのはどれか。
- 選択肢:
  1. 変わったのは「100点フォームで80点以上＝スペシャルティ」というラベル中心の運用であり、CVA は評価を Physical／Descriptive／Affective／Extrinsic に分けた。一方で Physical Assessment は2004年の生豆格付け制度に基づいており、欠点の分類語彙と換算の考え方自体は、物理的評価や国際取引の実務参照として現役で残っている ★
  2. CVA への移行で生豆の欠点分類は廃止され、物理的評価（Physical）は行われなくなった
  3. 旧フォームは CVA と併存する現行の公式規格であり、両方のスコアは同じ物差しでそのまま比較できる
  4. CVA では、欠点のあるカップに対する減点の仕組みが廃止された
- 解説（要点）: 2004年プロトコルとフォームは現行規格（102〜105）で「置き換える（supersede）」対象として明記されており、現行の公式規格ではない。情緒的評価（Standard 104-2024）でも、均一でないカップ1つにつき −2点、欠点のあるカップ1つにつき −4点の減点は残っており、減点の仕組みが廃止されたわけではない。
- 詳細解説: 「制度が置き換えられた」という言い方を正確に分解すると、置き換えられたのは単一スコアとラベルによる運用であり、欠点を数える語彙や Physical の記録方法まで一新されたわけではない、というのが要点である。SCA 公式の CVA ページも、Physical Assessment が2004年の生豆格付け制度に基づくことを述べている。旧フォームのスコアが市場で流通し続ける以上、数値を見たときに「どちらの物差しか」を区別する力が必要になる。
- 出典: SCA Coffee Value Assessment 公式ページ（https://sca.coffee/value-assessment ）／ SCA Standard 103-2024・104-2024 ／ エントリー 09-02、03-11

## Q-09-09-01
- id: Q-09-09-01
- entry_id: 09-09 / subtheme_id: 09-09 / difficulty: 3 / fact_type: fact
- 問題文: 焙煎工程の変更の前後でトライアングルテスト（3点試験法）を行い、評価者が統計的に有意に「異なる1点」を当てられた。この結果から言えることの範囲として正しいのはどれか。
- 選択肢:
  1. 2製品の間に知覚できる差があるという証拠は得られたが、どの属性が、どちら向きに、どれだけ違うか、および消費者に好まれるかどうかは、このテストだけでは分からない ★
  2. 異なる1点を当てられたのだから、新工程の方が酸が強くなったと結論できる
  3. 有意に当てられたのだから、新工程の製品の方が消費者に好まれることが示された
  4. トライアングルテストの当てずっぽうの正答率は1/2であり、半数を超えたかどうかで有意性を判断する
- 解説（要点）: トライアングルテストは識別試験であり、得られる答えは「差があるか」だけである。属性と方向は記述的試験、好ましさは対象消費者による嗜好試験の担当であり、提示形式が似ていても問いの種類を取り替えることはできない。なお、3点から異なる1点を選ぶ課題の当てずっぽうの正答率は1/2ではなく1/3である。
- 詳細解説: もう一つの留保として、通常の差の試験で「有意差なし」となっただけでは、2製品が同じ、または実務上十分に似ていることの証明にはならない（検出力が不足すれば、小さくない差でも見逃しうる）。工程変更の前後で「許容できない差がないこと」を確かめたい場合は、類似性の試験として、許容できる差の上限と検出力を先に決めて設計する必要がある。また、比較する製品が比較的均質であることが ISO 各規格の前提であり、コーヒーでは抽出ごとのばらつきが製品差より大きいと、試験は調製差を拾ってしまう。09-01 の調製統制が方法論の一部になるのはこのためである。
- 出典: ISO 4120:2021（トライアングルテスト）／ ISO 6658:2017（官能分析の一般指針）／ エントリー 09-09

## Q-10-02-03
- id: Q-10-02-03
- entry_id: 10-02 / subtheme_id: 10-02 / difficulty: 3 / fact_type: fact
- 問題文: 同じ量のコーヒーを飲んでも、人によってカフェインの「効き方」と「抜け方」が違う理由について、エントリーの整理として正しいのはどれか。
- 選択肢:
  1. 「代謝の速さ」と「感受性」は別の軸である。代謝は主に肝臓の酵素 CYP1A2 が担い（摂取量の約95%）、その活性は喫煙で高まって抜けが速くなり、妊娠や経口避妊薬の使用で低下して長く残る。一方、効き方の感受性には、アデノシン A2A 受容体の遺伝子の違いなどが関与する ★
  2. 違いはすべて耐性で説明でき、代謝の速さに個人差はない
  3. カフェインは体内で代謝されずそのまま排泄されるため、違いは体重による血中濃度の差だけである
  4. 喫煙者は CYP1A2 の働きが抑えられるため、カフェインが長く残る
- 解説（要点）: 喫煙は CYP1A2 を誘導し、カフェインのクリアランスを速める。「喫煙で CYP1A2 の働きが抑えられる」という理解は、誘導と阻害の取り違えである。逆に、妊娠、経口避妊薬、肝疾患等は代謝を遅くする要因として整理され、CYP1A2 を阻害する薬（例: フルボキサミン）は半減期を大きく延ばしうる。健康な成人の半減期は平均約4時間で、およそ2〜8時間の幅がある（EFSA 2015）。
- 詳細解説: 「抜け方」の個人差は、主に代謝酵素の活性の違いとして説明される。背景には CYP1A2 の遺伝的多型があり、その寄与は双生児研究でも示されている（Nehlig 2018）。これに対し、不安を感じやすいといった「効き方」の側には、受容体側（ADORA2A）の違いが関与するとされる。両軸を分けて考えることで、「すぐ眠れなくなる人」と「長く残る人」が必ずしも同じではないことが理解できる。なお、服薬中の人については一般論で判断せず、具体的な判断は医療者に委ねるのが本DBの立場である。
- 出典: Nehlig, A.「Interindividual Differences in Caffeine Metabolism and Factors Driving Caffeine Consumption」Pharmacological Reviews 70(2): 384–411, 2018（DOI: 10.1124/pr.117.014407）／ EFSA カフェインの安全性に関する科学的意見書, 2015 ／ エントリー 10-02
- 関連: Q-10-02-02, Q-10-04-01

## Q-10-04-03
- id: Q-10-04-03
- entry_id: 10-04 / subtheme_id: 10-04 / difficulty: 3 / fact_type: fact
- 問題文: ある記事が「EFSA によればカフェインは1日400 mgまで安全。だから妊婦も400 mgまで問題なく、コーヒーなら1日4杯まで飲んでよい」と書いた。この記事の問題点の組み合わせとして正しいのはどれか。
- 選択肢:
  1. （a）妊婦の目安は400 mgではなく、習慣的摂取で1日200 mgまでであること、（b）EFSA の数値は「この量まで飲むべき」という推奨量ではなく「安全性の懸念なしと評価された境界」であること、（c）カフェイン含有量は浸出条件で大きく変わるため、mg を杯数に単純換算できないこと ★
  2. 問題点は（a）だけで、（b）（c）の理解は正しい
  3. 問題点は（c）だけで、400 mgという数値自体は妊婦にもそのまま当てはまる
  4. EFSA の評価は妊娠していない成人だけについてのもので、妊婦については何の目安も示していない
- 解説（要点）: EFSA（2015）の整理は3つの数値の組み合わせである。妊娠していない健康な成人では単回200 mgまで、習慣的摂取は1日400 mgまで、妊婦・授乳中では習慣的摂取1日200 mgまでが、それぞれ「安全性の懸念なし」とされた。記事は、対象の違う数値を妊婦に流用し（a）、評価の境界を推奨量に読み替え（b）、さらに杯数換算という本DBが採らない単純化を加えた（c）点で、三重に誤っている。なお、妊婦についての目安は示されていないわけではなく、習慣的摂取1日200 mgまでと明示されている。
- 詳細解説: 妊娠中については、観察研究で有害方向の関連が例外的に報告されている領域でもある（10-03 の Poole et al. 2017 が例外として明記）。本DBでは「200 mgまでなら安全」と断定する形では書かず、「公的機関の評価では200 mg/日までで胎児への安全性の懸念なしと整理されている」という出典明記の形に留め、個人の状況に応じた判断は産科の医療者に委ねることを必ず添える。数値を使うときは、「誰についての、単回か習慣的か、どの機関の評価か」をそろえて読むことが前提になる。
- 出典: EFSA（欧州食品安全機関）カフェインの安全性に関する科学的意見書, 2015（エントリー 10-04 の出典 C10-01）／ Poole, R. et al., BMJ, 2017 ／ エントリー 10-04、10-01
