## Q-06-09-01
- id: Q-06-09-01
- entry_id: 06-09 / subtheme_id: 06-09 / difficulty: 1 / fact_type: fact
- 問題文: 抽出の前にカップを予熱する理由として、正しいのはどれか。
- 選択肢:
  1. 冷たいカップに注ぐと、カップの熱容量（材質と壁の厚みで決まる）に液体の熱を奪われて温度が下がるためであり、液量の少ないエスプレッソほど影響が相対的に大きい ★
  2. 冷たいカップではクレマが形成されなくなるため
  3. カップを温めると、抽出液の成分がカップの内面に吸着しなくなるため
  4. 予熱は見た目の演出であり、液体の温度には影響しないため
- 解説（要点）: クレマは抽出側（圧力と粉の状態）で形成されるもので、カップの温度で消えるものではない。また、予熱は単なる演出ではなく、注いだ直後から液体はカップに熱を奪われ、奪われる熱の量はカップの熱容量に比例する。厚手の磁器は予熱に時間がかかる代わりに、いったん温まれば温度を保つ側に働く。
- 詳細解説: 予熱の方法として実務では、カップウォーマーに置く、熱湯を注いで温めてから捨てる、マシンの蒸気で温める等が取られる（06-05 の手順でもカップを温めておくことが step 1 に含まれている）。サービング側で制御できるのは出発点の温度（予熱と抽出温度）と、冷める速度（材質・壁厚・液量・蓋の有無）であり、提供が遅れるほど設計した温度帯から外れていく。
- 出典: エントリー 06-09（サービングの実務 step 2）
- 関連: Q-06-05-01, Q-09-07-01
- メディア: M-06-09-3

## Q-06-09-02
- id: Q-06-09-02
- entry_id: 06-09 / subtheme_id: 06-09 / difficulty: 2 / fact_type: fact
- 問題文: Carvalho & Spence（2018）がブラジルのスペシャルティコーヒーのイベントで276人を対象に行った実験（同一のコーヒーを、口径の狭まるチューリップ型／開いたオープン型／中ほどがくびれたスプリット型の白い陶器カップで提供）で、示された結果はどれか。
- 選択肢:
  1. チューリップ型では香りがより強く評定され、スプリット型では甘さと酸がより強く評定された ★
  2. オープン型では香りが最も強く評定され、形状による甘さ・酸の評定の差は見られなかった
  3. 形状による評定の差が出たのは専門家だけで、一般愛好家では差が見られなかった
  4. スプリット型は専門家・愛好家の双方で最も好ましいと評定された
- 解説（要点）: この研究が示したのは「液体の成分が変わった」のではなく、評価する人の知覚・評定がどう動いたかである。香り・甘さ・酸の評定の差は専門家だけではなく愛好家でも見られた（好ましさの傾向は分かれた）。スプリット型の好ましさについては、愛好家で最も低く、専門家ではその傾向が出なかった。
- 詳細解説: 著者らは、最大径と開口径の比（D-ratio）が大きいチューリップ型で香りの評定が上がった点を、形状の物理的性質との関係として論じている。ただし対象は1銘柄のブラジル産コーヒーとイベント参加者であり、「このカップなら必ずこう感じる」という法則として一般化はできない。同種の研究として、カップ外側の色が期待を作り評価に及ぶこと（Carvalho & Spence 2019）、粗い表面のカップで酸がより強く評定されたこと（Carvalho, Moksunova & Spence 2020）も報告されており、器は中立な容れ物ではないという点が共通している。
- 出典: Carvalho, F. M. & Spence, C. (2018), *Food Quality and Preference*, 68: 315–321（NEW-VESSEL-01）／ エントリー 06-09
- 関連: Q-09-07-02, Q-12-03-01

## Q-09-10-01
- id: Q-09-10-01
- entry_id: 09-10 / subtheme_id: 09-10 / difficulty: 1 / fact_type: fact
- 問題文: 香りの同定（感じた香りに名前を当てる力）の訓練について、査読研究が示してきた知見として正しいのはどれか。
- 選択肢:
  1. 香りに一貫した名前（ラベル）を結びつけて学ぶ訓練が、後の識別やカテゴリ学習の成績を支える ★
  2. 名前を付けずに、できるだけ多くの種類の香りを嗅ぎ続けることが最も効果的である
  3. 同じ香りでも、その都度違う言い方で表現して覚える方がカテゴリとして身につく
  4. 香りの同定は訓練では動かせない生得的な能力である
- 解説（要点）: Rabin（1988）は、対象の香りに名前（ラベル）を結びつける訓練を受けた群が、香りの特徴を記述する訓練や無訓練の群より、その後の識別成績が良かったことを示した。Vanek, Sóskuthy & Majid（2021）は、香りと一貫した言語ラベルを組にして学んだ群が、ラベルの対応が一貫しない群より、香りのカテゴリ学習の成績が有意に良かったことを示した。その都度言い方を変えて覚える方が身につくという考えは、この知見と逆である。
- 詳細解説: 嗅覚は、検出や識別に比べて名前を当てること（同定）が特に難しい感覚であり、日常の身近な香りでも手がかりなしに正しい名前を言い当てられる割合は高くない。訓練の核は「たくさん嗅ぐこと」そのものではなく、香り→名前の結びつけを、一貫したラベルで、フィードバック付きで繰り返すことにある。ラベルは、注意を向ける先と、後から思い出すための手がかりの両方として働くと解釈されている。
- 出典: Rabin, M. D. (1988), *Perception & Psychophysics*, 44(6): 532–540（NEW-RABIN-1988）／ Vanek, N., Sóskuthy, M. & Majid, A. (2021), *Cognition*, 206: 104485（NEW-VANEK-2021）／ エントリー 09-10
- 関連: Q-09-07-01, Q-09-08-01
- メディア: M-09-10-2

## Q-09-10-02
- id: Q-09-10-02
- entry_id: 09-10 / subtheme_id: 09-10 / difficulty: 2 / fact_type: fact
- 問題文: 参照香料キット Le Nez du Café の中心セット（Révélation、36種）が長く用いてきた4分類（Enzymatic／Sugar Browning／Dry Distillation／Aromatic Taints）について、正しいのはどれか。
- 選択肢:
  1. 「香りが似ているか」ではなく「その香りがどこから来たか（生成段階）」で分ける分類である ★
  2. SCA Flavor Wheel と同じく、知覚の類似性で分ける分類である
  3. 香りの強さの順に4段階へ分ける分類である
  4. 36種はコーヒーの香りの全体を尽くしており、これ以外の香りは存在しない
- 解説（要点）: 4分類は、栽培・精製の段階に由来する香り（Enzymatic）、焙煎前期の糖の反応に由来する香り（Sugar Browning）、焙煎後期の繊維質の分解に由来する香り（Dry Distillation）、保管・取扱い・工程の異常で現れる香り（Aromatic Taints）という、生成段階の軸で分けている。知覚の類似性は、Flavor Wheel／WCR Lexicon の側の軸であり、両者は目的が異なる。また、36種は代表的な参照の集合にすぎず、コーヒーの香りの全てを網羅するものではない（WCR Lexicon は110属性を持つ）。
- 詳細解説: この4分類は、旧来の SCA（当時 SCAA）系の香りの枠組み Art of Aroma に対応する整理である。旧 CQI Q Grader の実技「Olfactory Skills」はこの36種を用い、同じ香りのペアを盲検で探すマッチング課題と、指定された瓶の香りを名前で同定する課題を別々に課していた。識別（同じ／違う）と同定（名前）は別の能力であり、訓練もカテゴリ→系統→個別の香りという段階制で進めるのが 09-10 の整理である。
- 出典: Éditions Jean Lenoir『Le Nez du Café』（NEW-LENOIR-NEZ-CAFE）／ エントリー 09-10、09-03
- 関連: Q-09-03-01, Q-09-09-01
- メディア: M-09-10-1

## Q-12-06-01
- id: Q-12-06-01
- entry_id: 12-06 / subtheme_id: 12-06 / difficulty: 1 / fact_type: fact
- 問題文: 注文を受けた際に内容を復唱する主な目的として、正しいのはどれか。
- 選択肢:
  1. 誤注文を「作る前」に客と照合して止めることであり、一致が取れた注文だけを調製に回すため ★
  2. 丁寧な接客であるという印象を客に与えるため
  3. 会計の金額を客に事前に知らせるため
  4. 混雑時に抽出の順序を決めるため
- 解説（要点）: 復唱は丁寧さの演出ではなく、誤注文を調製前に止めるための照合である。複数人分や持ち帰りの区別も含めて客と一致させる。注文時の確認項目（サイズ、温・冷、ミルクの有無と種類、甘さ、カフェインの有無等）の確認漏れは、提供後の作り直しとクレームの最も多い発生源になるため、復唱はその確認と一体の工程である。
- 詳細解説: 接客の基本動作は「迎え入れ→注文を受ける→確認・復唱→調製と提供→会計・見送り」という一連の流れとして設計される。各動作には理由があり、理由が分かれば店舗の事情に合わせて形を変えられる。行列ができる混雑時ほど復唱と確認を省略しないことが原則であり、効率化のために確認工程を削ると、作り直しとクレームで結果的に提供時間が延びる。
- 出典: エントリー 12-06（接客の基本動作「確認・復唱」）
- 関連: Q-12-01-01, Q-12-05-01
- メディア: M-12-06-1

## Q-12-06-02
- id: Q-12-06-02
- entry_id: 12-06 / subtheme_id: 12-06 / difficulty: 2 / fact_type: fact
- 問題文: 客から味に関する訴え（クレーム）があった場合の対応の原則として、正しいのはどれか。
- 選択肢:
  1. その場で原因を断定せず、何が・いつ・どの製品で起きたかの事実確認を行い、対応とともに記録して品質管理に接続する ★
  2. まず抽出の不良と認めて謝罪し、同じ豆で作り直して提供すれば足りる
  3. 味は好みの問題であるため、記録には残さず、その場の対応で完結させる
  4. 豆そのものの問題と判断し、同じロットの販売を直ちに中止する
- 解説（要点）: 訴えの時点では、原因が抽出の不良か、豆そのものか、器具か、客の体調・好みかは切り分け前には分からないため、その場で原因を断定しないことが原則である。抽出の不良と認めたり、豆の問題と判断して販売を止めたりするのは、確認前の断定に当たる。また、記録を残さないのは誤りで、記録（日時、訴えの要点、対象製品とロット、実施した対応）が残ることで、同じロットへの同種の訴えが重なった場合に「単発の好みの相違」か「製品の問題」かを判定する材料になる。
- 詳細解説: 原則は「事実確認→記録→品質管理への接続」であり、感情への対応と事実の処理を分けて考える。味に関する訴えは、同じロット・同じ条件でスタッフが確認する再現確認も行い、その結果も記録に含める。なお異物混入や食中毒が疑われる体調不良の訴えは、味や好みの問題として処理してはならず、食品衛生の担当範囲（12-07）として、対象製品の提供を止めて保管し、責任者へ直ちに報告するのが現場の初動である。
- 出典: エントリー 12-06（クレーム・トラブル対応の原則）
- 関連: Q-12-05-02, Q-09-07-01
- メディア: M-12-06-1

## Q-12-07-01
- id: Q-12-07-01
- entry_id: 12-07 / subtheme_id: 12-07 / difficulty: 1 / fact_type: fact
- 問題文: 日本で生豆を焙煎・粉砕してコーヒー豆（粉）を製造・販売する営業について、食品衛生法上の区分として正しいのはどれか。
- 選択肢:
  1. 営業許可ではなく営業届出の対象であり、届出業種には「コーヒー製造・加工業（飲料の製造を除く）」が独立の業種として明示されている ★
  2. カフェと同じ「飲食店営業」の許可が必要な許可業種である
  3. 製造・販売のいずれについても、許可も届出も不要である
  4. 食品衛生管理者の設置が必須となる許可業種である
- 解説（要点）: 2021年6月に創設された営業届出制度（食品衛生法第57条）の届出業種一覧には「コーヒー製造・加工業（飲料の製造を除く）」が明示され、「コーヒー生豆を焙煎、粉砕して荒びきコーヒー又はインスタントコーヒーを製造又は加工する営業」と定義されている。届出は営業開始前に管轄の保健所へ行う。一方、店内で客に飲食させるカフェは許可業種の「飲食店営業」に当たり（旧「喫茶店営業」は飲食店営業に統合された）ので、届出とは手続きが異なる。なお、食品衛生管理者は食品衛生責任者とは別の制度で、一部の製造業等に求められるものである。
- 詳細解説: 許可と届出の線引きは「公衆衛生に与える影響が著しい営業は許可、それ以外は届出」が骨格である。許可業種は2021年6月1日の改正法施行で従来の34業種から32業種に再編された。届出施設にも、食品衛生責任者の設置と HACCP に沿った衛生管理は求められる。店内で作った焼き菓子を包装して販売する等の展開では菓子製造業など別の許可業種が関係する場合があるため、形態が混ざる場合は開業・変更の前に管轄保健所へ相談することが自治体案内で共通して勧められている。
- 出典: 食品衛生法第55条・第57条／ 届出業種一覧（厚生労働省通知）／ エントリー 12-07
- 関連: Q-12-05-01, Q-10-05-01

## Q-12-07-02
- id: Q-12-07-02
- entry_id: 12-07 / subtheme_id: 12-07 / difficulty: 2 / fact_type: fact
- 問題文: HACCP に沿った衛生管理の制度化と、小規模なカフェに適用される方式の組み合わせとして、正しいのはどれか。
- 選択肢:
  1. 2021年6月1日に完全施行され、小規模な営業者等は業界団体が作成し厚生労働省が内容を確認した手引書を参考にする「HACCPの考え方を取り入れた衛生管理」が基準になる ★
  2. 2021年6月1日に完全施行されたが、小規模な飲食店は当面の間、制度の対象外である
  3. 2018年の法改正と同時に完全施行され、規模にかかわらず全事業者がコーデックスの7原則に基づく計画を自ら作る方式だけが認められる
  4. 完全施行は2024年であり、手引書方式は大規模事業者向けの簡略方式である
- 解説（要点）: HACCP に沿った衛生管理は2018年の食品衛生法改正で制度化され、2020年6月1日に施行、1年間の経過措置を経て2021年6月1日から完全施行された。なお、制度化は2018年の改正だが、完全施行はその年ではなく2021年である。基準は2つに分かれ、大規模事業者等が対象の「HACCPに基づく衛生管理」（コーデックスの7原則に基づき自ら計画を作る方式）と、小規模な営業者等が対象の「HACCPの考え方を取り入れた衛生管理」（手引書方式）であり、厚生労働省の案内では「飲食店営業を行う者その他の食品を調理する営業者」が後者の対象に明示されており、小規模な飲食店が制度の対象外になることはない。
- 詳細解説: 手引書方式では、手引書を参考に、衛生管理計画の作成→必要に応じた手順の設定→実施→記録→定期的な見直し、という流れを回す。飲食店向けには日本食品衛生協会の「HACCPの考え方を取り入れた衛生管理のための手引書（小規模な一般飲食店事業者向け）」（令和6年1月改訂第3版）が公表されている。計画は「一般衛生管理」（どの食品にも共通する基本事項）と「重要管理」（メニューごとの管理点）に分けて作るのが手引書の型であり、記録は実施の証拠として保健所の監視指導の際の確認対象にもなる。なお食品衛生責任者は許可施設・届出施設のいずれにも原則として施設ごとに置く必要がある（食品衛生法第51条）。
- 出典: 食品衛生法第51条／ 厚生労働省「HACCP に沿った衛生管理」の案内／ 日本食品衛生協会 手引書（小規模な一般飲食店事業者向け）／ エントリー 12-07
- 関連: Q-12-05-02, Q-12-07-01
- メディア: M-12-07-1
