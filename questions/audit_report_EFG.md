# 解説・選択肢整合性監査レポート（バッチE・F・G）

作成日: 2026-11-11
対象: `questions_batch_E.md`（10問）、`questions_batch_F.md`（2問）、`questions_batch_G.md`（4問）の全16問
方法: 各問題について、問題文・選択肢4件・正解（★）・解説（要点）・詳細解説を突き合わせ、下記の型で判定した。本レポートでは問題ファイル自体は編集していない。

## 判定の型

- 型1: 解説が★の正解と矛盾する（解説を読むと別の選択肢が正解になる等）
- 型2: 解説が問われている事実とは別の事実を説明し、正解の根拠になっていない
- 型3: 詳細解説・要点が特定の誤答の内容・番号・数値に言及し、その言及がアプリ運用（表示順シャッフル／誤答の再抽選）と衝突する、または実際の選択肢と合っていない
- 型4: 誤答の中に正解と言えてしまうものがある（複数正解）
- 型5: 文面レベルの不整合（用語の揺れ、解説内数値と選択肢の数値の不一致等）

## バッチE

### Q-03-09-01 — 型3
- 証拠（解説（要点）より引用）: 「選択肢2は焙煎後添加のフレーバードコーヒー、3は 03-06 の環境制御型（アナエロビック等）、4はサーマルショックの説明である。」
- 内容自体は実際の選択肢と一致している（2=焙煎後添加、3=環境制御のみ、4=熱水→冷水の急冷）。ただし番号で誤答を特定する書き方になっており、アプリでは表示順がシャッフルされるため、表示上の「選択肢2」と解説の「選択肢2」が食い違う。さらに誤答再抽選でこれらの誤答自体が差し替わった場合、解説が存在しない選択肢を説明することになる。
- 修正の方向性: 番号を外し、内容の言い換えで指す形にする（例: 「焙煎後に香料を添加する方式はフレーバードコーヒーであり、発酵段階の操作ではない」）。または誤答への言及自体を削り、正解の根拠のみで要点を構成する。
- なお正解と解説の内容面の整合（型1・型2・型4）は問題なし。

- 内容面の重大な不整合（型1・型2・型4）は全16問中0件だった。正解の指定と解説の論旨は全問で一致している。
