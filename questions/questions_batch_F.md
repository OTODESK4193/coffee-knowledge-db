## Q-09-01-03
- id: Q-09-01-03
- entry_id: 09-01 / subtheme_id: 09-01 / difficulty: 1 / fact_type: fact
- 問題文: SCA Standard 102-2024に基づくカッピングで、「フレグランス」と「アロマ」の評価対象とタイミングの組み合わせとして正しいのはどれか。
- 選択肢:
  1. フレグランスは抽出前の乾燥した粉の香り、アロマは抽出液の香りをクラストが壊れていない状態と、クラストを割る瞬間に評価する ★
  2. フレグランスは抽出液の香り、アロマは抽出前の乾燥した粉の香りを評価する
  3. フレグランスはクラストを割る瞬間の香り、アロマは冷めた抽出液を口に含んだときの味と香りを評価する
  4. フレグランスとアロマはどちらも抽出前の乾燥した粉の香りを指し、評価するタイミングに違いはない
- 解説（要点）: フレグランスは湯を注ぐ前の乾燥した粉を嗅覚だけで評価する区分である。アロマは抽出後の液の香りで、表面のクラストが壊れていないときと、スプーンで割る瞬間の2時点で評価する。
- 詳細解説: カッピングの手順では、まず抽出前に各カップの粉の香りを評価する（Step 1）。注湯後は、クラストを壊さずに置いた状態で香りを評価し、次にクラストを割り、その際に立ち上る香りを評価する（Step 2）。対象が「粉」か「抽出液」かだけでなく、アロマには評価する状態と瞬間が2つある点が、3つの用語を区別する要点である。
- 出典: SCA Standard 102-2024「Coffee Value Assessment: Sample Preparation and Tasting Mechanics」Specialty Coffee Association, 2024（エントリー 09-01）／ 用語DB glossary_G3（フレグランス、アロマ）

## Q-09-01-04
- id: Q-09-01-04
- entry_id: 09-01 / subtheme_id: 09-01 / difficulty: 2 / fact_type: fact
- 問題文: カッピングにおける「フレーバー」が「アロマ」と異なる点として正しいのはどれか。
- 選択肢:
  1. フレーバーは、口に含んだときに口中の味覚と、口腔から鼻腔後方へ届く嗅覚（レトロネーザル）が統合された複合知覚である ★
  2. フレーバーは、抽出前の乾燥した粉の香りを嗅覚だけで評価する区分である
  3. フレーバーは、舌で感じる基本味だけを指し、嗅覚は含まれない
  4. フレーバーは、抽出液の香りをクラストが壊れていない状態と割る瞬間に評価する区分である
- 解説（要点）: 抽出前の乾燥した粉の香りを嗅覚だけで評価する区分がフレグランス、抽出液の香りをクラストが壊れていない状態と割る瞬間に評価する区分がアロマであり、どちらも口に含む前の評価である。これに対しフレーバーは口中評価の区分で、味覚だけでも、飲む前に鼻で感じる香りだけでもなく、口中の味覚と鼻腔後方の嗅覚が合わさった知覚を指す。
- 詳細解説: アロマは抽出液から立ち上る香りを嗅覚で評価する。一方、フレーバーは液を口に含んだ後に生じる複合知覚であり、舌などの味覚情報と、口の奥から鼻腔後方へ届くレトロネーザルの情報が統合される。09-07でも、飲む前の香りと口中のフレーバーを分け、両方を別々に観察する考え方が示されている。
- 出典: SCA Standard 102-2024「Coffee Value Assessment: Sample Preparation and Tasting Mechanics」Specialty Coffee Association, 2024（エントリー 09-01）／ 用語DB glossary_G3（フレーバー）／ エントリー 09-07（レトロネーザルの記述）
- 関連: Q-09-01-03, Q-09-07-01, Q-09-07-02
- メディア: M-09-01-1, M-09-01-2
