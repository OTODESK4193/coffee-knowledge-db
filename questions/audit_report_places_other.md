# 監査レポート: カテゴリ04以外の「場所・地域を問う問題」の選択肢同種性

作成日: 2026-11-11
対象: `questions_export.json` 全254問のうち、カテゴリ04（産地）を除く213問
観点: 品質規則「誤答は正解と同じ種類・同じ粒度でなければならない」に照らした、場所を問う問題の選択肢の同種性

## 抽出方法

1. 問題文に場所を問う表現（「はどこか」「どの地域」「いつ・どこか」「原産地」「経路」等）があるものを機械抽出
2. カテゴリ04以外の全213問を通読し、答えの核が場所（国・地域・州・県・都市・港・産地・島・伝播経路）になる問題を人手で確定
3. あわせて、場所そのものは問わないが選択肢に地名を含む「組み合わせ型・出来事型」を参考区分として抽出

## 抽出結果の概要

- **主対象（場所そのものを問う問題）: 7件**
- 参考（場所を含む組み合わせ・出来事型）: 5件
- カテゴリ08（カフェ文化）は全問、場所が問題文側に固定され（ウィーン/ロンドン/イタリア/コロンビア等）、場所を問う問題は0件だった。カテゴリ03も同様で、場所を問う問題は0件（Q-03-07-02 はケニアの等級の意味、Q-03-10-02 はバリ島を固定したうえでの研究内容を問う問題）。

## 問題IDごとの判定（主対象）

### Q-01-01-01（01-01）アラビカ種の原産地はどこか → OK

### Q-01-03-01（01-03）最も早い確かな記録が現れる場所と担い手の組み合わせ → 型B
- 選択肢: 15世紀半ばのイエメン ― スーフィー共同体★ / 9世紀のエチオピア ― ヤギ飼い / 16世紀のイスタンブール ― 宮廷 / 17世紀のヴェネツィア ― 商人
- 問題の選択肢: 選択肢3・4。選択肢1・2は国・地域レベル（イエメン/エチオピア）、3・4は都市レベル（イスタンブール/ヴェネツィア）で、**地名の粒度が混在**している。「時代＋場所＋担い手」の組み合わせ形式のため実害は小さいが、規則上は粒度混在に当たる。
- 差し替え候補の方向性: 都市側を「オスマン帝国（イスタンブール）」「イタリア（ヴェネツィア）」のように地域名を併記して粒度をそろえる。

### Q-01-04-02（01-04）「ブルボン」系統の起源となったコーヒー栽培の導入はどれか → OK
- 選択肢はいずれも「年代＋主体＋経路（場所）」の導入イベント文で同種。場所の粒度（島・都市・国）には幅があるが、出来事文としての型が統一されており、場所の種類として破綻はない。

### Q-02-03-01（02-03）ゲイシャがエチオピアからパナマへ渡った経路 → OK
- 選択肢はいずれも「採集地 → 経由地 → 配布先」の経路チェーンで同種・同粒度。
- 参考所見: 選択肢3「ブルボン島 → レユニオン経由」は、ブルボン島がレユニオンの旧名であり同一の島を二重に経由する形になっている。誤答としての誤り方が「地名の取り違え」ではなく「同一地の重複」である点は、作問上の軽微な粗さとして記録する（型判定には含めない）。

### Q-05-01-01（05-01）焙煎豆の輸出の96%以上はどの地域からか → 型B
- 選択肢: 生産国である中南米 / 高所得地域★ / アジアの消費国 / アフリカの生産国
- 問題の選択肢: 選択肢2（正解）。誤答3件は地理区分（中南米/アジア/アフリカ）だが、正解の「高所得地域」は**所得水準による区分であり、地名・地域区分ではない**。問いは「どの地域か」と場所を尋ねているのに、正解だけ区分軸が異なる（地理 vs 所得）。
- 差し替え候補の方向性: 正解を「高所得地域（欧州・北米などの消費地域）」と地理を併記して場所型に寄せるか、誤答側も「低所得の生産地域」のような所得×地理の複合区分にそろえる。根拠データ（ICO『Coffee Development Report 2020』）自体の表現が「高所得地域」であるため、併記方式が現実的。

### Q-11-02-02（11-02）NESCAFÉ が発売されたのはいつ・どこか → OK

- 4件とも「年＋国名」で、国レベルの粒度がそろっている。

### Q-13-03-01（13-03）ドトールコーヒーショップ1号店が開店したのはいつ・どこか → 型B（副次的に型D）
- 選択肢: 1980年4月18日、原宿★ / 1962年、原宿 / 1996年、銀座 / 2013年、東京

## 構造的な備考（ユーザーの体感との関係）

静的データの範囲では、「地域を問う問題に全く関係ない選択肢が混ざっている」ケース（型A）は確認されなかった。アプリでそのように見える主因は、解説監査の際にも問題になった**方式A（誤答の再抽選）のプール設計**にあると考えられる。プールは「同じカテゴリの他問題の正解」から作られる仕様のため、例えばカテゴリ01では書名（Q-01-05-01 の正解『万国管闚』）・人名がらみの文・年を中心とする正解がプールに入り、原産地を問う Q-01-01-01 のような場所問題に再抽選が適用されると、地名でない選択肢が誤答として表示されうる。カテゴリ08・13でも同様の混入が起こりうる構造である。

対策の方向性: 場所を問う問題（および数値・書名など「答えの型」が固有の問題）は誤答再抽選の対象外にするか、プールを「同じ答えの型の正解」に限定すること。本備考はデータ側監査からの構造的指摘であり、アプリ側の現行実装の確認は対象外とする。
