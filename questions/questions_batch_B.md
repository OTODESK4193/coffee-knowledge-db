## 04-01 生産国マスター

### Q-04-01-01
- entry_id: 04-01 / subtheme_id: 04-01 / difficulty: 1 / fact_type: fact
- 問題文: USDA FAS『Coffee: World Markets and Trade』2025年12月版の2025/26年産予測（60kg袋）で、世界最大のコーヒー生産国はどこか。
- 選択肢: 1. ベトナム / 2. ブラジル ★ / 3. コロンビア / 4. エチオピア
- 解説（要点）: ブラジルが63,000千袋で世界1位です。2位ベトナム（30,800千袋）の約2倍の規模があります。
- 詳細解説: 同版の Coffee Summary 表（2025/26 forecast、単位は千袋=60kg袋、生豆換算）では、ブラジルは63,000千袋（アラビカ38,000／ロブスタ25,000）で、2位の約2倍という突出した規模の最大の生産国です。世界計は178.8百万袋とされ、各国のマーケティングイヤーの開始月は国により異なるため「2025/26」は同一暦期間を意味しません。数値は予測（forecast）であり、USDA は年2回改訂します。
- 出典: USDA FAS "Coffee: World Markets and Trade" December 2025（https://apps.fas.usda.gov/psdonline/circulars/coffee.pdf ）
- 関連問題ID: Q-04-02-BR-01, Q-04-01-02 / メディアID: M-04-01-1（生産国マスター表）, M-04-01-2

### Q-04-01-02
- entry_id: 04-01 / subtheme_id: 04-01 / difficulty: 2 / fact_type: fact
- 問題文: USDA 2025年12月版・2025/26予測・60kg袋の内訳で、生産量の約96%がロブスタという国はどこか。
- 選択肢: 1. ベトナム ★ / 2. エチオピア / 3. コロンビア / 4. ブラジル
- 解説（要点）: ベトナムです。30,800千袋のうちロブスタが29,600千袋を占めます。
- 詳細解説: 同版の内訳では、ベトナムはロブスタ29,600千袋／アラビカ1,200千袋で、ロブスタ比率は約96%です。主要生産国には全量がアラビカの国もあれば、二種を併産してアラビカが約6割という国もあり、「どの種の国か」は産地理解の基本軸になります。
- 出典: USDA FAS "Coffee: World Markets and Trade" December 2025（https://apps.fas.usda.gov/psdonline/circulars/coffee.pdf ）

- 解説（要点）: ギリン・バサ（giling basah）です。「湿ったまま脱穀する」という意味を持ち、ウェットハルとも呼ばれます。
- 詳細解説: スマトラ式は、果肉除去と短い発酵・予備乾燥の後、パーチメント（内果皮）を通常より水分が高い段階で脱穀し、生豆をむき出しのまま最終乾燥させる方式です。高温多湿で乾燥が難しい気候への適応として説明されます。なお脱穀時の含水率の数値は資料間で一致していないため、本DBでは数値を確定値として扱っていません。
- 出典: USDA FAS "Coffee: World Markets and Trade" December 2025 ほか USDA インドネシア国別報告系列（精製の詳細は本DB 03-05 と相互参照）

### Q-04-02-ID-02

## 04-03 イルガチェフェ

- entry_id: 04-03-YIRGACHEFFE / subtheme_id: 04-03 / difficulty: 2 / fact_type: fact

- 解説（要点）: ゲデオ・ゾーンです。町イルガチェフェを中心とする地域で、取引上の呼称範囲は町の行政範囲より広く、周辺地区も含みます。
- 詳細解説: イルガチェフェはエチオピア南部のゲデオ・ゾーンに位置する産地呼称です。在来種（heirloom）の混植が中心とされ、主収穫期はエチオピア全体の主収穫期（10〜12月）に含まれます。なお本DBの座標は町の代表点（北緯6.1667／東経38.2000）であり、産地全体の範囲を示すものではありません。また栽培標高帯は原典確認が取れていないため、本DBでは数値を登録していません。
- 出典: USDA GAIN "Coffee Annual" ET2025-0014（2025年6月公表）／座標は GeoDatos（2026-11-11確認）
- 関連問題ID: Q-04-02-ET-01, Q-04-03-YIRGACHEFFE-02 / メディアID: M-04-03-1

### Q-04-03-YIRGACHEFFE-02
- entry_id: 04-03-YIRGACHEFFE / subtheme_id: 04-03 / difficulty: 1 / fact_type: fact
- 問題文: イルガチェフェで代表的とされる精製方法はどれか。
- 選択肢: 1. スマトラ式（ウェットハル） / 2. ウォッシュド（水洗式） ★ / 3. ハニー / 4. パルプドナチュラル
- 解説（要点）: ウォッシングステーションでのウォッシュドが代表的です。ナチュラルも生産されますが、花や柑橘を思わせる軽やかな風味傾向はウォッシュドで語られることが多いものです。
- 詳細解説: イルガチェフェでは水洗式が代表的とされ、ウォッシュドでは花の香り、柑橘、紅茶を思わせる軽やかな質感が傾向として言及されます。これらは取引・専門資料の傾向表現であり測定値ではありません。同じイルガチェフェでも精製法が変われば印象は大きく変わるため、産地名と精製法はセットで理解するのが正確です。
- 出典: USDA GAIN "Coffee Annual" ET2025-0014 ほか産地資料（傾向記述として本DB 04-03 に整理）
- 関連問題ID: Q-04-03-YIRGACHEFFE-01, Q-04-02-ET-02 / メディアID: M-04-03-1

- 選択肢: 1. 粉の質量のうち溶け出した割合 / 2. 抽出液のうちコーヒー由来の溶質が占める割合（濃度） ★ / 3. 湯の総硬度 / 4. 抽出にかかった時間の割合
- 解説（要点）: TDS は抽出液の濃度（質量%）です。抽出率（粉の質量のうち溶け出した割合）とは独立に動く別の量です。
- 詳細解説: TDS が高い＝濃い、低い＝薄いという「強さ」の指標であり、それ自体は未抽出か過抽出かを示しません。実務では屈折計による測定値から求めます。またフィルターコーヒーとエスプレッソでは濃度の桁がまったく異なるため、TDS の数値は抽出方法とセットでなければ意味を持ちません。
- 出典: 本DB 07-05（根拠: Guinard et al., *Journal of Food Science*, 2023、https://doi.org/10.1111/1750-3841.16531 ほか）
- 関連問題ID: Q-07-05-02, Q-09-01-01 / メディアID: M-07-05-1（ブリューイング・コントロールチャート、自作 PN-12）, M-07-05-2

### Q-07-05-02
- entry_id: 07-05 / subtheme_id: 07-05 / difficulty: 2 / fact_type: fact
- 問題文: 抽出率（extraction yield）の計算式として正しいのはどれか。
- 選択肢: 1. TDS（%）× 抽出液の質量（g）÷ 粉の質量（g） ★ / 2. 粉の質量（g）÷ 抽出液の質量（g）× 100 / 3. TDS（%）÷ 抽出時間（分） / 4. 湯温（℃）× 抽出液の質量（g）÷ 粉の質量（g）
- 解説（要点）: 抽出率 ＝ TDS × 抽出液の質量 ÷ 粉の質量、です。粉を多く使えば濃く（TDS 高）ても抽出率は低くなりうる、という分離がブリューイング・コントロールチャートの土台になります。
- 詳細解説: チャートは横軸＝抽出率、縦軸＝TDS の2次元図で、1950年代に Lockhart（Coffee Brewing Institute）が作った枠組みが起源です。1回の抽出を1点として置き、ブリュー比率は原点から放射する直線群として描かれます。これにより「濃さの問題（比率で直す）」と「抽出具合の問題（粒度・時間・湯温・攪拌で直す）」を分けて診断できます。なお古典チャートの「理想域」の数値は公式原文の直接確認が済むまで本DBでは断定していないため、出題していません。
- 出典: Guinard et al. 2023（DOI: https://doi.org/10.1111/1750-3841.16531 ）／本DB 07-05
- 関連問題ID: Q-07-05-01 / メディアID: M-07-05-1, M-07-05-2

## 09-01 カッピング手順

### Q-09-01-01
- entry_id: 09-01 / subtheme_id: 09-01 / difficulty: 2 / fact_type: fact
- 問題文: SCA Standard 102-2024（CVA の試料調製）で定めるカッピングの投量は、容器の縁までの容量150 mLあたり何グラムか。
- 選択肢: 1. 6.00 g / 2. 7.50 g / 3. 8.25 g ★ / 4. 10.00 g
- 解説（要点）: 8.25 g です。豆1粒の重さに由来する ±0.2 g の許容差が認められ、カップごとに豆を別々に量ります。秤の精度は0.1 g以上が必要です。
- 詳細解説: 同規格では、粉砕はカッピング時刻の直前にカップごとに別々に挽き、粒度は米国標準20メッシュふるい（開口850 µm）を70〜75%が通過する粗さです。カッピング容器は強化ガラスまたは陶器で容量200〜350 mL、上部直径75〜90 mm、全カップで同一にします。情緒的評価では1試料につき5カップを試飲します。これらの数値は2026-11-11に規格本文PDFを直接開いて確認したものです。
- 出典: SCA Standard 102-2024 "Sample Preparation and Tasting Mechanics"（CVA 公式ページ: https://sca.coffee/value-assessment ）
- 関連問題ID: Q-09-01-02, Q-09-02-01 / メディアID: M-09-01-1（手順イラスト PN-15）, M-09-01-2

### Q-09-01-02
- entry_id: 09-01 / subtheme_id: 09-01 / difficulty: 2 / fact_type: fact
- 問題文: SCA Standard 102-2024 で、カッピングの抽出に使う湯の温度として定められているのはどれか。
- 選択肢: 1. 85 ± 3℃ / 2. 93 ± 3℃ ★ / 3. 98 ± 2℃ / 4. 100℃（沸騰水）
- 解説（要点）: 93 ± 3℃です。各カップの縁まで注ぎ、表面のクラスト（ドーム）を3〜5分壊さずに置いてから、スプーンでおよそ3回かき混ぜて割ります。
- 詳細解説: 試飲は、抽出液がおよそ70℃まで冷めてから口中評価（リカーリング）を始め、体温以下まで冷める過程で少なくとも3ラウンド繰り返します。試料の焙煎後の休息は8〜24時間、カッピング用焙煎レベルは粉の明度 L* 26〜29（Agtron "Gourmet" スケールで目標値63）と定められます。カッピング用水は同規格 Table 2 の範囲（塩素なし／カルシウム硬度50〜175 ppm CaCO3／アルカリ度40〜70 ppm CaCO3 付近／pH 6〜8）で、これはカッピング専用の規格であり一般の抽出用水の基準とは体系が別です。
- 出典: SCA Standard 102-2024（https://sca.coffee/value-assessment ）

## 09-02 評価制度

### Q-09-02-01
- entry_id: 09-02 / subtheme_id: 09-02 / difficulty: 2 / fact_type: fact
- 問題文: 「100点フォームで80点以上＝スペシャルティ」という運用は、どの制度のものか。
- 選択肢: 1. 現行の CVA（Coffee Value Assessment） / 2. 2004年プロトコル側の旧制度 ★ / 3. SCA Standard 105-2025（外在的評価） / 4. WCR Sensory Lexicon
- 解説（要点）: 旧制度です。2004年プロトコルとフォームは、現行規格（102／103／104）で「置き換える（supersede）」対象として明記されており、現行の公式規格ではありません。
- 詳細解説: 現行の CVA は、Physical（物理的評価）／Descriptive（記述的評価、Standard 103-2024）／Affective（情緒的評価、Standard 104-2024）／Extrinsic（外在的評価、Standard 105-2025）の組み合わせで、単一スコアに頼らない設計です。旧フォームのスコアは現在も市場で流通しうるため、数値を読むときはどちらの物差しかを必ず区別する必要があります。なお旧フォームの定義文の原文照合は本DBの残課題のため、この問題は「旧制度では」という明示のもとでのみ出題しています。
- 出典: SCA Coffee Value Assessment 公式ページ（https://sca.coffee/value-assessment ）／ SCA Standard 103-2024・104-2024
- 関連問題ID: Q-09-02-02, Q-09-01-01 / メディアID: M-09-02-1（評価フォーム比較表）, M-09-02-2

### Q-09-02-02
- entry_id: 09-02 / subtheme_id: 09-02 / difficulty: 3 / fact_type: fact
- 問題文: CVA の情緒的評価（SCA Standard 104-2024）で、8セクションすべてに中立の5を付けた場合（合計40）、換算後のカッピングスコアはどれか。
- 選択肢: 1. 50.00 / 2. 65.00 / 3. 79.00 ★ / 4. 80.00
- 解説（要点）: 79.00 です。「全て中立＝79点」が基準点になる設計で、旧フォームの「80点＝スペシャルティの境界」とは物差しが違います。
- 詳細解説: 情緒的評価は8セクション（Fragrance、Aroma、Flavor、Aftertaste、Acidity、Sweetness、Mouthfeel、Overall）に9点スケール（中心5＝中立）を適用し、換算表でスコア化して0.25点単位に丸めます。換算表の対応値は合計72（全て9）→ 100.00、合計8（全て1）→ 58.00 です。減点は、均一でないカップ1つにつき −2点、欠点のあるカップ1つにつき −4点。ここでの欠点は官能的欠点で、potato／moldy／phenolic の3種に限られます。
- 出典: SCA Standard 104-2024（付録の換算表で直接確認。CVA 公式ページ: https://sca.coffee/value-assessment ）
- 関連問題ID: Q-09-02-01, Q-09-01-02 / メディアID: M-09-02-1, M-09-02-2
