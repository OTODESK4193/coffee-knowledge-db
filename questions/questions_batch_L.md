## Q-04-02-CO-EASY-01
- id: Q-04-02-CO-EASY-01
- entry_id: 04-02-CO / subtheme_id: 04-02 / difficulty: 1 / fact_type: fact
- 問題文: コロンビアで生産されるコーヒーの種について正しいのはどれか。
- 選択肢:
  1. ロブスタのみ
  2. アラビカとロブスタが半々
  3. アラビカのみ ★
  4. リベリカが中心
- 解説（要点）: コロンビアは全量アラビカを生産する国で、USDA の統計でもロブスタの生産は計上されていません。ウォッシュド（水洗式）アラビカの代表的な供給国として知られています。
- 詳細解説: 生産量は USDA FAS『Coffee: World Markets and Trade』2025年12月版の2025/26年産予測で13.8百万袋（60kg袋、生豆換算）で、その内訳も全量アラビカです。精製は発酵槽での発酵と水洗を行うウォッシュドが伝統的に主体で、農家単位の小規模な精製（ベネフィシオ）が基本単位になります。
- 出典: USDA FAS "Coffee: World Markets and Trade" December 2025（04-S1）／ エントリー 04-02-CO
- 関連: Q-04-02-ET-01, Q-04-02-CO-01

## Q-04-02-CO-EASY-02
- id: Q-04-02-CO-EASY-02
- entry_id: 04-02-CO / subtheme_id: 04-02 / difficulty: 1 / fact_type: fact
- 問題文: コロンビアで伝統的に主流となっている精製方法はどれか。
- 選択肢:
  1. ナチュラル（乾燥式）
  2. ウォッシュド（水洗式） ★
  3. スマトラ式（ウェットハル）
  4. ハニープロセス
- 解説（要点）: コロンビアでは、果肉を除いた豆を発酵槽で発酵させてから水で洗うウォッシュド（水洗式）が伝統的に主体です。農家単位の小規模な精製（ベネフィシオ）で行われるのが基本の形です。
- 詳細解説: ウォッシュド主体のアラビカであることは、クリーンな飲み口や明るい酸質といったコロンビアの風味傾向の語られ方とも結びついています。精製の基本単位が農家ごとの小規模なベネフィシオである点も、生産者団体 FNC が品質基準まで担う体制とあわせて、コロンビアの産業構造の特徴の一つです。
- 出典: エントリー 04-02-CO ／ 03-05
- 関連: Q-04-02-CO-EASY-01, Q-03-05-01

## Q-06-02-EASY-01
- id: Q-06-02-EASY-01
- entry_id: 06-02 / subtheme_id: 06-02 / difficulty: 1 / fact_type: fact
- 問題文: ペーパーフィルターを使った透過式のドリップ抽出（フィルター式）の特徴として正しいのはどれか。
- 選択肢:
  1. 粉を湯に浸し、金属メッシュのプランジャーで押し分けて分離する
  2. 粉を入れたペーパーフィルターに湯を注ぎ、重力で抽出液を落とす ★
  3. 粉を湯に浸した後、空気圧でペーパーフィルター越しに押し出す
  4. 粉を湯に浸して抽出し、ペーパーでは漉さないため油分や微粉が液に残る
- 解説（要点）: フィルター式のドリップは、粉を入れたフィルターに湯を注ぎ、重力で抽出液を落とす透過式の抽出です。ペーパーフィルターが油分と微粉を抑えるため、透明感のある液になりやすいのが特徴です。
- 詳細解説: 透過式は浸漬式（06-03）に比べて、微粉と油分がフィルターで抑えられます。その度合いはフィルター素材で変わり、ペーパーが最も油分・微粉を抑え、布（ネル）や金属は油分を通して質感が出やすくなります。ドリッパーの形状（円錐形・台形・フラットボトム）で湯の流れ方は変わりますが、いずれも重力で落とす透過式です。
- 出典: エントリー 06-02 ／ 06-03
- 関連: Q-06-02-02, Q-06-03-01

## Q-06-02-EASY-02
- id: Q-06-02-EASY-02
- entry_id: 06-02 / subtheme_id: 06-02 / difficulty: 1 / fact_type: fact
- 問題文: ドリップ抽出で使うフィルター素材のうち、油分と微粉を最も抑えるのはどれか。
- 選択肢:
  1. 金属フィルター
  2. 布（ネル）フィルター
  3. ペーパーフィルター ★
  4. フィルターを使わない
- 解説（要点）: ペーパーフィルターが油分と微粉を最も抑えます。そのためペーパーで落とした液は透明感が出やすく、布（ネル）や金属のフィルターは油分を通す分、液の質感が出やすくなります。
- 詳細解説: フィルター素材によって油分と微粉の通し方は変わり、ペーパー（最も油分・微粉を抑える）から金属・布（油分を通し質感が出やすい）の方向に整理できます。同じ粉・同じ注ぎ方でも、フィルター素材が違えば抽出液の見た目と口当たりが変わります。
- 出典: エントリー 06-02
- 関連: Q-06-02-EASY-01

## Q-06-02-WAVE-01
- id: Q-06-02-WAVE-01
- entry_id: 06-02 / subtheme_id: 06-02 / difficulty: 1 / fact_type: fact
- 問題文: カリタ ウェーブ（ウェーブフィルターを使うフラットボトムのドリッパー）の特徴として正しいのはどれか。
- 選択肢:
  1. 底に大きな穴が1つ開いた円錐形で、注ぎ方が流量にそのまま反映される
  2. 底に小さな穴が3つ開いた台形で、穴が湯の流れを絞る
  3. ろ過部とフラスコが一体になった円錐形で、厚手の専用ペーパーを使う
  4. 底が平らで、粉の層の厚さが均一になりやすい ★
- 解説（要点）: カリタ ウェーブはフラットボトム（底が平らな形）のドリッパーで、粉の層の厚さが均一になりやすいのが特徴です。台形やフラットボトムは器具側の流量制御が効くため、注ぎ方のばらつきが味に出にくい設計です。
- 詳細解説: ドリッパーの形状は円錐形・台形・フラットボトムに大別でき、底の穴の数や大きさと、内側のリブ（溝）が湯の流れ方を決めます。ウェーブはフラットボトムの代表で、専用の波形フィルター（ウェーブフィルター）を使うことも特徴です。
- 出典: エントリー 06-02
- 関連: Q-06-02-02, Q-06-02-WAVE-02

## Q-06-02-WAVE-02
- id: Q-06-02-WAVE-02
- entry_id: 06-02 / subtheme_id: 06-02 / difficulty: 1 / fact_type: fact
- 問題文: ウェーブフィルター（カリタ ウェーブ専用の波形ペーパーフィルター）の働きとして正しいのはどれか。
- 選択肢:
  1. 専用の波形フィルターのひだが、ドリッパーの壁面との接触を減らす ★
  2. 金属製で繰り返し洗って使え、油分と微粉を通す
  3. 布製で、ペーパーより油分を通して液の質感を変える
  4. 厚手の紙で、フラスコと一体になった器具に合わせて使う
- 解説（要点）: ウェーブフィルターは、その波形のひだによってドリッパーの壁面とフィルターの接触を減らすためのものです。カリタ ウェーブ専用のペーパーフィルターです。
- 詳細解説: ドリッパー内側のリブ（溝）にも、フィルターと本体の間に空気と液の通り道を作り、抽出液が詰まらずに落ちるようにする役割があります。ウェーブやケメックスのように専用フィルターを前提とする器具では、フィルターの入手性も継続使用の条件になります。
- 出典: エントリー 06-02
- 関連: Q-06-02-WAVE-01

## Q-07-02-EASY-01
- id: Q-07-02-EASY-01
- entry_id: 07-02 / subtheme_id: 07-02 / difficulty: 1 / fact_type: fact
- 問題文: 浅煎りのコーヒーの風味の傾向として正しいのはどれか。
- 選択肢:
  1. 苦味と焙煎由来の香りが支配的になり、表面に油がにじむ
  2. 酸の知覚が強く、産地や品種由来の香りが残りやすい ★
  3. 酸と甘さの釣り合いが取りやすい中間の帯である
  4. 酸が弱まり、産地の違いより焙煎の違いが前面に出る
- 解説（要点）: 浅煎り側では酸の知覚が強く、果実や花など産地・品種由来の香りが残りやすくなります。焙煎由来の香ばしさは弱い側です。ただし「浅煎り＝酸っぱい」と一対一に決まるわけではなく、傾向は豆の個体（品種・精製・密度）によっても変わります。
- 詳細解説: 焙煎度による風味は方向として整理でき、深くなるほど苦味と焙煎由来の香りが支配的になって酸は弱まり、表面に油がにじみます。中間の帯は酸と甘さの釣り合いが取りやすく、カッピング用の焙煎がこの帯に置かれるのは、豆そのものの評価に向くためです。
- 出典: エントリー 07-02
- 関連: Q-07-02-02, Q-07-02-EASY-02

## Q-07-02-EASY-02
- id: Q-07-02-EASY-02
- entry_id: 07-02 / subtheme_id: 07-02 / difficulty: 1 / fact_type: fact
- 問題文: 日本で使われる焙煎度の8段階の呼称で、最も浅い段階はどれか。
- 選択肢:
  1. シナモン
  2. ミディアム
  3. ライト ★
  4. ハイ
- 解説（要点）: 日本の8段階の呼称は、浅い方からライト、シナモン、ミディアム、ハイ、シティ、フルシティ、フレンチ、イタリアンの順に並びます。最も浅い段階はライトです。
- 詳細解説: この8段階の並びは日本の焙煎・小売の現場で広く使われる慣用であり、公的規格として一元的に定められたものではありません。各段階が指す色の範囲は体系によってずれるため、豆を焙煎度で比べるときは、呼称だけでなく色の測定値を物差しにする必要があります。
- 出典: エントリー 07-02
- 関連: Q-07-02-EASY-01, Q-07-02-02
