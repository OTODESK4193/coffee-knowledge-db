## Q-01-05-EASY-01
- id: Q-01-05-EASY-01
- entry_id: 01-05 / subtheme_id: 01-05 / difficulty: 1 / fact_type: fact
- 問題文: コーヒーが日本にもたらされた経路について、通説的な整理として正しいのはどれか。
- 選択肢:
  1. ポルトガル人宣教師が布教とともに長崎へ持ち込んだ
  2. 鎖国下で唯一の対欧窓口だった長崎・出島のオランダ人を通じて持ち込まれた ★
  3. ペリー来航の際に黒船の乗組員が横浜へ持ち込んだ
  4. 中国との貿易で神戸に荷揚げされたのが始まりとされる
- 解説（要点）: 日本へのコーヒーの伝来は、鎖国下で唯一の対欧窓口だった長崎・出島のオランダ人によってもたらされたのが始まりで、17世紀末〜18世紀のことと考えられています。当初それを口にできたのは、出島に出入りする通詞や蘭学者などごく少数でした。
- 詳細解説: ただし、正確な最初の一件は特定されておらず、定説はありません。日本人の側の記録では、1782年刊行の『万国管闚』がコーヒーを記述した日本で最初の書籍とされ、江戸期の評価は芳しいものではありませんでした。商品としての輸入が本格化するのは開国後のことです。

- 選択肢:
  1. 果肉（中果皮）
  2. 種子 ★
  3. 外皮（外果皮）
  4. パーチメント（内果皮）

## Q-05-07-EASY-01
- id: Q-05-07-EASY-01
- entry_id: 05-07 / subtheme_id: 05-07 / difficulty: 1 / fact_type: fact
- 問題文: フェアトレード（Fairtrade）の基本的な考え方として正しいのはどれか。
- 選択肢:
  1. 価格はすべて市場に任せ、生産者への支援は行わない
  2. 生産者が受け取る価格を下支えし、適正な対価が生産者に届くようにする ★
  3. 消費国の焙煎業者が生産地の価格を自由に決める仕組みである
  4. 認証を受けた農園だけがコーヒーを輸出できる制度である
- 解説（要点）: フェアトレードは、生産者が適正な対価を受け取れるようにする考え方に基づく制度です。仕組みとしては、生産者が受け取る最低価格が定められ、それに生産者組織が共同で使途を決めるプレミアム（Premium）が上乗せされます。
- 詳細解説: 対象の中心は、小規模生産者組織（協同組合）です。市場価格が最低価格を上回る場合は市場価格が使われ、下回った場合に最低価格が下支えになる「セーフティネット」型の仕組みです。なお、認証があること自体が生産者への支払いの手厚さをそのまま保証するわけではなく、制度ごとの仕組みの違いを見る必要があります。
- 出典: エントリー 05-07
- 関連: Q-05-07-01

## Q-05-03-EASY-01

- 問題文: 2024〜2025年にコーヒーの国際価格が大きく上昇した主因として、FAO が挙げるのはどれか。
- 選択肢:
  1. 世界的な消費量の急増
  2. 投機資金の流入が主因であると断定されている
  3. 主要生産国の天候不良による減産など、供給側の要因 ★

## Q-06-05-EASY-01
- id: Q-06-05-EASY-01

- 問題文: エスプレッソの抽出方法の基本として正しいのはどれか。
- 選択肢:
  1. 細かく挽いた粉に高い圧力の熱湯を短時間で通過させる ★
  2. 粉を湯に数分間浸し、フィルターで漉し分ける
  3. 粉の上に湯を注ぎ、重力でゆっくり落とす
  4. 蒸気の圧力だけで粉に湯を通すのが現在の標準方式である
- 解説（要点）: エスプレッソは、細かく挽いた粉を詰めたポルタフィルターに、高い圧力をかけた熱湯を短時間で通過させて抽出します。高圧・短時間の抽出により、フィルターコーヒーとは全く異なる濃厚な液が得られ、油分が乳化してクレマが形成されます。
- 詳細解説: 圧力の作り方には歴史があり、蒸気圧式（19世紀末〜）、レバー（ピストン）式（1940年代後半〜）、電動ポンプ式（1960年代〜）と変遷してきました。現在の業務用・家庭用の主流は、ポンプで安定した圧力を供給する電動ポンプ式です。
- 出典: エントリー 06-05
- 関連: Q-06-08-02, Q-12-01-02

## Q-06-03-EASY-01

- 問題文: フレンチプレスは、抽出方式の分類ではどれに当たるか。
- 選択肢:
  1. 透過式
  2. 加圧式
  3. 煮出し式
  4. 浸漬式 ★
- 解説（要点）: フレンチプレスは、粉を湯に浸して抽出する浸漬式の器具です。浸漬が終わったら金属メッシュのプランジャーを下げて粉を底へ押し分け、液と分離します。ペーパーフィルターを使わないため、油分と微粉が液に残り、質感の強い抽出になります。
- 詳細解説: 浸漬式は粉と湯が全面で接触するため、透過式に比べて抽出のムラが出にくく、再現性が取りやすい方式です。同じ浸漬式のエアロプレスは、浸漬の後に空気圧でペーパーフィルター越しに押し出す点がフレンチプレスと異なります。
- 出典: エントリー 06-03
- 関連: Q-06-03-01, Q-06-02-EASY-01

## Q-07-02-EASY-03
- id: Q-07-02-EASY-03
- entry_id: 07-02 / subtheme_id: 07-02 / difficulty: 1 / fact_type: fact
- 問題文: 深煎りのコーヒーの風味の傾向として正しいのはどれか。
- 選択肢:
  1. 酸の知覚が強く、産地や品種由来の香りが残りやすい
  2. 苦味と焙煎由来の香りが支配的になり、表面に油がにじむ ★
  3. 酸と甘さの釣り合いが取りやすい中間の帯である
  4. 焙煎由来の香ばしさが弱く、果実や花の香りが前面に出る
- 解説（要点）: 焙煎が深い側では、苦味と焙煎由来の香りが支配的になり、表面に油がにじみます。酸は弱まり、産地の違いより焙煎の違いが前面に出る傾向があります。
- 詳細解説: 焙煎度による風味は方向として整理でき、浅い側では酸の知覚が強く産地・品種由来の香りが残りやすく、中間の帯は酸と甘さの釣り合いが取りやすくなります。ただし傾向は豆の個体（品種・精製・密度）によっても変わるため、焙煎度だけで味が一対一に決まるわけではありません。
- 出典: エントリー 07-02
- 関連: Q-07-02-EASY-01, Q-07-02-01

  4. 生豆の欠点を目で見て取り除く作業
- 解説（要点）: カッピングは、1つのコーヒー試料を複数カップに分け、各カップを独立に挽いて抽出し、条件をそろえて並べて官能評価する方法です。試料の特徴や均一性、品質の印象を比較・評価するために行われます。
- 詳細解説: 現在の SCA 公式規格では、試料の焙煎・計量・粉砕から試飲の手順までが SCA Standard 102-2024（CVA の試料調製）に定められています。評価は、粉の香り（フレグランス）、抽出液の香り（アロマ）、口中での評価（フレーバーや余韻など）の順に進みます。

## Q-09-07-EASY-01

- 問題文: 「テイスティング」と「カッピング」の違いとして正しいのはどれか。
- 選択肢:
  1. カッピングは飲むための一杯を味わう営みで、テイスティングは規格化された評価方法である
  2. テイスティングは飲むための一杯を観察する営みで、カッピングは条件を規格化して試料を比較・評価する方法である ★
  3. 両者は全く同じ作業を指す言葉である
  4. テイスティングの結果は、そのまま公式の品質スコアとして使える

## Q-10-02-EASY-01
- id: Q-10-02-EASY-01
- entry_id: 10-02 / subtheme_id: 10-02 / difficulty: 1 / fact_type: fact
- 問題文: 健康な成人では、摂取したカフェインの血中濃度が半分に減るまでの時間（半減期）は、平均でおよそどれくらいか。
- 選択肢:
  1. およそ30分
  2. およそ4時間 ★
  3. およそ24時間
  4. およそ3日
- 解説（要点）: カフェインの半減期は、健康な成人で平均およそ4時間です。ただし個人差が大きく、およそ2〜8時間の幅があると整理されています（EFSA の2015年の評価に基づく）。夕方に摂ったカフェインが夜の睡眠の時間帯まで体内に残りうるのは、この半減期のためです。
- 詳細解説: カフェインは摂取後速やかに吸収され、血中濃度はおよそ30分〜2時間でピークに達します。代謝の速さには遺伝的な個人差があるほか、喫煙、妊娠、併用薬などの影響も受けるため、半減期は一人ひとり異なります。

## Q-10-02-EASY-02

- 問題文: カフェインと睡眠の関係について、EFSA の評価に基づく説明として正しいのはどれか。
- 選択肢:
  1. 就寝前に摂ったカフェインが、一部の人では入眠や睡眠に影響しうる ★
  2. カフェインを常用していれば、睡眠への影響は完全になくなる
  3. カフェインには眠りを深くする作用がある
  4. カフェインは飲んですぐに体内から抜けるため、睡眠とは無関係である
- 解説（要点）: EFSA の評価では、就寝前に摂取した100 mg程度のカフェインが、一部の人で入眠や睡眠に影響しうることが整理されています。カフェインの半減期を考えると、夕方以降の摂取が夜の睡眠に残ることは自然なことです。
- 詳細解説: カフェインを常用すると、眠気を抑える作用への耐性は一部生じますが、睡眠への影響が完全に消えるわけではない点も研究上指摘されています。本DBでは個人差が大きいため、「何時以降は控える」といった一律の時刻の目安は置いていません。

## Q-11-01-EASY-01
- id: Q-11-01-EASY-01
- entry_id: 11-01 / subtheme_id: 11-01 / difficulty: 1 / fact_type: fact
- 問題文: 「デカフェ（脱カフェイン）」とは、どのような加工を指すか。
- 選択肢:
  1. 焙煎した豆からカフェインを取り除く加工
  2. 抽出したコーヒー液からカフェインを漉し取る加工
  3. 焙煎前の生豆の段階で、カフェインを取り除く加工 ★
  4. カフェインをほとんど含まない品種だけを栽培すること
- 解説（要点）: デカフェ（脱カフェイン）は、焙煎前の生豆の段階でカフェインを選択的に取り除く加工です。豆を水蒸気や温水で膨潤させてカフェインを移動しやすい状態にし、そこからカフェインだけを引き抜くのが、各方式に共通する骨格です。
- 詳細解説: 方式は大きく3系統に分かれます。水のみを使う水法（Swiss Water Process 等）、超臨界状態の二酸化炭素を使う CO2 法、有機溶媒を使う溶媒法です。いずれの方式でも、風味の材料まで一緒に抜けてしまうと味が痩せるため、カフェインへの選択性と風味成分の保持の両立が工夫の中心になります。
- 出典: エントリー 11-01
- 関連: Q-11-01-01, Q-11-01-02

## Q-11-02-EASY-01
- id: Q-11-02-EASY-01
- entry_id: 11-02 / subtheme_id: 11-02 / difficulty: 1 / fact_type: fact
- 問題文: インスタントコーヒーの基本的な作り方として正しいのはどれか。
- 選択肢:
  1. 焙煎豆をそのまま細かく砕いて粉末にする
  2. 抽出したコーヒー液を濃縮し、乾燥させて粉末・顆粒にする ★
  3. 生豆を乾燥させて粉末にする
  4. コーヒー液をそのまま冷凍し、氷の塊として販売する
- 解説（要点）: インスタントコーヒー（可溶性コーヒー）は、抽出したコーヒー液を乾燥させて粉末・顆粒にし、湯で溶かすだけで飲めるようにした製品です。製法の骨格は「抽出 → 濃縮 → 乾燥」です。
- 詳細解説: 乾燥の方式には、濃縮液を熱風の中に霧状に噴霧して瞬間的に乾かすスプレードライと、凍結させて真空下で氷を昇華させるフリーズドライがあります。乾燥の工程で揮発性の香りが失われやすいことが、レギュラーコーヒーとの風味差の主因になります。
- 出典: エントリー 11-02
- 関連: Q-11-02-01, Q-11-04-01
