## Q-06-01-01
- id: Q-06-01-01
- entry_id: 06-01 / subtheme_id: 06-01 / difficulty: 1 / fact_type: fact
- 問題文: バリ（臼刃）式グラインダーのうち「フラット刃」の砕き方として正しいのはどれか。
- 選択肢:
  1. 向かい合う2枚の平たい円盤刃の間を通して砕き、刃同士の間隔（ギャップ）で粒度を決める ★
  2. 円錐形の内刃とリング状の外刃の間で砕く
  3. 容器の底でプロペラ状の刃を高速回転させ、叩き砕く
  4. 複数のローラーで段階的に砕く
- 解説（要点）: フラット刃は、向かい合う2枚の平たい円盤刃の間を通して砕く方式で、粒度は刃同士の間隔（ギャップ）で決まる。同じバリ式のコニカル刃も「刃の間を通して砕く」点は共通し、プロペラ状の刃で叩き砕くブレード式とは原理が根本的に異なる。
- 詳細解説: フラット刃は業務用・家庭用電動に多く、コニカル刃は手挽きミルの多くと家庭用電動に多い。手挽きと電動の違いは駆動方式であり、砕き方の原理はバリ式では共通する。均一な粒度が得られるバリ式は、フィルター抽出からエスプレッソまで全方式に対応でき、粒度が不均一になりやすいブレード式は、細かい粉が過抽出側、粗い粒が未抽出側に働いて味の再現性が低くなる。
- 出典: Illy, Andrea & Viani, Rinantonio（編）『Espresso Coffee: The Science of Quality』第2版、Academic Press, 2005（ISBN: 9780123703712）／ SCA Standard 102-2024「Coffee Value Assessment: Sample Preparation and Tasting Mechanics」Specialty Coffee Association, 2024（https://sca.coffee/value-assessment）

## Q-06-01-02
- id: Q-06-01-02
- entry_id: 06-01 / subtheme_id: 06-01 / difficulty: 2 / fact_type: fact
- 問題文: グラインダー内部に残る前回の粉（リテンション）への対処として正しい手順はどれか。
- 選択肢:
  1. 試料や豆を替えるとき、少量を挽いて押し出す「捨て挽き」をする ★
  2. 内部を水で洗い流す
  3. 刃同士を接触させたまま回して粉を落とす
  4. 粉受けだけを新しいものに交換する
- 解説（要点）: グラインダー内部には前回の粉が残留するため、豆を替える際は少量を挽いて残留粉を押し出す。刃は錆びの原因になるため原則として水洗いせず、細かくしすぎて刃同士が接触すると傷む機種がある点も、手順上の注意である。
- 詳細解説: 残留粉が古い粉として新しい抽出に混ざることは、味の再現性を損なう身近な要因である。この捨て挽きの考え方は家庭用に限らず、カッピングの規格（SCA-102-2024）でも同様の手順が定められている。手入れとしては、ブラシでの清掃と、分解できる機種での定期的な内部清掃が基本になる。
- 出典: SCA Standard 102-2024「Coffee Value Assessment: Sample Preparation and Tasting Mechanics」Specialty Coffee Association, 2024（https://sca.coffee/value-assessment）／ Illy, Andrea & Viani, Rinantonio（編）『Espresso Coffee: The Science of Quality』第2版、Academic Press, 2005（ISBN: 9780123703712）

## Q-06-02-01
- id: Q-06-02-01
- entry_id: 06-02 / subtheme_id: 06-02 / difficulty: 2 / fact_type: fact
- 問題文: ペーパーフィルターの起源について、ドイツ特許商標庁（DPMA）の資料で確認できる事実はどれか。
- 選択肢:
  1. メリタ・ベンツが1908年に得た権利は「特許」ではなく実用新案で、対象はろ過の仕組みだった ★
  2. 1908年に円錐形フィルターの特許が登録された
  3. 1908年に台形ドリッパーの特許が登録された
  4. メリタ・ベンツが権利を得たのは1930年代になってからだった
- 解説（要点）: DPMA の紹介によれば、メリタ・ベンツはコーヒーを漉す器具について1908年6月20日出願・7月8日に実用新案登録を得た。円錐形フィルターに関わる特許（DE 653796 等）は1930年代のものとして区別して記載されており、「1908年に円錐フィルターを発明した」という俗説とはずれる。
- 詳細解説: ここで重要なのは、1908年の権利の対象が「今日の円錐形フィルターそのもの」ではなく、ろ過の仕組みである点である。権利の種類（実用新案か特許か）と対象を正確に押さえることが、器具史を俗説と分けて理解する第一歩になる。
- 出典: ドイツ特許商標庁（DPMA）「Melitta Bentz」紹介ページ（https://dpma.de/english/our_office/publications/ingeniouswomen/melittabentz/index.html）

## Q-06-02-02
- id: Q-06-02-02
- entry_id: 06-02 / subtheme_id: 06-02 / difficulty: 1 / fact_type: fact
- 問題文: 円錐形ドリッパーと台形ドリッパーの設計の違いとして正しいのはどれか。
- 選択肢:
  1. 円錐形は底の大きな穴が流れをあまり制限しないため注湯の影響が大きく、台形は底の小さな穴が律速になって注ぎ方のばらつきが味に出にくい ★
  2. 台形は底に大きな穴が1つ開き、注湯の影響が最も大きい
  3. 円錐形は粉を湯に浸して抽出する浸漬式の器具である
  4. 両者の違いはフィルターの素材だけで、本体の形状は同じである
- 解説（要点）: 円錐形（代表: V60）は湯の流れをドリッパー側があまり制限しないため、注ぎ方がそのまま流量に反映されやすい。台形（カリタの三つ穴式など）は穴が流れの律速になるためドリッパー側で流量が絞られる。これは優劣ではなく、「調整を注湯でやるか、器具に任せるか」という設計差である。
- 詳細解説: ドリッパー内側のリブ（縦の溝）は、フィルターと本体の間に空気と液の通り道を作り、抽出液が詰まらずに落ちるようにするための構造である。フィルター素材でも液は変わり、ペーパーは油分・微粉を最も抑え、金属・布は油分を通して質感が出やすい方向に整理できる。
- 出典: ドイツ特許商標庁（DPMA）「Melitta Bentz」紹介ページ（https://dpma.de/english/our_office/publications/ingeniouswomen/melittabentz/index.html）／ HARIO UK 公式「Hario turns 100」2022（https://www.hario.co.uk/blogs/news/hario-turns-100-celebrating-a-century-of-innovation）／ SCA Standard 102-2024, Specialty Coffee Association, 2024

## Q-06-03-01
- id: Q-06-03-01
- entry_id: 06-03 / subtheme_id: 06-03 / difficulty: 1 / fact_type: fact
- 問題文: フレンチプレスで浸漬が終わった後の正しい操作はどれか。
- 選択肢:
  1. プランジャーをまっすぐゆっくり下げて粉の層を底に寄せる程度に留め、抽出液はすぐにすべて注ぎ分ける ★
  2. プランジャーを力いっぱい押し固めてから注ぐ
  3. プランジャーを下げたまま容器の中で保管し、飲むたびに注ぐ
  4. プランジャーを上下に繰り返し動かしてから注ぐ
- 解説（要点）: 力を入れて押し固めると微粉が金属メッシュをすり抜けやすくなるため、粉の層を寄せる程度に留める。また、容器に残しておくと底の粉で抽出が続くため、抽出液はすべてカップやサーバーに移すのが手順である。
- 詳細解説: フレンチプレスはペーパーフィルターを使わない浸漬式で、油分と微粉が液に残り、質感の強い抽出になる。浸漬式は粉と湯が全面で接触するため透過式より抽出のムラが出にくく、SCA-102-2024 でも記述的評価のバッチブリューとしてフィルター抽出と並んでフレンチプレスが認められている。
- 出典: SCA Standard 102-2024「Coffee Value Assessment: Sample Preparation and Tasting Mechanics」Specialty Coffee Association, 2024（https://sca.coffee/value-assessment）／ AeroPress, Inc. 公式「About AeroPress, Inc. and Alan Adler」（https://aeropress.com/pages/about）

## Q-06-03-02
- id: Q-06-03-02
- entry_id: 06-03 / subtheme_id: 06-03 / difficulty: 2 / fact_type: fact
- 問題文: エアロプレスについて、メーカー公式史で確認できる事実はどれか。
- 選択肢:
  1. 発明家アラン・アドラーが2003年から開発を始め、30以上の試作を経て、2005年11月に Coffee Fest Seattle で発表された ★
  2. 1929年にミラノの設計者が米国で特許を取得した
  3. 1958年にフランスのメーカーが製造したことで普及した
  4. フレンチプレスと同じく、発明者は特定されていない
- 解説（要点）: なお、1929年にミラノの設計者が米国で特許を取得した出来事や、1958年にフランスのメーカーが製造した出来事は、いずれもフレンチプレスの特許史の一断面である。エアロプレスは比較的新しい器具で、家庭用抽出器具の中では例外的に「発明者・発表年・発表の場」が公式史で特定できる。
- 詳細解説: エアロプレスは、浸漬の後に空気圧でペーパーフィルター越しに押し出す器具で、浸漬の均一さとペーパーフィルターの透明感を併せ持つ。チャンバーを逆さに組み立てる倒立法では押し出しの前に浸漬時間を自由に取れるが、ひっくり返す工程で熱湯をこぼす危険への注意が手順に必要である。

## Q-06-04-01
- id: Q-06-04-01
- entry_id: 06-04 / subtheme_id: 06-04 / difficulty: 1 / fact_type: fact
- 問題文: サイフォン（バキュームポット）で、抽出液が下フラスコへ引き戻される仕組みはどれか。
- 選択肢:
  1. 熱源を外すと下フラスコ内の蒸気が冷えて圧力が下がり、抽出液がフィルターを通って引き戻される ★
  2. 内蔵ポンプが抽出液を吸い上げる
  3. 上ロートを傾けて下フラスコへ注ぎ戻す
  4. 粉の重さで抽出液が押し戻される
- 解説（要点）: サイフォンは、水蒸気圧で下フラスコの湯を上ロートへ押し上げ、火を外した後の負圧で抽出液を引き戻す器具である。上昇と下降の両方が「蒸気圧の増減」で説明できる点が、この器具の原理の核心である。
- 詳細解説: 粉は上ロートで湯と接触するため、抽出の接触形態は浸漬に近く、高い湯温で抽出される。温度管理と攪拌が味に直結する技術依存度の高い器具で、ガラス器具と火を組み合わせるため、空焚きの回避やフラスコのヒビの点検といった安全面の注意が前提になる。
- 出典: HARIO UK 公式「Hario turns 100」2022（https://www.hario.co.uk/blogs/news/hario-turns-100-celebrating-a-century-of-innovation）／ Bialetti 公式「Our History」（https://www.bialetti.com/us_en/our-history）

## Q-06-04-02
- id: Q-06-04-02
- entry_id: 06-04 / subtheme_id: 06-04 / difficulty: 2 / fact_type: fact
- 問題文: モカポットの正しい使い方として、エントリーの手順に合うものはどれか。
- 選択肢:
  1. 下ボイラーへの注水は安全弁より下までとし、バスケットの粉はタンピングせず表面をならす ★
  2. 安全弁が水に浸るまでたっぷり注水する
  3. 粉はエスプレッソと同じように強くタンピングする
  4. 抽出液が勢いよく噴き出すよう、強火を保ち続ける
- 解説（要点）: 安全弁を水没させると安全機構が働かないため、注水は弁より下までが原則である。粉を詰めすぎ・圧縮しすぎると過剰な圧力と抽出不良の原因になり、勢いよく噴き出す状態は火が強すぎるサインである。
- 詳細解説: モカポットは水蒸気圧で湯を押し上げる直火式器具で、ビアレッティ社の公式年表では1919年の工房開設と1933年の Moka Express 発売が確認できる。ただし抽出圧力はエスプレッソマシンのポンプ圧とは桁が違い、クレマも原理上は生じないため、「直火エスプレッソ」という通称は販売上の呼称として、エスプレッソの定義とは分けて理解する必要がある。
- 出典: Bialetti 公式「Our History」（https://www.bialetti.com/us_en/our-history）／ HARIO UK 公式「Hario turns 100」2022（https://www.hario.co.uk/blogs/news/hario-turns-100-celebrating-a-century-of-innovation）

## Q-06-05-01
- id: Q-06-05-01
- entry_id: 06-05 / subtheme_id: 06-05 / difficulty: 2 / fact_type: fact
- 問題文: 1884年に特許を取得したアンジェロ・モリオンドの機械について、正しい説明はどれか。
- 選択肢:
  1. 大量の粉にまとめて通湯するバッチ式で、1杯ごとの抽出の仕組みではなかった ★
  2. バネとレバーで高い圧力を作り、クレマを生んだ
  3. 電動ポンプで安定した圧力を供給した
  4. ポルタフィルターで1杯ずつ抽出する仕組みだった
- 解説（要点）: モリオンドの機械は蒸気で「経済的かつ即時に」コーヒーを作る特許として理解すべきもので、現存する実機はなく、シングルショットの仕組みでもなかった。バネとレバーでクレマを生む方式や、電動ポンプで圧力を供給する方式は、いずれも20世紀に入ってからの発展である。
- 詳細解説: エスプレッソマシンの分類は、そのまま圧力の作り方の歴史である。蒸気圧式（19世紀末〜）→ レバー（ピストン）式（1940年代後半、クレマの誕生）→ 電動ポンプ式（1960年代〜）という流れで整理すると、各時代の機械の位置づけがつかめる。
- 出典: Illy, Andrea & Viani, Rinantonio（編）『Espresso Coffee: The Science of Quality』第2版、Academic Press, 2005（ISBN: 9780123703712）

## Q-06-05-02
- id: Q-06-05-02
- entry_id: 06-05 / subtheme_id: 06-05 / difficulty: 2 / fact_type: fact
- 問題文: 熱交換式（HX）のエスプレッソマシンの仕組みとして正しいのはどれか。
- 選択肢:
  1. 1つの蒸気ボイラーの中を抽出湯の管が通り、通過時に加熱される方式で、蒸気と抽出湯を同時に出しやすい ★
  2. 抽出用ボイラーと蒸気用ボイラーを独立させ、それぞれ温度管理する方式である
  3. ポンプを持たず、ボイラーの蒸気圧だけで抽出する方式である
  4. レバーとバネの力だけで圧力を作る方式である
- 解説（要点）: 熱交換式は、抽出用と蒸気用のボイラーを独立させるデュアルボイラー方式とは構造が異なる。熱の安定が抽出の再現性を決めるため、業務用ではグループヘッド自体を熱湯循環で温める構造や、ボイラーを分ける方式が採られる。
- 詳細解説: ポンプにも種類があり、小型で家庭用・小型業務用に多い振動式と、静かで安定した圧力が得られ業務用に多いロータリー（ベーン）式がある。家庭用と業務用の差は、原理ではなく、温度と圧力の安定性、蒸気との同時使用、連続抽出への耐性に現れる。
- 出典: Illy, Andrea & Viani, Rinantonio（編）『Espresso Coffee: The Science of Quality』第2版、Academic Press, 2005（ISBN: 9780123703712）

## Q-06-06-01
- id: Q-06-06-01
- entry_id: 06-06 / subtheme_id: 06-06 / difficulty: 1 / fact_type: fact
- 問題文: トルコ式（ジェズヴェ）の手順として正しいのはどれか。
- 選択肢:
  1. 砂糖は最初に冷水と極細挽きの粉と一緒にジェズヴェに入れ、沸騰直前に火から下ろして泡を各カップに分け入れる ★
  2. 砂糖は飲む直前に、各自がカップの中で加える
  3. 十分に沸騰させ続けてからカップに注ぐ
  4. 抽出後にペーパーフィルターで漉してから注ぐ
- 解説（要点）: トルコ式では砂糖を入れる場合は最初に加えるのが様式で、飲む段階では加えない。泡はトルココーヒーの出来を象徴する要素とされ、沸騰させる前に火から下ろして泡を分け入れる。フィルターで漉さないため、粉はカップの底に沈殿する。
- 詳細解説: ジェズヴェは銅製が伝統的で、胴が下で膨らみ口が一度すぼまる形は、泡を保ちやすく注ぎやすいためのものである。注いだ後は粉が底に沈むまで少し置いてから飲み、底に残る粉の跡を読む占いの習俗は 08-02 で扱う。
- 出典: UNESCO「Turkish coffee culture and tradition」2013（https://ich.unesco.org/en/RL/00645）
- 関連: Q-06-06-02, Q-08-02-01

## Q-06-06-02
- id: Q-06-06-02
- entry_id: 06-06 / subtheme_id: 06-06 / difficulty: 1 / fact_type: fact
- 問題文: ジェベナ（jebena）について正しいのはどれか。
- 選択肢:
  1. エチオピアとエリトリアで使われる黒い土製（または金属製）の壺で、球形の胴と細長い首・注ぎ口を持ち、注ぎの際に粉がカップへ流れ込みにくい構造である ★

- 解説（要点）: ジェベナはエチオピアのコーヒーセレモニーの中核の道具で、生豆の焙煎から粉砕、煮出しまでを担う儀式の器具である。トルコ式のジェズヴェ（銅製で内側が錫引きされた小鍋）とは出自も用途も異なる器具である。

- 解説（要点）: トルココーヒー文化と伝統は代表リスト（2013年）、コロンビアのコーヒー文化景観は世界遺産リスト（文化景観、2011年）の制度であり、ウィーンのカフェハウス文化の登録はそのどちらでもない。俗に「ウィーンのカフェ文化は UNESCO 世界遺産」と言われることが多いが、正確ではなく、これらを同じ「UNESCO 遺産」として並べてはならない。
- 詳細解説: 登録先はオーストリアUNESCO国内委員会が管理する国内インベントリである。国内目録の説明文はカフェハウスを「時間と空間を消費するが、請求書に現れるのはコーヒーだけの場所」と表現しており、制度の格ではなく、この滞在文化そのものが登録の対象である。

## Q-08-05-01
- id: Q-08-05-01
- entry_id: 08-05 / subtheme_id: 08-05 / difficulty: 1 / fact_type: fact
- 問題文: ロンドンのコーヒーハウスが「ペニー・ユニバーシティ」と呼ばれた理由はどれか。
- 選択肢:
  1. 1ペニーで入場して、コーヒーと新聞と会話が得られる場だったから ★
  2. ロンドン大学の付属施設として運営されていたから
  3. コーヒー1杯の価格が法律で1ペニーに統制されていたから
  4. 入場者に学位が授与されていたから
- 解説（要点）: ロンドンのコーヒーハウスは、1ペニーの入場でコーヒーと新聞と会話が得られる場であり、「大学（ユニバーシティ）」に例えられた。17〜18世紀にはニュースと議論が流通する社交と公共の場だった。船荷保険の引受人たちが集まったエドワード・ロイドの店からは保険市場ロイドの原型が生まれ、株式の売買もコーヒーハウスで始まった。つまりロンドンでは、カフェは商業と情報のインフラだった。
- 詳細解説: ただし、コーヒーハウスを「理性的議論の公共圏」の理想型とだけ描く見方には、実際の店はもっと雑多で商業的だったという批判的検討がある（Cowan の研究の主題）。本データベースでは「公共圏の揺籃」という決まり文句を、この留保とセットで提示する。
- 出典: Cowan, Brian『The Social Life of Coffee: The Emergence of the British Coffeehouse』Yale University Press, 2005（ISBN: 9780300106664）

## Q-08-08-02
- id: Q-08-08-02
- entry_id: 08-08 / subtheme_id: 08-08 / difficulty: 1 / fact_type: fact
- 問題文: コロンビアで日常的に飲まれる「ティント（tinto）」について正しいのはどれか。
- 選択肢:
  1. 小さなカップの甘いブラックコーヒーを指し、街では魔法瓶を担いだ露天商から小さなカップで供される ★

  3. ミルクをたっぷり入れた大きめの一杯を指す
