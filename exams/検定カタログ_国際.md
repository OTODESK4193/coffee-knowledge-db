# 検定カタログ（国際）

作成日・確認日: **2026-11-11**（すべての記載はこの日に公式サイト等で確認した内容）
範囲: 国際的に通用するコーヒー資格のうち、主催団体が公式に公開している情報（カリキュラム範囲、試験構成、公開資料の所在）のみを整理する。
**本書に試験問題・教材の問題文は一切転載していない。** 非公式な問題流出・受験体験記は出典に使っていない。

## 最重要の前提（2025年の制度変更）

- **Q Grader は2025年10月1日に運営が CQI（Coffee Quality Institute）から SCA（Specialty Coffee Association）へ移管された。** SCA 公式の Q Grader 案内ページ（education.sca.coffee の FAQ）によれば、同日以降 SCA が CVA（Coffee Value Assessment）に基づく「Evolved Q Grader」を運営し、CQI は Q Grader の運営から外れた。旧来の2004年カッピングフォームに基づく CQI 版 Q Grader（後述「CQI 旧制度」）とは、試験構成が根本的に異なる。本書では現行制度（SCA）と旧制度（CQI）を分けて記載する。
  - 出典: SCA Education「Q Grader Program」FAQ ページ https://education.sca.coffee/q-grader-old （ページ自体は現行概要ページへ移行中。移管の経緯・日付は同ページで確認）
- SCA の資格体系は再編が進行中である。従来の「100ポイントで SCA Coffee Skills Diploma」という旧制度は終了し、現在はコース単位の修了証（Certificate）と、それらを組み合わせる **SCA Skills Diplomas（キャリア別ディプロマ）** が公式サイトの現行案内である（旧制度のポイント制に言及する第三者資料は現行制度と混同しないこと）。

## 6. 「過去問題」「練習問題」についての総括

- **過去問題: SCA・CQI のいずれも、試験問題の公式公開は行っていない**（2026-11-11確認時点で、公式サイト・公式データベースに過去問題集の掲載なし）。
- **公式の練習問題: 問題形式の公式サンプルは確認できなかった。** 代わりに公式が提供しているのは、(a) カリキュラムの学習目標・トピック範囲、(b) Q Grader の受験準備ガイド（試験コンポーネント別の準備方法）、(c) CVA 規格・フォーム等の基盤文書、である。
- 第三者の問題集サイト・体験記は本書の出典に使っていない。それらを使う場合は公式資料ではないことを明示すべきである。
