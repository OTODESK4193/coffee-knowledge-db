# coffee-knowledge-db

コーヒー知識学習アプリのための、出典を明記した知識データベースのバックアップです。
信頼できる情報源（ICO / FAO / 世界銀行 / USDA / UNESCO / SCA等の一次・準一次資料）に基づき、
項目ごとに情報源・検証日・信頼度を記録しています。

## 現在の規模（2026-11-12 時点）

- エントリー: 110件（カテゴリ 00〜13）
- 4択問題: 282問（難易度1: 117 / 2: 130 / 3: 35）
- 用語集: 288語
- 選択肢ごとの解説: 164件（カテゴリ02・03）

## 構成

| パス | 内容 |
|---|---|
| `entries/` | エントリー本文（カテゴリ別Markdown） |
| `questions/` | 問題バッチ（A〜M）、選択肢ごとの解説JSON、監査レポート |
| `glossary/` | 用語集の原データと構築スクリプト |
| `exams/` | 検定・資格の調査カタログと対応マップ |
| `media_assets/` | 自作図解SVG、構造化テーブル、世界地図データ（Natural Earth、パブリックドメイン）、写真のライセンス記録 |
| `database_schema_v2.sql` / `app_schema_extension.sql` | DBスキーマ |
| `update_questions.py` | 問題データの検証・統合スクリプト |
| `questions_export.json` / `glossary_export.json` | アプリ取り込み用エクスポート |
| `app/` | 静的PWA版アプリ本体（素のHTML/CSS/JS、記録は端末内保存）。`app/sync-data.py` で正本からデータを再同期 |
| `sources_catalog_*.md` ほか | 情報源カタログ、調査項目整理、アプリ計画などの設計文書 |

## このリポジトリに含まれないもの

- `coffee_knowledge.db`（SQLite本体）: 上記のスキーマ・原データ・スクリプトから再生成できます
- 写真ファイル（Wikimedia Commons、6枚）: 出典とライセンスは `media_assets/photos_licences.md` に記録があり、再入手できます
- ローカルのバックアップコピー（`.bak*`）: 履歴はこのリポジトリのコミットで代替します

## アプリ

学習アプリ本体（テーマ別クイズ／エンドレス／入門コース／苦手・復習／用語辞書・カード）は
このデータを使って別途提供されています。静的PWA版を検討中です。
