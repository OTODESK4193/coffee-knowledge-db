## 要約

接客・サービスは、抽出技術（12-01〜12-04）と清掃・保全（12-05）の間にある「飲み手に届ける」工程の実務である。制度上の位置づけとして、SCA Coffee Skills Program の Barista Skills Foundation の学習範囲に「接客の基礎」が含まれ（C12-01、検定カタログ_国際で確認）、国内では JBA バリスタライセンスのレベル3が「接客サービス」を含む総合力を認定範囲としている。ただし接客の作法そのものに公的規格はなく、店舗ごとのマニュアルが正本になる領域であるため、本エントリーは特定企業のマニュアルに依拠せず、業態を問わず通用する実務の「型」を **原則と理由のセット** で整理する。本文は、基本動作の流れ（M-12-06-1 の接客フロー表に構造化）、専門店ならではの説明と聞き取り（M-12-06-2）、クレーム対応の原則、店舗運営の入口、の4部構成とする。異物混入等の食品安全に関わる事案の扱いは 12-07（食品衛生）の担当範囲とし、本エントリーでは分担と初動のみを記す。

## 本文

### 接客の基本動作（詳細は M-12-06-1）

接客は一連の流れとして設計する。各動作には「なぜそうするか」の理由があり、理由が分かれば店舗の事情に合わせて形を変えられる。

| 段階 | 動作の型 | 理由 |
|---|---|---|
| 迎え入れ | 来店に気づいた時点で声をかけ、注文の受け方（カウンター注文／席での注文／先会計か等、店の方式）が客に分かるようにする | 方式が分からないことが、専門店で客が最初につまずく点である。待ち時間が発生する場合は、その見込みをこの時点で伝える |
| 注文を受ける | メニュー名だけでなく、サイズ、温・冷、ミルクの有無と種類、甘さ、カフェインの有無（通常／デカフェ）等の選択肢を確認する | 選択肢の確認漏れは、提供後の作り直しとクレームの最も多い発生源になる |
| 確認・復唱 | 受けた注文を復唱し、複数人分や持ち帰りの区別も含めて客と一致させる | 復唱は誤注文を「作る前」に止めるための照合であり、丁寧さの演出ではない。一致が取れた注文だけを調製に回す |
| 調製と提供 | 抽出の順序を管理し、同席者の分はできるだけ揃えて出す。提供が遅れる場合は、待っている客に状況を一言伝える | コーヒーは抽出直後から温度が下がり、知覚される印象が変わっていく飲み物である（09-07）。カップの予熱と提供温度の管理は 06-09 のサービング実務と一体であり、「作る順序」と「冷める速度」の両方を管理するのが提供タイミングの実務である |
| 会計・見送り | 会計の金額と内容を明示し、忘れ物・持ち帰り品の取り違えがないかを確認する | 取り違えは味以前の問題として店の信頼を損なう。最後の接点の確認が、次の来店につながる |

- **「待たせる」こと自体より「見通しが立たない」ことが不満になる**: 行列や抽出の混雑で待ち時間が伸びる場合は、注文を受ける前に見込みを伝える。伝えた見込みがずれる場合も、途中で一度伝える。待ち時間の管理は提供時間の問題であると同時に、情報提供の問題である（後述「店舗運営の入口」）。

### コーヒー専門店ならではの接客

#### 豆・抽出の説明のしかた ― 専門用語を言い換える

- 専門店の説明でありがちな失敗は、生産・焙煎・抽出の内部用語（例: 精製方法の細目、焙煎の進行用語、抽出パラメータの数値）をそのまま客に渡すことである。客が知りたいのは工程の名前ではなく「自分が飲んでどう感じるか」であり、説明は **知覚に翻訳して** 渡す。
- 言い換えの実務は、用語DBの「ひとこと」（専門用語を使わない日常語の言い換え）をそのまま接客に応用する形になる。例: 「浅煎り」は「香りが明るく、酸味が感じやすい煎り方」、「ウォッシュド」は精製名を言う前に「すっきりした味わいになりやすい作り方」という知覚の側から入る。
- **断定の形にしない**: 味は主観であり、産地名や精製名だけで個人の感じ方が保証されるわけではない（味の傾向は 09-04、表現は 09-08 の範囲）。「〜な味です」ではなく「〜な傾向があります」「〜が好きな方に選ばれています」という形が、説明としての正確さと誠実さを保つ。
- 聞かれた範囲を超えて講義をしない。説明の量は客の関心に合わせ、深く知りたい客には産地・精製・焙煎の順に掘り下げる入口を用意する（豆の旅の順序は初心者向け学習パスと同じ構造が使える）。

#### 好みの聞き取り（詳細は M-12-06-2）

好みの聞き取りは、感想を聞くのではなく **選択の軸を聞く** 作業である。実務で使う軸は次のとおり。

| 軸 | 聞き方（例） | 接続 |
|---|---|---|
| 酸味 | 「酸味のあるコーヒーはお好きですか」 | 苦手な客に浅煎り・高酸の豆を勧める事故を防ぐ。酸の質の表現は 09-08 |
| 苦味・焙煎度 | 「しっかり苦いものと、軽いものでは」 | 焙煎度（07-02）と抽出の濃さは別の軸であり、混同して聞かない |
| ミルク | 「ミルク入りとブラックでは」 | ミルク飲料は豆の個性より質感が前面に出る（09-06 のペアリングの考え方も参照） |
| 温・冷と飲む場面 | 「温かいもの／冷たいもの」「食後に」等 | 提供形態と器（06-09）の選択につながる |
| カフェイン | 「デカフェにしますか」 | 次項の配慮と直結する。通常／デカフェの選択肢は最初から提示する |

- 聞き取った軸から、候補は1〜2点に絞って提示する。選択肢を並べすぎると専門店の知識が客の負担になる。外した場合は「どこが違ったか」を聞き直すことが、次の提案の精度を上げる（味の言葉の共有は 09-07 のテイスティングの考え方と共通する）。

#### アレルギー・カフェインへの配慮

- **アレルギー**: ミルク、代替ミルク（大豆等）、ナッツ系のシロップやトッピング等、飲料には複数のアレルゲンになり得る原材料が入る。客から申告や質問があった場合は、原材料表示と店の仕様書で確認して答えるのが原則であり、記憶で「入っていません」と断定しない。器具の共用（同じピッチャー・スプーン）による接触の可能性も含めて確認し、判断できない場合は上位者・責任者に確認する。これは安全に関する事項であり、味の説明とは扱いが異なる。
- **カフェイン**: 妊娠中・服薬中・カフェインに敏感である等の相談には、デカフェ（11-01）を含む選択肢を提示するところまでが店の役割である。摂取量の目安は公的機関の整理（EFSA: 妊婦の習慣的摂取 200 mg/日まで等、10-04）を聞かれた範囲で伝えるに留め、**個人の体調や服薬についての判断・助言はしない**（医療的な主張は本DBの健康情報の方針として行わない、10-03/10-04）。判断に迷う訴えは医療者への相談を案内する。

### クレーム・トラブル対応の原則

- **原則は「事実確認→記録→品質管理への接続」** である。感情への対応と事実の処理を分けて考える。
  1. **事実確認**: 何が、いつ、どの製品（豆の銘柄・ロット、抽出条件）で起きたかを客の話から切り分ける。その場で原因を断定しない（抽出の不良か、豆そのものか、器具か、客の体調・好みかは切り分け前には分からない）。
  2. **対応**: 事実関係に応じ、代替品の提供や返金等の店舗の規定に沿って対応する。規定がない店舗では、対応の権限を持つ者（責任者）に速やかに引き継ぐ。
  3. **記録**: 日時、客の訴えの要点、対象製品とロット、実施した対応を記録に残す。記録は 05-09 の品質管理（クレーム・回収への対応、トレーサビリティ）に接続され、同じロットへの同種の訴えが重なった場合に「単発の好みの相違」か「製品の問題」かを判定する材料になる。
  4. **再現確認**: 味に関する訴えは、同じロット・同じ条件でスタッフが確認する（カッピング・テイスティングの手順は 09-01/09-07）。確認結果も記録に含める。
- **食品安全に関わる事案は分担が異なる**: 異物混入、食中毒が疑われる体調不良の訴え等は、味や好みの問題として処理してはならない。本エントリーでは扱わず 12-07（食品衛生）の担当範囲とする。現場の初動としてのみ、対象製品の提供を止めて保管し、責任者へ直ちに報告すること、その後の判断は責任者と所管の手続きに従うことを記す。

### 店舗運営の入口

- **開店作業**: 接客は開店準備の完了と一体である。機器の立ち上げと洗浄状態の確認（12-05）、その日の豆での抽出基準の確認（12-01 のダイアリングインは開店時の味の基準づくりでもある）、カップ等の備品と原材料の不足確認が、提供を始める前提になる。
- **閉店作業**: 清掃（12-05）と記録（清掃記録、抽出の調整ログ、クレーム記録、在庫の異常）を翌営業日へ引き継ぐ形で閉める。記録の引き継ぎが切れると、翌日の接客と品質管理が再びゼロから始まる。
- **行列・提供時間の管理**: ボトルネックは抽出工程にあることが多く、注文を受ける速度と作る速度の差が行列になる。管理の型は、(1) 注文の順序を可視化して取り違えを防ぐ、(2) 待ち時間の見込みを注文前に伝える（基本動作の節と共通）、(3) 混雑時ほど復唱と確認を省略しない、の3点である。効率化のために確認工程を削ることは、作り直しとクレームで結果的に提供時間を延ばす。
- **文化としての接客との違い**: 喫茶店の接客の様式や歴史（純喫茶の接客、自家焙煎店のあり方）は 08 系・13-02 の文化・系譜の範囲であり、本エントリーは現業の実務に限定する。
