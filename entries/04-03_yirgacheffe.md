# 要約
エチオピア南部のゲデオ・ゾーン（Gedeo Zone）に位置するコーヒー産地の呼称。行政上の町イルガチェフェ（Yirga Ch'efe）を中心とする地域で、ウォッシュド（水洗式）コーヒーの産地として国際的に知られる。本エントリーの座標は町の代表点であり、産地全体の範囲を示すものではない。

# 本文

## 地理（geo_places 登録値）
| 項目 | 値 | 備考 |
|---|---|---|
| 代表点（町） | 北緯 6.1667 / 東経 38.2000（WGS84） | **代表点**。GeoDatos の座標データで確認（2026-11-11）。産地の重心や境界ではない |
| 町の標高 | 1,880〜1,919 m | 町そのものの標高（百科事典経由で確認）。**産地の栽培標高帯とは別**であり混同しない |
| 行政上の位置 | ゲデオ・ゾーン（南エチオピア地域州側） | 近年の州再編で所属州の表記が変わっているため、州名は Phase 3 で現行行政区分を確認して固定する |
| 栽培標高帯 | 未登録（要検証） | 一般に約1,700〜2,200mと語られるが、本試作では原典確認が取れていないため数値を入れない |

注: 取引上「イルガチェフェ」と呼ばれる範囲は町の行政範囲より広く、周辺地区（コチェレ、ウェナゴ、ゲデブ等）を含む産地呼称として使われることが多い。この「呼称範囲」と行政界は一致しない（カタログ02 §F の指摘どおり、boundary は行政界を流用し、産地固有の範囲は別途注記で持つ）。

## 生産の特徴（傾向記述）
- 精製: ウォッシングステーションでの水洗式（ウォッシュド）が代表的とされるが、ナチュラルも生産される。比率は未検証のため断定しない。
- 品種: 在来種（heirloom）の混植が中心とされる（02-04 と連動）。JARC 選抜の番号品種が南部で広く植えられているとの資料もあるが、本地域への限定確認は未了。
- 収穫期: エチオピアの主収穫期（10〜12月）に含まれる（04-02-ET 参照）。地域単独の月次データは未確認。
- 産業面: USDA が支援する TechnoServe の "Regrow Yirga" プロジェクトがゲデオ・ゾーンで実施され、老木のスタンピング更新等で単収が改善した事例が USDA GAIN（ET2025-0014）に報告されている。

## 風味傾向（傾向記述）
- ウォッシュドでは花の香り、柑橘、紅茶を思わせる軽やかな質感がよく言及される。これらは取引・専門資料の傾向表現であり、測定値ではない。同じ「イルガチェフェ」でも精製法（ウォッシュド／ナチュラル）で印象は大きく変わるため、アプリでは精製法とセットで表示する。
