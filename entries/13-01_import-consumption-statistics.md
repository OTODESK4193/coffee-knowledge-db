## 要約

日本の輸入・消費統計の中心は、全日本コーヒー協会（AJCA）が公表する **「日本のコーヒー需給表」** で、1996年以降の時系列が公開されている（C13-01）。需給表は **生豆ベース（トン）** で作られ、生豆輸入量と製品輸入量（生豆換算）は **財務省貿易統計** が原データ、在庫は AJCA 調べ、という出所の分かれ方をしている。今回、需給表で直接確認した値では、**国内消費量は2018年の470,212 t がこの時系列のピーク側にあり、2024年は400,218 t、生豆輸入量は2024年 360,430 t** と、消費は緩やかな減少基調にある。数値を使うときは「どの年の・生豆換算か・確報か速報か」を必ず併記し、チャート（M-13-01-1 輸入量／M-13-01-2 消費量）はこの需給表を正として構造化する。品目の定義そのものは税関の統計品目表（HS 0901 系、C13-03）が正本である。

## 本文

### 統計の体系（どこに何があるか）

- **AJCA「日本のコーヒー需給表」**（C13-01）: 期首在庫＋生豆輸入量＋製品輸入量（生豆換算）＝供給計、そこから国内消費と輸出を引いて期末在庫を出す需給の形で、日本のコーヒーの全体量を1表で追える。注記によれば、在庫（期首・期末）は AJCA 調べ、輸入量・消費量（生豆換算を含む）は財務省貿易統計に基づく。RC はレギュラーコーヒー、IC はインスタントコーヒーの略。
- **財務省貿易統計／e-Stat**（C13-04）: 品目別・国別の数量と金額の原データ。輸入相手国の構成（M-13-01-3）はこちらから作る。
- **品目定義**（C13-03）: コーヒーは HS 09.01（0901.11 非デカフェ生豆／0901.12 デカフェ生豆／0901.21・0901.22 焙煎豆／0901.90 その他）、インスタントコーヒーは 2101.12 系に分類される。「輸入量」という数字が何を含むかは、この分類が決める。
- **需要側の調査**（C13-02）: AJCA「コーヒー需要動向調査」は量ではなく飲む人の行動（杯数・飲用率）を測る調査で、13-04 で扱う。需給表（量）と混同しない。

### 確認済みの時系列（需給表、生豆ベース、単位 t）

本バッチで AJCA 需給表の公表値から直接読み取った範囲のみを置く（供給計・在庫は表の構造として上記の通り）。

| 年 | 生豆輸入量 | 国内消費量（生豆換算） | 備考 |
|---|---|---|---|
| 1996 | 326,914 | 352,189 | 需給表の時系列の起点 |
| 2018 | 401,249 | 470,212 | 消費はこの期間のピーク側 |
| 2019 | 436,654 | 452,903 | 生豆輸入量はこの年が大きい |
| 2020 | 391,713 | 430,715 | |
| 2022 | 390,208 | 432,873 | |
| 2023 | 355,819 | 401,627 | |
| 2024 | 360,430 | 400,218 | 前年比は消費 −0.4%（需給表の対前年比表示） |

- 読み取れるのは「2018年前後を境に、消費量が470千 t 級から400千 t 級へ緩やかに下がっている」という **量の事実** までであり、減少の原因（人口動態、価格、嗜好変化等）の切り分けは需給表だけではできない。原因の議論は 13-04 で、出典のある範囲に限って扱う。
- 2025年の値は速報ベースで公表が進んでいるが、確報値との差し替えが前提になるため、本エントリーの確定表には入れず、M-13-01-1／-2 のデータ登録時に「速報」フラグ付きで扱う（末尾メモ）。

### 国際位置づけの注意

- 日本の消費量の国際順位は ICO 統計に基づく整理で語られることが多い（AJCA も世界の国別消費量を ICO 統計から再掲している）。ただし ICO の集計（コーヒー年度・60 kg袋）と AJCA 需給表（暦年・トン・生豆ベース）では基準が違い、**数値同士を直接つないではいけない**（単位換算は 00-02、集計基準の違いは 04-01／05-02 の扱いと共通）。

## 未確認・要検証メモ

- **2025年の確報値**: 需給表は速報→確報で値が動く。本バッチで検索結果に現れた2025年速報値（生豆輸入 359,629 t、消費 397,272 t 等）は、AJCA 公式 PDF の現行版を直接開いて版（速報／確報）を確認してから M-13-01-1／-2 に登録する。本文の確定表には入れなかった。
- **輸入相手国の構成比**: 国別生豆輸入量の表（ブラジル、ベトナム、コロンビア等の順位と量）は AJCA の国別表で公表されているが、本バッチでは AJCA 公式の国別表そのものを直接開いて数値を確認できていない（二次報道経由の値のみ）。M-13-01-3 は公式国別表の直接確認後に作成する。
- **輸入金額の系列**: M-13-01-1 には輸入金額の列があるが、金額は貿易統計の金額ベースで別途抽出が必要であり、本バッチでは未着手。量の系列と金額の系列は価格変動（05-03）の影響の受け方が違うため、混ぜて1系列にしない。
- **家計調査との接続**: 総務省「家計調査」のコーヒー支出系列（C13-05）は、2025年の品目分類改定前後のコード接続が未確認（カタログ §9-15）。世帯側の支出動向は、接続表を確認してから 13-04 に取り込む。
- **status 判断**: 需給表の構造と主要年の値は公式公表値で確認できたが、2025年確報・国別構成・金額系列が未了のため draft とする。
