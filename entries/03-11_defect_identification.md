# 要約
生豆の欠点を「目で見て数える」ための知識を整理する。国際取引で参照される SCA の生豆欠点分類（Green Arabica Coffee Classification、2004年体系）では、欠点を深刻さで Category 1（一次欠点）と Category 2（二次欠点）に分け、種類ごとに定めた換算率で「相当欠点数（full defect equivalents）」に直して合計する。全黒豆・全酸豆・カビ豆・乾燥チェリー・異物は1粒（1個）で相当欠点1、部分黒豆・部分酸豆は3粒で1、砕豆・未熟豆・貝殻豆などは5粒で1、軽度の虫害豆は10粒で1、という換算である。旧来のスペシャルティグレードの条件は、アラビカ生豆350gサンプルで Category 1 がゼロ、相当欠点数の合計が5以下とされてきた。本エントリーはあくまで「同定のための知識」であり、実物や写真を見て判定する訓練そのものは、アプリ側に写真・イラスト素材が別途必要である（末尾メモ参照）。カップに出たときの知覚（官能的欠点）は 09-05 が担当し、本エントリーは外観による分類と同定を担当する。

# 本文

## 位置づけ（何のための知識か）
- 本エントリーの対象は、J.C.Q.A. 鑑定士の「生豆鑑定」、SCA CSP Green Coffee の欠点同定、Evolved Q の Physical Assessment が共通して要求する「欠点豆を見分けて数える」知識である。ただし試験・実務の核心は実物を手に取って判定する実技であり、本エントリーはその前提知識（分類の枠組みと同定ポイント）の補完に位置づく。
- 03-07 は選別工程と「等級制度は国ごとに違う」という制度面を扱った。本エントリーは、そのうち国際的に参照される SCA 分類の語彙と判定基準を掘り下げる。国別制度の数値と混ぜて使わないこと（サンプル量からして異なる。後述）。
- 09-05 の官能的欠点（ポテト／カビ／フェノール）とは区別する。たとえば「カビ」は、09-05 ではカップで知覚される匂いの欠点、本エントリーでは豆の外観に見えるカビ損傷（物理的欠点）として扱う。両者は関連するが、判定する対象（液体か豆か）が違う。

## 分類体系（SCA 生豆欠点分類、2004年体系）
- 枠組み: 生豆サンプルを広げ、欠点豆を種類別に拾い上げて数え、種類ごとの換算率で相当欠点数に換算し、切り捨てて合計する。1粒に複数の欠点が重なる場合は、より深刻な方だけを数える（業界資料で説明される運用）。
- Category 1（一次欠点）: カップ品質への影響が大きく、旧来のスペシャルティグレードでは混入ゼロが条件とされた。
  - 全黒豆、全酸豆、カビ豆（fungus damage）、乾燥チェリー（ポッド）、異物: 1粒（1個）＝相当欠点1
  - 重度の虫害豆: Category 1 に分類されるが、換算は5粒＝相当欠点1（カテゴリと換算率が連動しない例として注意が要る）
- Category 2（二次欠点）: 個別の影響は小さいが蓄積すると品質を下げるもの。
  - 部分黒豆、部分酸豆: 3粒＝相当欠点1
  - パーチメント付き豆、フローター、未熟豆、萎凋豆、貝殻豆、砕豆・欠け豆、果皮（ハスク）付き豆: 5粒＝相当欠点1
  - 軽度の虫害豆: 10粒＝相当欠点1
- 旧来のスペシャルティグレードの条件（2004年体系）: アラビカ生豆350gサンプルで Category 1 相当欠点ゼロ、Category 2 を含む相当欠点数の合計5以下、あわせて水分等の条件と、焙煎豆100gサンプルでクエーカー（焙煎しても色づかない未熟豆）が無いことが求められたと業界資料に整理されている（03-07 の FAO 資料が示す乾燥目標約11%とは別の、SCA 側の条件である点に注意）。
- **CVA 時代の位置づけ**: SCA 公式 CVA ページが述べる通り、CVA の Physical Assessment はこの2004年の生豆格付け制度に基づく（09-02 で確認済み）。変わったのは「80点以上＝スペシャルティ」というラベル中心の運用であり、欠点の分類語彙・換算の考え方自体は、Physical の記録や国際取引の実務参照として現役である。なお貿易向けの欠点参照チャートとして ISO 10470（Green coffee — Defect reference chart）も存在するが、本エントリーでは存在の指摘に留める。
- ロブスタには別の分類体系がある。アラビカの換算値をロブスタに流用しないこと（ロブスタ側の具体的数値は未確認のため本エントリーでは扱わない）。

## 欠点ごとの同定ポイント（M-03-11-2 への登録値）
風味への影響は「方向」の提示に留める。カップでの知覚の詳細は 09-05 を参照。

| 欠点 | 分類・相当数 | 見た目の特徴 | 発生段階・主な原因 | 風味への影響の方向 |
|---|---|---|---|---|
| 全黒豆（full black） | Cat 1／1粒＝1 | 表面の50%以上が不透明な黒〜黒褐色に変色し、しわが寄ることが多い。「50%以上か」が部分黒豆との判定境界 | 収穫・精製: 過熟・落果して土に触れた実、過発酵、微生物の汚染 | 強い発酵臭、フェノール様、汚れた印象。少数でもカップを支配する |
| 部分黒豆（partial black） | Cat 2／3粒＝1 | 黒変が表面の50%未満（黒い斑点、縁や先端だけの黒変） | 全黒豆と同じ原因の軽いもの。乾燥ストレス等も | 多数集まると平板で鈍い印象 |
| 全酸豆（full sour） | Cat 1／1粒＝1 | 豆全体が黄褐色〜赤褐色に変色。割ると酢のような酸臭がある場合がある | 精製: 過発酵、汚れた発酵水、収穫後果肉除去までの放置 | 酢酸様の酸っぱさ、発酵した不快な酸 |
| 部分酸豆（partial sour） | Cat 2／3粒＝1 | 変色が部分的で、全酸豆より淡い黄褐色 | 過発酵の軽いもの | 軽い酸敗感 |
| カビ豆（fungus damage） | Cat 1／1粒＝1 | 表面にカビによる斑点・粉状の付着が見える | 乾燥・保管: 乾燥不足、高湿環境での保管・輸送（03-07／03-08） | カビ臭・かび臭さ（09-05 の moldy と関連）。風味以前に食品衛生上の問題として扱う |
| 重度の虫害豆（severe insect damage） | Cat 1／5粒＝1 | 穿孔が3個以上、または内部にトンネル状の食害が広がる | 栽培: コーヒーベリーボーラー（03-03）の食害 | 汚れた印象、酸敗・カビの侵入口にもなる |
| 軽度の虫害豆（slight insect damage） | Cat 2／10粒＝1 | 穿孔が1〜2個 | 同上（ベリーボーラー） | 単独では小さい。孔の数が判定境界（3個以上で重度） |
| 未熟豆（immature） | Cat 2／5粒＝1 | 緑がかった銀色で薄く、表面にしわ。断面が詰まっていない | 収穫: 未熟なチェリーの混入（03-04） | 草っぽさ、渋み、甘さの不足。焙煎後に色づかないものはクエーカーと呼ばれ、焙煎豆側で判定される |
| 萎凋豆（withered） | Cat 2／5粒＝1 | しなびてスポンジ状に軽く、しわが多い | 栽培: 干ばつ、栄養不足、樹への過剰な結実負担 | 木質で平板な印象 |
| 貝殻豆（shell） | Cat 2／5粒＝1 | 豆が貝殻のように割れて外側と内側に分かれた形状 | 発育過程の異常（果実内での種子の形成異常とされる） | 焙煎で縁が焦げやすく、焙煎ムラの原因になる |
| 砕豆・欠け豆（broken/chipped/cut） | Cat 2／5粒＝1 | 破片、欠け、切り傷のある豆 | 脱穀・選別: 過乾燥の豆への機械的負荷、脱殻機の調整不良（03-07） | 焙煎ムラ、酸化が進みやすい |
| フローター（floater） | Cat 2／5粒＝1 | 白っぽく軽い。水に浮く性質が名の由来で、水選の段階でも除去対象になる（03-04／03-07） | 樹上で乾いた実や未充実の実由来 | 薄く木質・紙様の印象 |
| パーチメント付き豆／果皮付き豆（parchment／hull・husk） | Cat 2／5粒＝1 | 内果皮（パーチメント）や乾いた果皮が残ったままの豆 | 脱穀の不完全（03-07） | 直接の影響は小さいが、脱穀工程の品質を示す指標 |
| 乾燥チェリー（dried cherry／pod） | Cat 1／1粒＝1 | 果実の形のまま乾いたものが混入 | 精製・脱穀の不完全 | 発酵・過熟の印象を持ち込むことがある |
| 異物（foreign matter） | Cat 1／1個＝1 | 小石、木片、土塊など豆でないもの | 収穫・乾燥・脱穀の各段階での混入 | 風味以前の問題。石はグラインダー損傷の原因にもなる。大きさにより扱いが分かれる（メモ参照） |

## サンプルの扱い（評価作法の知識）
- **サンプル量は制度で異なる**: SCA 分類（アラビカ）は350g。国別制度には300gで数えるものがある（エチオピアの欠点数等級、ブラジルの NY 表示。03-07）。生の個数を制度間でそのまま比較してはいけない。
- 手順の骨格: サンプルを広げる→欠点を種類別に拾い分ける→種類別に数える→換算率で相当欠点数に直し切り捨てる→カテゴリ別と合計を記録する。サンプルがロットを代表していることが全ての前提であり、サンプリング自体の作法（袋の各部から取る等）は取引実務の領域として本エントリーでは深追いしない。
- クエーカーは生豆ではなく焙煎豆で判定する（焙煎しても色づかない未熟豆）。「生豆の同定」と「焙煎後の確認」は別工程である。
- 水分・サイズ・色も Physical の記録項目である（09-02）。欠点数だけでロットの評価が完結するわけではない。

# 未確認・要検証メモ
- **換算値とスペシャルティ条件の格付け**: 本エントリーの相当欠点数（1／3／5／10粒）とスペシャルティ条件（350g、Cat 1 ゼロ、合計5以下、焙煎豆100gでクエーカーなし）は、SCA の生豆欠点ハンドブック（Green Coffee Defect Handbook、2004年体系）に基づく値として、輸入業者・業界解説など複数のB級資料で一致を確認した範囲で載せた。SCA 公式の原典（ハンドブックは有料刊行物。また Green Coffee の格付け規格として SCA-110 の存在が二次資料で言及される）は未照合であり、verified 化の必須条件とする。出典は仮ID 03-S24（SCA 欠点ハンドブック／Green Arabica Coffee Classification）としてカタログ正式追加を提案する（既存の 03-S18 は輸入業者グレード解説）。
- **サンプル量の諸説**: 二次資料には SCA 分類を300gと記すものも混在する。350gが輸入業者資料の主流であり本文は350gを採ったが、原典照合時に確定する。国別制度の300g（03-07）とは別物である。
- **異物の細分**: ハンドブックでは石・木片は大きさで扱いが細分されると二次資料が示唆するが、細部の換算は未確認のため本文は「1個＝1」の原則形に留めた。
- **全黒豆の「50%」境界**: 複数の業界資料で一致する同定基準だが、これも原典照合の対象に含める。
- **ロブスタの分類**: ロブスタ向けの別体系の存在のみ確認。具体的な欠点種と換算値は未確認のため書いていない。扱う場合は別エントリーとする。
- **ISO 10470**: 貿易向け欠点参照チャートとしての存在のみ二次資料で確認。内容（欠点の図版・分類）は未確認。
