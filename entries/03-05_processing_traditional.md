# 要約
精製（プロセス）は、収穫したチェリーから果皮・果肉・ミューシレージ（粘液質）・パーチメント（内果皮）を取り除き、乾燥した生豆を得る工程の総称である。伝統方式は大きく、(1) チェリーのまま乾燥させるナチュラル（乾式）、(2) 果肉を除去し発酵と水洗でミューシレージを落としてから乾燥させるウォッシュド（水洗式）、(3) 果肉だけ除去してミューシレージを残したまま乾燥させるハニー／パルプドナチュラル、(4) 高い含水率のままパーチメントを剥くスマトラ式（ウェットハル、現地名 giling basah）に分かれる。どの層を・どの順序で・どの水分状態で取り除くかが方式の違いの本質で、02-05 の断面図の層と対応させて理解する。工程フローは必須メディア M-03-05-1（制作指示 PN-08）に4方式並列で図解する。

# 本文

## 方式ごとの工程（M-03-05-1 のフロー図と step 番号を一致させる）

### ウォッシュド（水洗式）
1. 収穫・選別（水に浮く欠点果の除去を含む）
2. 果肉除去（パルピング）: 収穫後速やかに機械で外皮と果肉を外す
3. 発酵: パーチメントに付いたミューシレージを、タンク内で微生物・酵素の働きで分解する（FAO 資料。時間は気温・方式で変わる）
4. 水洗: 分解されたミューシレージを洗い流す
5. 乾燥: パーチメントコーヒーの水分はこの段階で約57%。最適とされる約11%まで天日（パティオ／ raised beds）または機械で乾燥させる（FAO 資料では天日で8〜10日が目安とされる）
6. 脱穀（ドライミル工程、03-07）

多量の水を使うこと、排水の環境負荷が課題であり、節水型の設備（機械式ミューシレージ除去等）への置き換えも進んでいる。使用水量の具体的数値は資料により幅が大きく、本エントリーでは置かない。

### ナチュラル（乾式）
1. 収穫・選別
2. チェリーのまま乾燥: 外皮・果肉をつけたまま天日で乾燥させる。FAO 資料では「最も古く、最も単純で、機械をほとんど必要としない」方式とされ、天候により最大4週間ほどで最適水分約11%に到達する
3. 脱穀: 乾いた果皮・果肉とパーチメントを一度に取り除く

発酵や水洗による後段の修正が効かないため、収穫時点での成熟選別が特に重要になる。乾燥中の管理（攪拌、雨対策、カビ防止）が品質を決める。

### ハニー／パルプドナチュラル
1. 収穫・選別
2. 果肉除去: ウォッシュドと同様に外皮と果肉を外す
3. ミューシレージを残したまま乾燥: 発酵・水洗の工程を経ず（または最小限にし）、粘液質をつけたままパーチメントごと乾燥させる。残す量により呼び名が細分される場合がある（ホワイト／イエロー／レッド／ブラック等。呼称の体系は生産者・地域依存で公的規格ではない点に注意）
4. 脱穀

ブラジルのパルプドナチュラルと中米のハニーは近縁の方式として扱われることが多い。両者の呼称の使い分けに厳密な国際定義はない（要検証メモ参照）。

### スマトラ式（ウェットハル／giling basah）
1. 収穫後、農家段階で果肉除去（小型パルパー）
2. 短い発酵と部分乾燥: パーチメントのまま少しだけ乾かす
3. 高含水のまま脱穀: 含水率がまだ高い（資料により約30〜50%の範囲で語られる）段階でパーチメントを剥く。通常の脱穀（乾燥後）とは順序が逆である点が本方式の決定的な特徴
4. 裸の生豆のまま最終乾燥

インドネシア（スマトラ、スラウェシ等）の多湿な気候と、小規模農家から集荷する流通構造に結びついた方式とされる。生豆が暗い青緑色を帯びる外観も特徴として語られる。

## 味への影響（傾向記述）
| 方式 | 傾向として語られる表現 |
|---|---|
| ウォッシュド | クリーンで明快、産地・品種の特徴が出やすい |
| ナチュラル | 果実味が強く、甘さとボディが出やすい一方、発酵由来の欠点も出やすい |
| ハニー | ウォッシュドとナチュラルの中間的。甘さが強調されやすい |
| スマトラ式 | 土やハーブを思わせる個性、重いボディ、低い酸質として語られることが多い |

これらは取引・専門資料で広く用いられる傾向表現であり、同一方式でも生産者・ロットで大きく異なる。アプリでは「傾向」として表示し、方式から味を断定しない。

## 方式選択の条件
- 気候（乾燥期の有無と湿度）、水資源の availability、設備投資、労働力、狙う市場が選択を決める。コロンビアのようにウォッシュドが標準化された国、ブラジルのように乾式＋パルプドナチュラルが発達した国、インドネシアのウェットハルなど、国・地域の標準は 04 の国別プロファイルと相互参照する。
